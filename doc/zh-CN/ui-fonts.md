# Linux 界面字体与渲染说明

本文档介绍 Mark Shot 在 Linux 环境下的界面字体匹配规则、渲染参数及配置生效方式。

## 字体匹配规则

Mark Shot 界面控件（包含设置界面、提示窗口、文字识别与翻译面板、贴图右键菜单等）的文字显示规则如下：

1. **Fontconfig 默认无衬线字体**：应用程序优先通过 Fontconfig 查询系统默认的 sans-serif（无衬线）字体族。该设置来自 Fontconfig 配置，不保证与 KDE 或 GNOME 独立保存的桌面 UI 字体设置一致。
2. **特定界面例外**：个别有固定排版需求的界面保留明确指定的字体家族，例如文字识别结果中的表格表头固定使用 DejaVu Sans。
3. **回退后备**：当未配置无衬线字体或查询失败时，程序回退到内置的 Inter 字体，维持界面可读。
4. **标注文字独立性**：截图标注工具中的文本添加功能使用独立的排版与导出路径，标注文字字体不会自动跟随 Fontconfig 默认字体。

## 渲染参数支持

在 Linux 平台下，Mark Shot 按匹配字体的粗细与像素尺寸，读取并遵循 Fontconfig 定义的微调与抗锯齿规则：

- **抗锯齿（Antialias）**：平滑字形边缘。
- **字体微调（Hinting 与 Hintstyle）**：支持无微调（None）、轻度（Slight）、中度（Medium）与完全微调（Full）。
- **自动微调（Autohint）**：遵从系统的自动微调配置。
- **子像素排布（RGBA）**：支持 RGB、BGR、VRGB、VBGR 等液晶排布。
- **LCD 滤镜（LCDFilter）**：应用配置的次像素平滑滤镜。
- **内嵌点阵（Embeddedbitmap）**：在相应字号下遵循内嵌位图设定。

### 半透明背景文字渲染

在透明或半透明背景区域渲染字体时，程序自动使用灰度抗锯齿，减轻次像素排布可能带来的边缘彩色杂边。

## 配置生效与重启要求

Mark Shot 在运行期间不监听 Fontconfig 规则文件的动态修改。

若调整了系统的 Fontconfig 规则或安装了新字体：

1. **常规退出**：退出并重新启动 Mark Shot。
2. **后台待命进程**：若开启了后台待命或托盘常驻模式，需通过托盘菜单退出应用程序，或在终端结束常驻进程后重新启动，新规则方可生效。
