# Mark Shot 原生 Wayland 预览版 5

本版补齐独立 OCR 结果窗口的原文右键菜单，复用共享文字编辑器和原生弹出表面。
完整 Rust 重写尚未完成，不替代 Mark Shot Qt 稳定版，不更新 Latest，也不进入原版发行渠道。

## 本版改动

- 原文右键提供 Undo、Redo、Cut、Copy、Paste、Delete、Select All，保留两处分隔线及原版快捷键
- 右键保持光标和选区，不定位字符或开始拖选；原图页不接收原文菜单动作
- 菜单尺寸 225×229、行高 29，对照真实 `OcrTextPane::showEditorMenu` 和自绘 `ContextMenu`
- 左键释放才执行动作；右键、禁用行、分隔线和菜单内编辑快捷键不修改正文
- 上下、Tab、Home、End、翻页键跳过禁用项，首字母在可用匹配项之间循环
- 菜单使用独立 `xdg-popup`，可伸出父窗口边界，合成器负责屏幕避让和输入抓取
- 创建抓取只使用当前真实鼠标按下的座席和序列号，不复用旧输入序列号
- 打开菜单取消显示候选、停止拖选并停用输入法目标；关闭后恢复资格，过期确认不能进入正文
- 菜单角色销毁后才交付编辑或剪贴板动作，选区复制不触发全文复制反馈
- 菜单复用有界共享内存缓冲和缓存排版，静止时不提交帧或启动轮询
- 窗口输入、原文菜单和菜单动作拆分为独立模块，不与表格复制格式菜单混用
- 第五版发布校验强制要求同指纹的 niri、Sway 菜单证据和原生输入法隔离证据

## 构建与验证

仅提供 Linux Wayland x86_64 归档，使用 Ubuntu 24.04 构建，最低 glibc 为 2.39。
程序需要 Wayland、xkbcommon、PipeWire 和 Fontconfig 运行库，不依赖 Qt、GTK 或 WebView。
归档包含可执行文件、来源提交、依赖许可、帮助输出及兼容性文档。

远程构建的 789 项 Rust 测试通过，10 项忽略；152 项 Python 测试通过。
格式、所有目标与功能的严格 Clippy、验证脚本导入检查、发布编译和许可检查通过。
发布只使用成功远程构建的固定归档，不重新打包或用本地构建替代。该下载二进制验证十四组私有桌面回归：

- niri、Sway 截图 layer/window 四组共 21 个原生输入场景，候选不进入导出，原图与基准逐像素一致
- 两组文字光标回归，提交结束后停止周期重绘，验证窄区域损坏提交及 niri 失焦暂停
- 两组 OCR 结果输入法回归，验证原文、单元格及菜单候选取消、过期确认拒绝和资格恢复
- 两组原文菜单回归，验证七项编辑动作、左右键职责、禁用项、首字母导航、外部取消和持久剪贴板
- 三组历史流程、长图及鼠标回归，保留原图 RGBA、IDAT、保存快照、配置策略、分隔和滚动断言
- 一组独立历史确认回归，验证同进程父子关系、输入隔离、释放确认及父窗口关闭回收
- 历史、结果窗口及静止菜单采样为单线程，空闲 CPU 时钟增量为零，没有持续菜单帧提交

Qt 6.12.0 探针只读链接原版对象，采集实际原文菜单的 21 个场景，不用相似菜单替代。
此前预览版 4 的下载二进制在新增回归中复现“右键不创建原文菜单”，保留失败证据。
复制顺序通过原生角色销毁、业务调用日志和持久剪贴板结果共同验证；剪贴板源由独立守护进程创建。
原始来源、归档和二进制摘要及回归摘要见公开资产 `native-preview-verification.json`。

原版仓库在本轮出现无关的并发修改。本版不写入或撤销这些文件；菜单参考样本在并发修改前取得，
只读构建器确认当时的 407 个原版对象没有过期依赖。验证记录明确保留前后状态差异。

## 已知差异

- 离屏 Qt 探针未从 Shift+F10 或 Menu 键自动产生上下文事件，真实 Wayland 键盘入口仍待验证
- 完整 Qt 焦点遍历、独立结果窗口和属性字段光标闪烁、表格多选及全页几何仍未完成
- 窗口系统装饰、全部主题和语言、全部焦点信号及 Qt 全界面像素比较仍未完成
- 历史完整提示框、长状态和空预览换行、精确 Qt 滚轮与翻页、增量缓存仍未完成
- OCR 未编辑单元格首次 CJK 输入、全部 Unicode、Bidi、Fcitx/IBus 和活动大文档资源尚未全面验证
- 完整设置、翻译、上传、扩展、托盘、配置迁移及其他原版兼容性工作仍保留
- 此前 niri 菜单关闭后的首次移动偏差仍为已知差异，本版不宣称修复，也不补发移动掩盖问题
- OCR 窗口回归使用固定识别结果，不将其表述为模型下载或真实 OCR 的新验证
- 二维码扫描和录像不在本次重写范围内

详细证据与边界见归档中的 `docs/ocr-source-menu-compatibility.md`、
`docs/window-input-method-compatibility.md` 和 `docs/history-clear-dialog.md`。
