# Mark Shot 原生 Wayland 预览版 3

本版修正截图历史窗口偏离原版的布局与输入行为。完整 Rust 重写尚未完成，不替代
Mark Shot Qt 稳定版，不更新 Latest，也不进入原版发行渠道。

## 本版改动

- 删除历史窗口多余的搜索、数量、加减和刷新控件，恢复顶部五项操作及底部记录开关
- 默认 800×520、最小 440×320，列表与预览保持水平分区，分隔条支持拖动
- 使用原版 SVG 和深色配色，历史窗口定向加载系统 Sans Serif，记录只显示日期与尺寸
- 右键列表只选择记录，右键按钮不执行操作，Ctrl+F 不增加原版不存在的输入框
- 左键按钮在原按钮内释放才执行；Space 释放触发，Enter 不代替按钮点击，失焦取消旧事务
- 滚动条绘制和输入共用几何，拖动与轨道翻页不切换活动记录，屏幕外选择仍可复制原图
- 未选中记录只缓存缩略图，避免满屏记录挤掉当前整图预览并引发循环读取
- 新版发布清单要求同一下载二进制通过三组历史回归，旧标签、清单与公开资产保持不变

## 构建与验证

仅提供 Linux Wayland x86_64 归档，使用 Ubuntu 24.04 构建，最低 glibc 为 2.39。
程序需要 Wayland、xkbcommon、PipeWire 和 Fontconfig 运行库，不依赖 Qt、GTK 或 WebView。
归档包含可执行文件、来源提交、依赖许可、帮助输出及兼容性文档。

远程构建的 776 项 Rust 测试通过，10 项忽略；147 项 Python 测试通过。
格式、所有目标与功能的严格 Clippy、验证脚本导入检查、发布编译和许可检查通过。
发布使用成功构建的固定归档，不重新打包或以本地构建替代。该下载二进制在私有桌面验证：

- niri、Sway 截图 layer/window 四组共 21 个原生输入场景，候选不进入导出，原图与基准逐像素一致
- 两组截图文字光标回归，提交结束后停止周期重绘，验证窄区域损坏提交及 niri 失焦暂停
- 两组独立 OCR 结果窗口输入法场景，原文与单元格候选、复制、撤销和表格提交相互隔离
- 历史完整流程验证原图 RGBA、IDAT、Unicode 保存、覆盖取消、删除后快照、普通贴图及重编辑
- 历史边界验证首次禁用不创建目录、拖动时快捷键保护、144×20000 长图和目录导航
- 历史鼠标验证重复右键不编辑、右键复制不执行、分隔拖动、三十二项记录滚动及屏幕外原图复制
- 历史和静止 OCR 结果窗口采样为单线程，空闲 CPU 时钟增量为零

真实 Qt 6.12.0 离屏参考覆盖四组窗口尺寸、五组分隔宽度、状态行、初始焦点及 Space
按下与释放。原生几何执行严格矩形比较，但这不证明全部主题、真实 Qt Wayland 或逐像素一致。
固定来源、归档和二进制摘要及场景证据见公开资产 `native-preview-verification.json`。

## 已知差异

- 历史窗口仍只覆盖英文深色主题；完整提示框、长状态与空预览换行、精确 Qt 滚轮与翻页、增量缓存及全像素比较未完成
- 清空仍为窗口内受控确认层，不是原版独立对话框；数量与容量策略通过配置设置
- OCR 未编辑单元格首次 CJK 输入、完整焦点遍历、独立窗口光标闪烁、正文右键菜单及表格多选仍未完成
- 完整 Unicode、Bidi、Fcitx/IBus、完整合成器与多输出矩阵及活动大文档资源尚未全面验证
- 亮色主题、完整设置、翻译、上传、扩展、托盘、配置迁移及其他原版兼容性工作仍保留
- 此前 niri 菜单关闭后的首次移动偏差仍为已知差异，本版不宣称修复
- 本版 OCR 窗口回归使用固定识别结果，不将其表述为模型下载或真实 OCR 的新验证
- 二维码扫描和录像不在本次重写范围内

详细边界见归档中的 `docs/history-window-reference.md`、`docs/history-compatibility.md`
与 `docs/window-input-method-compatibility.md`。
