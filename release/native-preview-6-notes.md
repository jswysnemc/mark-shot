# Mark Shot 原生 Wayland 预览版 6

本版修正 OCR 结果窗口的按钮输入时机和焦点职责。界面行为以原版 Qt
`OcrResultWindow` 的实际控件为依据，不以相似测试窗口代替原版。

## 本轮修正

- 复制、撤销、关闭按钮在左键按下时只显示按下状态，原按钮内部释放才执行；移出释放取消。
- 移出后返回恢复按下外观；失焦和内部焦点切换取消未完成事务。
- 右键和中键只聚焦按钮，不执行操作；左键抓取期间的右键不启动正文菜单。
- Space 包括 Ctrl、Shift、Alt、Meta 组合均等待释放，自动重复按下不重复执行。
- 普通 Return 不执行非默认按钮；只有无修饰键 Escape 关闭普通结果窗口。
- 页签保留左键按下即切换，右键只获得页签焦点。
- 全空白原文禁用全文复制；禁用按钮点击后正文不能继续接收字符或输入法确认。
- 最后一项原文撤销后隐藏撤销按钮，把焦点转向启用的复制按钮。
- 按下背景与焦点边框参考原版暗色规则，不把按钮按下当作已选页签。

## 验证

来源构建固定在 `rewrite/native-wayland` 的成功提交。正式资产直接复用该次远程构建
归档，不以发布任务重新编译的文件替换。来源、任务、产物编号和 SHA-256 见随附的
`native-preview-verification.json`。

- 799 项 Rust 测试和 154 项 Python 测试通过，格式、严格 Clippy、验证工具检查通过。
- 36 个实际 Qt 控件场景重新采集后与冻结记录一致，原生测试逐事件回放其中十三组序列。
- 同一下载二进制通过私有 niri/Sway 的十六组回归，包括按钮释放、输入法、原文菜单、
  注释候选隔离、光标局部重绘、历史窗口和确认对话框。
- 按钮回归检查按下中间状态、移出释放、右键焦点、Return、Ctrl+Space、修饰键 Escape、
  关闭释放和退出后的持久剪贴板；静止窗口保持单线程，观察期间 CPU 计数不增加。
- 预览版 5 在新增回归中复现按下即复制，失败证据保留。旧标签与资产不修改。
- 测试不启动 OCR 模型，不修改用户配置，也不修改原版 Qt 源码。

## 运行

仅提供 Linux x86_64 原生 Wayland 预览产物，基于 Ubuntu 24.04 构建，要求 glibc 2.39
或更新版本。解压后运行 `mark-shot-native/mark-shot --help` 查看入口。
首次使用 OCR 时通过应用内下载引导获取模型；本轮不重复执行真实模型识别。
运行依赖不包含 Qt、GTK 或网页视图。

## 未完成范围

本版不代表原版重写已经完成。OCR 窗口仍需补齐单行标题栏、图标、翻译、更多操作、
独立置顶入口、原文复制绑定、完整焦点遍历、反馈计时及逐像素对照。现有复制按钮在
原图与表格页面的绑定尚未完全沿用 Qt 标题栏的原文复制职责。

历史窗口全部提示与滚动细节、主题和中文界面、输入法与合成器完整矩阵，以及设置、
上传、扩展、托盘和配置迁移仍未完成。多设备混合按键和真实 Fcitx/IBus 未全面验证。
niri 菜单关闭后的首次移动差异仍保留，不补发移动事件掩盖。
扫码、录像暂不实现；原版 Qt 稳定版本保持最新正式版地位。
