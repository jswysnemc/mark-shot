# Mark Shot 原生 Wayland 预览版 2

本版继续 Rust 原生重写，重点增加独立 OCR 原文与已开启编辑的表格单元格输入法。
完整重写尚未完成，不替代 Mark Shot Qt 稳定版，不更新 Latest，也不进入原版发行渠道。

## 本版改动

- OCR 结果窗口接入 Wayland text-input-v3，原文、单元格、按钮、菜单和原图保持输入资格隔离
- 候选仅用于显示，不进入原文复制、局部历史或表格持久数据
- 多行确认独立撤销，单行连续确认合并撤销，对照真实 Qt 编辑器状态
- 表格单击选择，双击、F2 或普通键入开启编辑；提交才写回，Escape 丢弃草稿
- Ctrl+Shift+C 始终复制 OCR 原文，表格 TSV、CSV、Markdown、HTML 通过格式菜单复制
- 合法 UTF-8 周边正文最多 4000 字节，过期目标与非法删除批次整体拒绝
- 版本化发布证据保留旧清单，公开资产采用固定名称，禁止覆盖已公开版本

## 构建与验证

仅提供 Linux Wayland x86_64 归档，使用 Ubuntu 24.04 构建，最低 glibc 为 2.39。
程序需要 Wayland、xkbcommon、PipeWire 和 Fontconfig 运行库，不依赖 Qt、GTK 或 WebView。
归档包含可执行文件、来源提交、依赖许可、帮助输出及兼容性文档。

远程构建的 764 项 Rust 测试通过，10 项忽略；146 项 Python 测试通过。
格式、所有目标与功能的严格 Clippy、验证脚本导入检查、发布编译和许可检查通过。
实际发布归档经过校验并解包；同一下载二进制在私有 niri、Sway 会话完成：

- 截图 layer/window 四组共 21 个原生输入场景，候选不进入最终导出，导出与基准逐像素一致
- 两组截图文字光标回归，提交结束后停止周期重绘
- 两组 OCR 窗口输入法场景，验证候选字形、复制隔离、确认历史、扩展汉字替换、非法批次画面不变及切页停用
- 单元格提交与取消、原文快捷键和 TSV 菜单，静止窗口单线程、CPU 时钟增量为零且无新表面请求
- OCR 缓存识别、首次下载引导、表格识别、结果编辑、关闭与剪贴板交接

公开 `native-preview-verification.json` 固定来源任务、归档和二进制指纹、场景证据摘要
及未完成范围；不能用本地编译的画面证据代替下载二进制。

## 已知差异

- 未编辑单元格首次直接开始 CJK 输入仍待验证；本版原生输入资格仅在单元格编辑器开启后启用
- 完整焦点遍历、独立窗口光标闪烁、OCR 正文右键菜单及表格多选、几何仍未完成
- 历史窗口多出的搜索与数量输入框偏离原版，仍待修正
- 全 Unicode、Bidi、Qt 逐像素一致、Fcitx/IBus、完整合成器与多输出矩阵、大文档活动候选资源尚未全面验证
- niri 菜单关闭后的首次移动偏差仍保留，原版 Qt 同样复现，没有补发移动掩盖
- 亮色主题、完整设置、翻译、上传、扩展、托盘、配置迁移及其他原版兼容性工作继续保留
- 二维码扫描和录像不在本次重写范围内

详细状态见归档中的 `docs/rewrite-status.md` 与 `docs/window-input-method-compatibility.md`。
