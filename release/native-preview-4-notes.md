# Mark Shot 原生 Wayland 预览版 4

本版将历史清空确认替换为同进程独立模态窗口，并修正真实 Qt 按钮的焦点与修饰键行为。
完整 Rust 重写尚未完成，不替代 Mark Shot Qt 稳定版，不更新 Latest，也不进入原版发行渠道。

## 本版改动

- 清空确认使用独立 xdg-toplevel，在首次提交前建立原生父子关系，不再绘制历史窗口内覆盖层
- 默认尺寸 315×96、最小 223×77，正文和两按钮矩形对照真实 Qt，不加入额外内部标题或图标
- Cancel 初始获得焦点；默认 Enter、Escape 和窗口管理器关闭均取消，明确确认后才删除记录
- 右键按钮取得焦点但不执行；左键或 Space 按下保留记录，释放才执行，外部释放取消该次事务
- Enter 和 Space 保留 Ctrl、Alt、Shift 等修饰键行为；带修饰键的 Escape 不关闭对话框
- 父子窗口共用连接、进程和内存分配器，各自维护缩放、缓冲和帧回调，不增加驻留工作线程
- 模态期间隔离父窗口键盘、指针和输入法；关闭子窗口只回传一次结果，关闭父窗口回收子窗口
- 旧对话框身份和输入批次不能作用于新窗口；原图、目录身份、无关文件及配置保留规则不变
- 发布清单增加同指纹独立确认回归要求，旧预览版标签、清单和公开资产保持不变

## 构建与验证

仅提供 Linux Wayland x86_64 归档，使用 Ubuntu 24.04 构建，最低 glibc 为 2.39。
程序需要 Wayland、xkbcommon、PipeWire 和 Fontconfig 运行库，不依赖 Qt、GTK 或 WebView。
归档包含可执行文件、来源提交、依赖许可、帮助输出及兼容性文档。

远程构建的 783 项 Rust 测试通过，10 项忽略；148 项 Python 测试通过。
格式、所有目标与功能的严格 Clippy、验证脚本导入检查、发布编译和许可检查通过。
发布只使用成功远程构建的固定归档，不重新打包或以本地构建替代。该下载二进制验证十二组私有桌面回归：

- niri、Sway 截图 layer/window 四组共 21 个原生输入场景，候选不进入导出，原图与基准逐像素一致
- 两组文字光标回归，提交结束后停止周期重绘，验证窄区域损坏提交及 niri 失焦暂停
- 两组 OCR 结果窗口输入法回归，原文与单元格候选、复制、撤销和表格提交相互隔离
- 三组历史流程、长图及鼠标回归，保留原图 RGBA、IDAT、保存快照、配置策略、分隔和滚动断言
- 一组独立确认回归，验证同进程父子关系、默认及修饰键取消、右键不执行、外部释放取消和 Ctrl+Space 释放确认
- 父窗口复制、删除隔离与父窗口关闭回收子窗口，合法损坏记录清理，无关文件、链接和已保存原图保留
- 历史及静止 OCR 窗口采样为单线程，空闲 CPU 时钟增量为零

Qt 6.12.0 探针只读链接当前原版对象，使用 QtTest 官方鼠标事件取得三十组清空对话框
状态；窗口尺寸、正文、按钮、焦点、Enter、Escape、Space、修饰键和文件结果执行对照。
原始来源、归档和二进制摘要及回归摘要见公开资产 `native-preview-verification.json`。

## 已知差异

- 该 niri 会话未提供 xdg-dialog 管理器；本版验证原生父子关系和客户端模态隔离，不宣称模态提示分支已经验证
- 窗口系统装饰、全部主题和语言、全部焦点信号及 Qt 全像素比较仍未完成
- 历史完整提示框、长状态和空预览换行、精确 Qt 滚轮与翻页、增量缓存仍未完成
- OCR 未编辑单元格首次 CJK 输入、完整焦点遍历、窗口光标闪烁、正文右键菜单和表格多选仍未完成
- 完整 Unicode、Bidi、Fcitx/IBus、完整合成器与多输出矩阵及活动大文档资源尚未全面验证
- 亮色主题、完整设置、翻译、上传、扩展、托盘、配置迁移及其他原版兼容性工作仍保留
- 此前 niri 菜单关闭后的首次移动偏差仍为已知差异，本版不宣称修复
- OCR 窗口回归使用固定识别结果，不将其表述为模型下载或真实 OCR 的新验证
- 二维码扫描和录像不在本次重写范围内

详细证据与边界见归档中的 `docs/history-clear-dialog.md`、`docs/history-window-reference.md`
和 `docs/window-input-method-compatibility.md`。
