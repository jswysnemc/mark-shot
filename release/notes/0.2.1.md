## Mark Shot 0.2.1

本版本新增开机启动设置、Windows Setup 安装包和 Rust 原生版本的 Nix 构建，并收录 0.2.0 发布后的桌面兼容性、安装包及界面修复。

### 设置与桌面集成

- 在“设置 → 外观”中新增“开机启动”，默认关闭。Linux 使用当前用户的 XDG 自动启动文件，Windows 使用当前用户的 Run 注册表项。
- 启动项保留独立配置路径，并在程序位置变化后同步。AppImage 引用原始镜像路径；Flatpak 暂不支持此选项。
- 托盘菜单新增更多延时截图预设，录制支持可选常驻控制面板。
- 优化设置按钮与操作布局，完善历史记录重新选择区域、剪贴板贴图和工具栏提示。

### Windows 与 Nix 分发

- Windows 同时提供 ZIP 便携包和 Setup 安装包。Setup 安装到当前用户目录，包含媒体库和资源，并创建程序与设置的开始菜单入口。
- 安装包执行静默安装、文件摘要、启动和卸载检查。卸载保留用户配置，仅删除指向本安装目录的开机启动项。
- 将 `qt-old` 的 Nix 构建迁移到当前 Rust 版本，保留软件包和开发环境入口，支持 Linux x86_64 与 ARM64。
- Nix 固定 Rust 工具链、Cargo 依赖和媒体源码，包含桌面文件、依赖版权通知、媒体库及对应源码，并验证工作区测试、编码导出和安装内容。

### 兼容性与编辑修复

- 修复 Linux Mint/Cinnamon X11 中截图选区跟随光标迟缓的问题（[#164](https://github.com/jswysnemc/mark-shot/issues/164)），合并重复指针移动事件，并统一缩放与原生像素处理。
- 修复 RPM 构建目录冲突和陈旧产物混入。Fedora 软件包使用 Fedora 43 构建基线和 OpenSSL 3，并在发布前验证共享库要求。
- 修复 X11/Xwayland 剪贴板图像传输中的非阻塞文件描述符问题，完善桌面捕获与后台服务回归验证。
- 增加直接箭头样式，改进箭头头部比例、形状边缘与扩散阴影；修复阴影瓦片一致性和清空标注后的重绘。
- 改进滤镜焦点效果、Windows 控件选择层级，以及 Windows 字体元数据复用。

### English

Mark Shot 0.2.1 adds login startup preferences, a Windows Setup installer and Nix builds for the native Rust application. It also includes desktop, packaging and editing fixes merged after 0.2.0.

- **Desktop preferences:** Add an opt-in launch-at-login control under Settings → Appearance. Linux uses a user XDG autostart entry; Windows uses the current user's Run registry key. AppImage entries use the persistent image path. Flatpak does not currently support this option.
- **Desktop controls:** Add delayed screenshot presets, an optional persistent recording panel, toolbar tooltips, history region reselection and clipboard pinning improvements.
- **Windows installer:** Ship both a portable ZIP and Setup. The installer includes runtime resources and Start menu entries. Installation, hashes, startup and uninstall are checked; uninstall preserves preferences and removes only startup registration owned by that installation.
- **Nix migration:** Build the native Rust application on Linux x86_64 and ARM64 with a pinned compiler, Cargo dependencies and media sources. The package includes desktop resources, license notices and the replaceable media library with matching sources. Flake checks cover workspace tests, software encoding/export and installed-package contracts.
- **Compatibility:** Fix slow pointer-following capture selection on Linux Mint/Cinnamon X11 ([#164](https://github.com/jswysnemc/mark-shot/issues/164)) by coalescing pointer motion and using consistent scaling and native pixels. Improve Wayland process detection and X11/Xwayland nonblocking clipboard descriptors. Fedora packages use a Fedora 43/OpenSSL 3 baseline with dependency validation, and RPM builds no longer reuse stale workspaces.
- **Editing:** Add direct arrow heads and refine arrows, shapes, diffuse shadows, filter focus effects, Windows control selection and font metadata reuse. Fix stale shadow tiles and redraw after clearing annotations.
