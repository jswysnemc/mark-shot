## Mark Shot 0.2.0

Mark Shot 0.2.0 正式发布。本版本是项目自立项以来的里程碑升级，完成了从早期 C++/Qt 6 架构向 100% 纯原生 Rust 的整体重写，彻底剥离了对 C++ 工具链与 Qt 6 庞大图形库的运行时依赖。0.1.x 版本的 Qt 源码已归档至 `qt-old` 分支。

新版本内置基于 tiny-skia 与 cosmic-text 的轻量化软件渲染引擎，针对 Linux（Wayland、X11）与 Windows 提供原生底层后端，在降低资源消耗与安装包体积的同时，实现了屏幕截图、图像标注、桌面贴图、离线文字识别、多服务翻译、全功能屏幕录制及系统集成的全链路原生化。

### 核心架构与性能革新

- **纯原生 Rust 架构**：全仓采用 Rust 编写，构建配置与代码逻辑彻底解耦 Qt 与 CMake 工具链。
- **自研轻量级软件渲染器**：直接在共享内存缓冲（SHM）完成像素合成与矢量绘制，无 GPU 运行时强依赖；采用分层渲染与脏矩形局部刷新机制，仅重绘变化区域，界面空闲时事件循环完全阻塞等待，消除后台资源开销。
- **单二进制多进程微架构**：单一可执行文件通过受控参数按需派生贴图、剪贴板持久化、文字识别推理、结果交互、截图历史、配置管理及屏幕录制等独立子进程。窗口关闭即可完全释放对应堆内存与模型资源。

### 全平台原生后端驱动

- **Wayland (wlroots / niri / Sway)**：
  - 支持 `ext-image-copy-capture` 与 `wlr-screencopy` 高性能屏幕捕获；
  - 默认采用 `wlr-layer-shell` 协议构建全屏覆盖层；
  - 深度集成 niri 与 Sway 原生 IPC 接口，提供精确的窗口边界自动吸附与活动窗口截图；
  - 原生适配 `text-input-v3` 输入法协议与 `wlr-data-control` 剪贴板协议。
- **Wayland (KDE Plasma)**：
  - 集成 KWin ScreenShot2 原生快照通道，支持透明回退至桌面门户；
  - 引入原生窗口几何快照机制，支持可见窗口识别、层叠顺序解析与最小化窗口过滤；
  - 修正首帧预读跨异步运行时总线交接及共享缓冲回收映射复用问题。
- **Wayland (GNOME)**：
  - 基于 XDG Desktop Portal 与 PipeWire 实现受控屏幕捕获；
  - 借助 Xwayland 选择区协议与增量传输（INCR）稳定处理跨端大图数据。
- **Linux X11**：
  - 基于 XGetImage 与 RandR 实现物理像素级截屏，通过 EWMH 协议支持窗口自动吸附；
  - 通过 XFixes 协议协商实现光标形状与位置捕获；
  - 重构 X11/Xwayland 剪贴板增量分块传输机制，解决超大 PNG 图像在部分合成器下传输中断的问题；
  - 原生支持 XIM 输入法与原生窗口置顶。
- **Windows (x86_64)**：
  - 基于 Win32 GDI 实现屏幕采集，基于原生 Win32 消息循环构建覆盖层与无边框贴图窗口；
  - 结合 DWM 扩展边框与 Windows UI Automation 异步控件树实现窗口边缘吸附；
  - 原生支持系统剪贴板（PNG、DIBV5、Unicode 文本）。

### 屏幕录制系统

- **原生录屏引擎**：集成独立的 `crates/shot-media` 录制模块，支持 Linux 与 Windows 双平台。
- **交互与控制面板**：录制作为常规工具复用既有选区，提供紧凑型浮动参数栏，支持实时调节录制格式（MP4、MKV、GIF）、帧率、倒计时、系统音频/麦克风源、编码画质、软硬件编码器及光标捕获开关。
- **操作稳定性**：采用显式点击确认启动机制，防止误触启动采集；支持录制中途暂停与继续，并在停止录制后平滑调度后台导出任务。

### 标注与编辑体验重塑

- **外扩选中边界**：矩形、椭圆与形状标记的选中控制框向外留白，避免控制边框遮挡原始标注的线条粗细与描边色彩，缩放控制锚定正文边界。
- **贴图编辑整合**：贴图编辑界面重塑为紧凑的单行工具栏，右侧统一收拢最小化、最大化和关闭控制；进入编辑模式时自动隐藏来源贴图，退出后自动无损恢复。
- **高精度放大镜**：设计紧凑型取色放大镜，实时展示像素网格放大与 HEX / RGB 原始数值读数。
- **矢量标注精细化**：优化抗锯齿经典箭头、自由画笔、荧光笔、几何图形、马赛克/模糊、标尺测量（含角度模式与旋转吸附）及多级序号渲染。
- **文本输入增强**：文字标注支持行内自适应排版、字号滚轮调节与原生候选词交互。

### 文字识别 (OCR) 与智能翻译

- **本地离线 OCR**：原生接入 PP-OCRv5 模型与推理引擎，支持 SIMD 指令集加速，按需加载，无需配置 Python 环境。
- **结果编辑与结构化导出**：提供专用结果查看与编辑窗口，支持表格结构化识别，并支持一键导出为 TSV、CSV、Markdown 与 HTML 格式。
- **多通道翻译接入**：支持 Bilibili Index-Translate、OpenAI、Anthropic Claude、Google Gemini、腾讯翻译君、百度翻译、有道翻译及自定义外部命令行管道。
- **全平台输入法整合**：结果编辑窗口与标注文字输入深度适配 Wayland text-input-v3、X11 XIM 及 Windows IME。

### 设置中心与桌面集成

- **原生设置面板**：提供直观的配置管理中心，展示有效工具链、调色板及存储路径；采用干净的增量持久化策略，未修改的字段不向磁盘覆盖写入，保障配置文件可维护性。
- **交互过渡保护**：从截图侧栏唤起设置中心时，系统优先关闭截屏遮罩与活动选区，平滑展现设置界面。
- **系统托盘与全局快捷键**：全面打通系统托盘菜单，支持快速触发截图、录屏与退出；完善桌面门户快捷键空绑定检测与恢复机制，杜绝误报注册成功。

### 自动化验证与工程分发

- **虚拟机矩阵验证**：构建覆盖 KDE Plasma (Wayland)、GNOME (Wayland) 以及 Xfce (原生 X11) 的自动化虚拟机回归套件，全量通过包含 17 项端到端流程、X11 故障注入与恢复、320×512 像素级长截图拼接校验，以及 1233 项单元与集成测试。
- **全平台分发矩阵**：
  - Debian / Ubuntu：提供针对 Debian 13、Ubuntu 24.04、Ubuntu 26.04 等发行版的 amd64 与 arm64 `.deb` 安装包；
  - Fedora：提供 aarch64 与 x86_64 的 `.rpm` 与 `.src.rpm` 软件包；
  - Arch Linux：提供 AUR 原生二进制包 `.pkg.tar.zst`；
  - 通用便携包：提供独立 AppImage、Flatpak 以及跨发行版 tar.gz 归档；
  - Windows：提供包含专用媒体运行时的 x86_64 MSVC 便携归档。
- **内联安全校验**：所有正式构件均在发布页面内嵌显示完整 SHA-256 校验和，无需下载外部摘要文件。

### 平台适用范围与已知限制

- GNOME Wayland 环境暂不支持窗口几何探测，区域识别与常规截图可用。
- Windows 版本已具备全套原生能力，但在混合 DPI 及部分特定输入法环境下仍建议作为实验性支持使用。
- 自动化虚拟机验证基于单屏、100% 缩放与软件编码环境，尚未完全覆盖复杂物理多屏混合缩放、独立硬件编解码加速及外部云服务异常情况。macOS 暂不提供支持。
- 在最小化 Debian / Ubuntu 编译环境中运行测试套件时，需预先安装 `dbus-daemon`，用于支撑 KDE 私有总线隔离回归测试。

### English

Mark Shot 0.2.0 is the official release marking the complete migration of the project from the legacy C++/Qt 6 architecture to 100% native Rust. All runtime dependencies on the C++ toolchain and Qt 6 GUI libraries have been eliminated. The legacy Qt codebase has been archived in the `qt-old` branch.

Powered by an in-house software rendering engine built upon tiny-skia and cosmic-text, this release provides native platform backends for Linux (Wayland, X11) and Windows (x86_64). It delivers native screenshot capture, annotation, desktop pinning, offline OCR, translation pipelines, full-featured screen recording, and desktop system integration with lower memory overhead and reduced package footprints.

#### Core Architecture & Rendering

- **Pure Native Rust**: The entire codebase and build system are written in Rust (Rust 2024 / 1.95+), completely removing C++, Qt, and CMake toolchain dependencies.
- **Lightweight Software Renderer**: Pixels and vector paths are rendered directly to shared memory buffers via tiny-skia and cosmic-text without requiring GPU runtimes. Layered rendering combined with dirty-rect updates repaints only changed areas. The event loop blocks cleanly when idle, eliminating background CPU usage.
- **Single-Binary, Multi-Process Model**: A single executable launches isolated child processes on demand for pinned overlays, clipboard serving, OCR engine inference, inspection windows, capture history, configuration, and screen recording. Closing an editing surface releases associated heap allocations and ONNX models immediately.

#### Platform Backends

- **Wayland (wlroots / niri / Sway)**:
  - High-performance capture via `ext-image-copy-capture` and `wlr-screencopy`;
  - Fullscreen capture overlays driven by `wlr-layer-shell`;
  - Accurate window boundary snapping and active-window capture via niri and Sway IPC;
  - Native `text-input-v3` input method protocol and `wlr-data-control` clipboard support.
- **Wayland (KDE Plasma)**:
  - Native KWin ScreenShot2 capture integration with transparent fallback to XDG Desktop Portal;
  - Native window snapshot mechanics supporting visible boundary detection, z-order sorting, and minimized window filtering;
  - Fixed pre-read bus handoff across asynchronous runtimes and shared memory buffer reuse regressions.
- **Wayland (GNOME)**:
  - Screen capture through XDG Desktop Portal and PipeWire streams;
  - Reliable large image delivery through Xwayland incremental (INCR) clipboard transfers.
- **Linux X11**:
  - Direct capture via XGetImage and RandR with physical pixel accuracy; EWMH-assisted window snapping;
  - Cursor shape and position tracking with XFixes version negotiation;
  - Rewritten clipboard streaming logic to prevent large PNG truncation on various window managers;
  - Native XIM support and window elevation (`_NET_WM_STATE_ABOVE`).
- **Windows (x86_64)**:
  - Native Win32 GDI capture and message loop driving borderless pinned surfaces;
  - Window snapping using DWM extended frame boundaries and asynchronous UI Automation tree queries;
  - Native Windows clipboard integration (PNG, DIBV5, and Unicode text).

#### Screen Recording

- **In-Process Media Library**: Powered by `crates/shot-media` on both Linux and Windows.
- **Controls & Formats**: Reuses the active selection box with a compact floating toolbar. Supports format switching (MP4, MKV, GIF), framerate, countdown delays, system audio/microphone capture, encoding quality presets, encoder selection, and cursor toggles.
- **Explicit Workflow**: Requires an explicit start trigger to prevent accidental captures. Supports in-flight pause/resume and non-blocking asynchronous export upon completion.

#### Annotation & Interaction Refinements

- **Outset Selection Frames**: Transform frames for rectangles, ellipses, and shape markers expand outward, leaving stroke widths and boundary colors fully visible while anchoring scaling to content margins.
- **Consolidated Pinned Editing**: Pinned image editing utilizes a unified single-line toolbar with integrated minimize, maximize, and close controls. Source stickers hide upon entering edit mode and restore cleanly on exit.
- **Compact Sampling Magnifier**: Redesigned loupe displaying zoomed pixel grids alongside real-time HEX and RGB color values.
- **Vector Annotation Polish**: Refined anti-aliased arrows, freehand pens, highlighters, geometric shapes, blur/pixelate tools, multi-level counter badges, and ruler measurement with angle snapping.
- **Text Formatting**: Text boxes feature adaptive dimensions, mouse-wheel font size adjustments, and inline candidate handling.

#### OCR & Translation Ecosystem

- **Local Offline OCR**: Built-in PP-OCRv5 engine accelerated via SIMD without requiring external Python environments.
- **Structured Inspection**: Dedicated results window supporting table structure recognition with direct export to TSV, CSV, Markdown, and HTML.
- **Multi-Provider Translation**: Integrated support for Bilibili Index-Translate, OpenAI, Anthropic Claude, Google Gemini, Tencent, Baidu, Youdao, and custom command-line pipes.
- **Input Method Integration**: Full IME compatibility across Wayland text-input-v3, X11 XIM, and Windows IME within both the OCR editor and text annotations.

#### Configuration & Desktop Integration

- **Native Settings Dialog**: Clear presentation of effective tool setups, color palettes, and target directories with a clean sparse-override persistence model.
- **Seamless Modal Transitions**: Opening settings from the capture sidebar dismisses the screen mask and active selection prior to displaying the configuration interface.
- **System Tray & Global Hotkeys**: Native system tray with quick triggers for capture, recording, and exit. Portal global shortcut handlers properly surface empty bindings and prevent false registration claims.

#### Verification & Packaging Matrix

- **Virtual Machine Verification**: Validated through an automated suite across KDE Plasma (Wayland), GNOME (Wayland), and Xfce (Native X11) covering 17 end-to-end workflows, X11 server fault injection recoveries, 320x512 pixel-exact scrolling stitches, and 1,233 passing unit and integration tests.
- **Distribution Packages**:
  - Debian / Ubuntu: Native `.deb` packages for Debian 13, Ubuntu 24.04, and Ubuntu 26.04 on amd64 and arm64;
  - Fedora: `.rpm` and `.src.rpm` packages for x86_64 and aarch64;
  - Arch Linux: AUR binary archives (`.pkg.tar.zst`);
  - Portable Linux: Standalone AppImage, Flatpak, and tar.gz distributions;
  - Windows: x86_64 MSVC standalone zip archives bundled with runtime media libraries.
- **Inline Checksums**: Release assets are verified against full SHA-256 digests displayed directly on the release page.

#### Platform Boundaries & Notes

- Window boundary detection on GNOME Wayland is currently unavailable; regional recognition and manual capture remain functional.
- The Windows port is feature-complete but remains classified as experimental pending further testing on diverse multi-DPI hardware.
- Automated testing covers single-screen configurations at 100% scale using software encoding. Multi-monitor setups with fractional scaling, dedicated hardware encoders, and external web APIs remain subject to local validation. macOS is not supported.
- Minimal Debian/Ubuntu build environments require `dbus-daemon` to execute the isolated KDE private bus regression tests.
