## Mark Shot 0.2.5

本版本为长度尺子新增简约双头箭头样式，完善置顶贴图的缩放倍率与操作微反馈提示，并修复 Wayland 门户截屏/录屏、旧版开机启动项迁移及 Windows 后台待命进程回收问题。

### 标注与尺子

- 长度尺子新增“箭头样式”开关（`[tools.ruler].style = "simple"`）：启用后以两端实心双头箭头呈现，并在主轴居中直接显示像素跨度（如 `240px`），不再额外弹出浮动详情卡片；跨度较短时自动将数值抬至箭头外侧避免遮挡。
- 支持在属性栏切换默认样式与已选中尺子的样式，并持久化至配置与工具状态。

### 置顶贴图体验

- 拖动边缘或角缩放、滚轮缩放以及右键菜单缩放/重置贴图时，在左上角短暂显示当前缩放倍率（`100%` 表示原始逻辑尺寸）。
- 优化滚轮缩放步进吸附：在接近原始尺寸（`100%` 附近 20% 范围内）跨越 `100%` 时精确吸附回 `100%`，避免小数舍入跳过原尺寸，同时不影响大跨度缩放。
- Wayland 置顶贴图补充操作与识别状态微提示胶囊，涵盖复制图片、复制文字、顺逆时针旋转 90°、置顶开关、划词选字开关、原文/译文视图切换以及未识别到文字提示。

### 桌面集成、门户与平台修复

- Wayland 桌面门户截屏在 PipeWire 流连接阶段显式协商 `SPA_PARAM_Buffers` 共享内存参数（支持 `MemFd` 与 `MemPtr`），避免部分合成器或门户等待缓冲协商导致首帧超时。
- 门户录屏在已有视频帧后若桌面授权关闭，能够正常结束并完成封装保存，不再被阻塞或误报失败；同时后台启动不再主动弹出系统全局快捷键配置窗口。
- 兼容旧版 Qt 时代残留的 `--tray` 启动参数并转入后台常驻服务，开启开机自启动时自动迁移并清理旧的 `--tray` 自启动项。
- Windows 托盘菜单退出后台服务时，立即终止并回收正在准备或挂起的待命截图子进程，避免残留进程。

### English

Mark Shot 0.2.5 adds a simple double-headed arrow style for length rulers, enhances pinned image zoom feedback and Wayland status capsules, and fixes Wayland portal buffer/recording handling, legacy autostart migration, and Windows standby worker cleanup.

- **Ruler annotations:** Add a **Simple** double-headed arrow style (`Arrow style` toggle in the property bar and `[tools.ruler].style`) for length measurements. It renders the pixel span inline at the center of the arrow without a separate floating detail card, and lifts the label outside when the span is too short.
- **Pinned images:** Display the current zoom percentage HUD in the top-left corner while dragging edges/corners, scrolling the wheel, or zooming/resetting from the menu. Snap wheel zoom steps crossing `100%` within 20% of the original size cleanly back to `100%`. Add Wayland status capsules for copying images or text, 90-degree rotation, always-on-top toggles, text selection mode, translation view toggles, and empty OCR results.
- **Wayland, desktop integration, and Windows:** Explicitly negotiate PipeWire `SPA_PARAM_Buffers` (`MemFd` and `MemPtr`) during Wayland portal capture to prevent first-frame timeouts. Finish portal recordings cleanly when authorization closes after frames have been captured, and avoid popping up the system global shortcut configuration dialog during background startup. Support the legacy `--tray` flag and migrate old Qt `--tray` autostart entries. Terminate and reap standby capture workers immediately when exiting from the Windows tray menu.
