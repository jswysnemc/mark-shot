## Mark Shot 0.2.4

本版本优化 KDE Plasma (Wayland) 下置顶贴图的移动响应，支持遵循 Linux 系统的 Fontconfig 默认无衬线字体及渲染微调规则，改善滚动长截图在跨应用拼接与文本抗锯齿过渡时的匹配精度，并支持剪贴板 HTML/RTF 富文本及表格贴图。

### 置顶贴图与桌面交互

- KDE Plasma (Wayland) 环境下重构置顶贴图的缓冲复用逻辑：在 2560×1600 分辨率贴图测试中，移动帧间隔中位数由约 26.6ms 缩短至约 13.3ms；原图复用同时改善了贴图缩放过程中的重绘开销。
- 保持基于 `wlr-layer-shell` 的置顶层级，超长图或超大尺寸贴图保留既有软件渲染路径，避免极端尺寸显示异常。
- 修复捕获租约监听器把文件读取事件当作变化，造成空闲反复唤醒的问题。
- 置顶贴图的原图复制、旋转与置顶状态切换已完成实机验证。
- 贴图支持从剪贴板读取并呈现 HTML 与 RTF 富文本内容：保留文本颜色、段落对齐方式与表格轮廓；可读本地图片正常显示，网络或无法读取的图片显示为带标签占位框。

### 界面字体与系统集成

- Linux 界面控件（设置窗口、提示浮层、OCR 与翻译面板、贴图右键菜单等）优先遵循 Fontconfig 匹配系统默认 sans-serif 字体，不再将界面固定为 Inter。该匹配遵循 Fontconfig 规则，不保证与 KDE 或 GNOME 独立保存的桌面 UI 字体一致；特定控件保留明确指定的字体（如 OCR 表格头固定使用 DejaVu Sans）。
- 读取并应用 Fontconfig 中的抗锯齿（Antialias）、字形微调（Hinting / Hintstyle）、自动微调（Autohint）、子像素排布（RGBA）、LCD 滤镜（LCDFilter）与内嵌点阵（Embeddedbitmap）规则。
- 优化半透明背景下的文本渲染，半透明区域采用灰度抗锯齿，减轻次像素彩色杂边。
- 截图标注工具内的文本添加与导出保留独立排版路径；系统未提供合适字体时回退至内置 Inter。
- 复用现有字体映射并限制字形缓存大小。修改系统 Fontconfig 规则后需重启应用程序（含常驻托盘与后台待命进程）以重新加载。

### 截图与长截图拼接

- 优化滚动长截图在浏览器滚动及文本抗锯齿设置过渡时的图像锚点对齐，减少连续滚动拼接处的错位。
- 改善长截图在稀疏内容、固定顶部导航栏以及动态列表场景下的接缝识别与拼接容错。
- 对齐选区快捷键行为，支持使用 `Ctrl+A` 选中等同于中键全屏选取的范围。

### 平台与体验细节

- KDE 环境新增活动窗口截图快捷键支持，并校正托盘与窗口图标关联。
- 优化 Windows 后台辅助进程启动交互，抑制后台初始化过程中的系统光标闪烁。
- 避免截屏与录制提示信息进入 Linux 录屏画面。

### English

Mark Shot 0.2.4 improves pinned image movement responsiveness on KDE Plasma (Wayland), honors Linux Fontconfig default sans-serif font choices and rendering rules, refines scrolling screenshot stitching across font rendering transitions, and adds clipboard rich text and table pinning.

- **Pinned image and desktop interaction:** Overhaul pinned image buffer reuse on KDE Plasma (Wayland). In benchmark tests with a 2560x1600 pinned image, the median frame interval during window movement dropped from ~26.6ms to ~13.3ms, while buffer reuse also reduces redraw overhead during scaling. Retain `wlr-layer-shell` overlay semantics and keep the software fallback path for oversized pins. Fix an idle wakeup loop where the capture lease listener treated file read events as changes. Verify image copying, rotation, and always-on-top toggles. Support pinning clipboard HTML and RTF formatted rich text with table outlines, aligning paragraphs, displaying readable local images, and showing placeholders for remote images.
- **Interface fonts and rendering:** Query Fontconfig for the default sans-serif font on Linux instead of fixing Inter across all UI elements. This query follows Fontconfig configuration and is not guaranteed to match desktop UI fonts stored independently by KDE or GNOME; controls with explicit font requirements retain their families (such as OCR table headers using DejaVu Sans). Honor font antialiasing, hinting style, autohint, subpixel layout, LCD filters, and embedded bitmaps. Apply grayscale antialiasing on translucent backgrounds to reduce color fringing. Keep canvas text annotation on an independent rendering path, and fall back to bundled Inter if system fonts are unavailable. Font changes take effect upon restarting the application, including any background standby processes.
- **Capture and scrolling stitching:** Improve scrolling screenshot anchor tracking across browser text rendering transitions, reducing seams during continuous scrolling. Strengthen stitch recovery across sparse content, fixed navigation bars, and updating list views. Align `Ctrl+A` selection scope with middle-click fullscreen capture.
- **Platform details:** Add active-window capture shortcut support and correct window icons on KDE. Suppress startup cursor flickering for Windows internal workers. Keep overlay notices out of Linux screen recordings.
