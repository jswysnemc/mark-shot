## Mark Shot 0.2.2

本版本新增文字识别下载镜像配置、截图起始界面精简开关、系统原生文件保存门户与双预览长截图面板，并包含输入法、Wayland 悬浮层拖动及桌面门户兼容性修复。

### 截图、长截图与桌面集成

- 新增 `[capture].show_start_bar` 与 `[capture].show_hints` 选项（默认开启），可在“设置 → 截图与标注”中分别隐藏顶部起始模式栏与左下角快捷键提示面板，支持直接拖选截图（[#165](https://github.com/jswysnemc/mark-shot/issues/165)、[#171](https://github.com/jswysnemc/mark-shot/issues/171)）。
- 截图编辑器与历史记录中的“另存为”改用系统原生文件对话框：Linux 使用 `org.freedesktop.portal.FileChooser` 门户，Windows 使用 `IFileSaveDialog`。
- 重构滚动长截图控制面板，采用无边框极简双预览布局并保留选区高亮框，同时在状态栏展示总长度与单次拼接新增像素读数。
- “打开方式”纳入标记 `NoDisplay=true` 但已注册图片 MIME 类型的桌面查看器（如 `imv`），仅过滤 `Hidden=true` 条目（[#174](https://github.com/jswysnemc/mark-shot/issues/174)）。

### 文字识别、输入法与诊断

- 新增 `[ocr].download_mirror` 与环境变量 `MARK_SHOT_OCR_MIRROR`，支持为 ONNX Runtime 及 PP-OCRv5 模型配置 HTTP/HTTPS GitHub 下载镜像前缀；镜像异常时自动回退直连 GitHub，并强制校验固定 SHA-256 摘要（[#171](https://github.com/jswysnemc/mark-shot/issues/171)）。
- 从“设置 → 文字识别 → 管理语言包与运行库”打开资源面板时保持窗口常驻，便于单次连续安装或卸载多个语言包（[#171](https://github.com/jswysnemc/mark-shot/issues/171)）。
- 为全部单行输入框（设置搜索、行内输入、可搜索下拉、翻译凭据、独立取色十六进制框）接入 Wayland `zwp_text_input_v3` 与 X11 `XIM` 预编辑及候选窗定位；修复 Wayland 初次提交前席位绑定、跨屏输出重映射与空文本光标矩形回退，并在 Layer 覆盖层文字编辑期间按需切换 `OnDemand` 键盘交互以兼容 Fcitx5（[#172](https://github.com/jswysnemc/mark-shot/issues/172)）。
- `--debug` 启动时向标准错误输出当前诊断日志路径，并将 `--debug`、`--no-debug`、`--debug-log` 覆盖参数传递给后台辅助进程（[#171](https://github.com/jswysnemc/mark-shot/issues/171)）。

### 标注与界面细节

- 多个“聚焦”与“椭圆聚焦”滤镜区域合并为统一遮罩，避免重叠或多选区重复叠加外围暗度。
- 重构辅助属性工具栏、下拉菜单悬停与选中项间距、颜色选择器滑块手柄与色板布局；新增画布及贴图滚轮缩放百分比徽标，并精修贴图识别、翻译与上传状态胶囊。
- 修复 Windows 分层圆角窗口外侧残留直角像素的问题。

### Wayland、门户与打包兼容

- 消除 Wayland `zwlr_layer_surface_v1` 悬浮录制控制面板拖动时的往返抖动与滞后：拖动期间保持抓取表面静止，通过穿透点击的帧节流预览层实时跟随指针，松开鼠标后一次性提交最终坐标（[#173](https://github.com/jswysnemc/mark-shot/issues/173)）。
- 桌面门户截图先完成 ScreenCast 授权再读取显示器列表以识别热插拔屏幕，自动丢弃失效恢复令牌重试，并保持输出流顺序一致（[#168](https://github.com/jswysnemc/mark-shot/pull/168)）。
- 修复沙箱、Flatpak 及门户环境下缺少 `zwp_linux_dmabuf` 或 `xdg-output` 时的 Wayland 截图与 `xdg_toplevel` 全屏覆盖层尺寸映射（[#167](https://github.com/jswysnemc/mark-shot/issues/167)、[#170](https://github.com/jswysnemc/mark-shot/issues/170)）。
- 修复 HiDPI 缩放屏幕下原生截图场景初始选区与窗口悬停候选框的物理像素换算偏差（[#169](https://github.com/jswysnemc/mark-shot/issues/169)）。
- AppImage 启动独立辅助进程时改用宿主机持久化 `$APPIMAGE` 镜像路径，避免主截图进程退出卸载临时 FUSE 挂载点后触发 `SIGBUS`（[#166](https://github.com/jswysnemc/mark-shot/issues/166)）。

### English

Mark Shot 0.2.2 adds configurable OCR download mirrors, capture startup UI toggles, native file-chooser save dialogs and a dual-preview scrolling capture panel, along with input method, Wayland layer-drag and desktop portal fixes.

- **Capture and desktop integration:** Add `[capture].show_start_bar` and `[capture].show_hints` switches in Settings → Capture ([#165](https://github.com/jswysnemc/mark-shot/issues/165), [#171](https://github.com/jswysnemc/mark-shot/issues/171)). Use native system save dialogs (`org.freedesktop.portal.FileChooser` on Linux and `IFileSaveDialog` on Windows) for Save as in the editor and history window. Redesign the scrolling-capture panel with borderless detail and overview dual previews, live `+px` stitch increments, and a preserved region outline. Include valid `NoDisplay=true` image viewers such as `imv` in Open with ([#174](https://github.com/jswysnemc/mark-shot/issues/174)).
- **OCR, input methods and diagnostics:** Add `[ocr].download_mirror` and `MARK_SHOT_OCR_MIRROR` for HTTP/HTTPS GitHub mirror acceleration with automatic direct-GitHub fallback and mandatory SHA-256 verification, and keep the OCR resource dialog open when launched from Settings ([#171](https://github.com/jswysnemc/mark-shot/issues/171)). Enable `zwp_text_input_v3` and `XIM` across all single-line UI fields, bind Wayland seats before first commit, remap multi-monitor outputs, and use `OnDemand` keyboard interactivity during Layer-overlay text editing for Fcitx5 ([#172](https://github.com/jswysnemc/mark-shot/issues/172)). Print the active log path on `--debug` and propagate logging flags to helper processes ([#171](https://github.com/jswysnemc/mark-shot/issues/171)).
- **Editing and interface:** Combine multiple Focus and Ellipse focus regions into one surround-dimming mask without stacking darkness. Refine secondary property bars, dropdown item spacing, color picker handles and swatches, status pills, wheel-zoom percentage badges, and Windows rounded-corner clipping.
- **Wayland, portal and AppImage compatibility:** Eliminate Wayland layer-surface drag oscillation on the floating recording panel via a frame-throttled click-through preview layer ([#173](https://github.com/jswysnemc/mark-shot/issues/173)). Authorize ScreenCast before enumerating hot-plugged monitors and retry stale restore tokens ([#168](https://github.com/jswysnemc/mark-shot/pull/168)). Fix sandboxed Wayland `xdg_toplevel` overlay sizing and fallbacks without `zwp_linux_dmabuf` or `xdg-output` ([#167](https://github.com/jswysnemc/mark-shot/issues/167), [#170](https://github.com/jswysnemc/mark-shot/issues/170)), HiDPI physical-pixel selection scaling ([#169](https://github.com/jswysnemc/mark-shot/issues/169)), and AppImage helper spawning via `$APPIMAGE` to avoid FUSE `SIGBUS` crashes ([#166](https://github.com/jswysnemc/mark-shot/issues/166)).
