## Mark Shot 0.2.6

本版本新增多选区透明裁切截图模式，优化尺子吸附、读数显示与取色标注体验，修复滚动长截图列表悬停偏移及 Wayland 门户截屏/录屏/快捷键兼容性问题，并实现稳定版本发布后自动同步更新 AUR 软件包。

### 多选区截图

- 顶部模式栏新增**多选区**入口：左键拖动添加矩形，右键拖动扣除矩形，区域间空白与内部孔洞均导出为透明像素。
- 支持 `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` 撤销与重做，按 `Enter` 或点击底部**进入编辑 (Enter)** 以原始物理分辨率交接至图片编辑器，也可直接使用复制、保存、贴图等快捷键导出。

### 尺子、选框、取色与滚动截图

- 尺子绘制与移动支持吸附至已识别界面区域边缘，标准长度尺属性栏新增可折叠的宽度、高度、对角线、面积读数开关并在选中时显示实际数值，同时优化标注选框与旋转交互。
- 取色器支持拖动已有取色标注的采样点重新取色，并在取色模式下通过 `Ctrl+C` 复制指针下方实时十六进制颜色值。
- 滚动长截图在存在列表项悬停高亮变化时保持稳定列锚点与重叠对齐，避免误判偏移。

### Wayland 门户、录屏与发布流程

- Wayland 门户截屏改为多显示器并发取帧，个别静止输出超时不再拖垮已成功输出；PipeWire 流在首帧等待窗口内自动重新激活以促使合成器补发首帧。
- 全局快捷键优先通过 `ListShortcuts` 核对已有登记，避免 KDE Plasma 6.3 等门户重复弹出系统快捷键设置窗口；门户录屏在桌面省略来源坐标时自动回退至逻辑/物理尺寸核对。
- DMA-BUF 显存录屏优先选用 `XR24`/`AR24`/`NV12` 格式并兼容旧 VAAPI 驱动回退，首帧显存导入失败时自动切换至 CPU 帧加硬件上传路径；修复编码器零帧退出或收尾时的崩溃风险。
- 稳定版发布工作流在 GitHub Release 公开后自动同步更新 AUR 的 `mark-shot` 与 `mark-shot-bin` 元数据。

### English

Mark Shot 0.2.6 introduces multi-region capture with transparent cutouts, refines ruler snapping, readouts, selection frames, eyedropper resampling, and scrolling stitch stability, hardens Wayland portal capture/hotkeys/recording paths, and automates stable AUR package publication.

- **Multi-region capture:** Select **Multi-region** in the top mode bar to add rectangles with left drag and subtract gaps or holes with right drag. Undo/redo with `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`, hand off the masked full-resolution composite to the editor with `Enter` or **Edit (Enter)**, or export directly with standard finish shortcuts.
- **Editor and scrolling capture:** Snap rulers to detected region edges while drawing or moving, toggle individual standard length readouts in a collapsible property bar group with live values when selected, drag existing eyedropper tips to resample pixels, and copy the live HEX colour under the pointer with `Ctrl+C`. Preserve scrolling screenshot overlap alignment across list hover highlights.
- **Wayland portals, recording, and releases:** Fetch multi-monitor portal frames concurrently with PipeWire stream reactivation on stalled first frames, inspect existing global shortcut registrations with `ListShortcuts` before binding to avoid repeated portal dialogs, and validate portal recording sources by logical/physical dimensions when coordinates are omitted. Prioritize compatible DMA-BUF formats with VAAPI fourcc and CPU-frame hardware-upload fallbacks, guard zero-frame encoder teardown, and automatically publish validated `mark-shot` and `mark-shot-bin` AUR packages after stable GitHub Releases.
