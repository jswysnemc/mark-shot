## Mark Shot 0.2.3

本版本新增尖尾与圆尾箭头样式选项及独立双箭头属性、荧光笔正片叠底混合与直线模式、文字工具聚焦虚线外框，全面修复 Windows 原生输入法上下文管理与飞书剪贴板位图兼容，并优化 Wayland 焦点策略、界面控件布局与窗口尺寸自适应。

### 标注工具与绘制体验

- 箭头工具新增“尖尾”（Sharp）与“圆尾”（Rounded）选项；双箭头改为独立复选属性，可与直箭头、实心三角、开口线及尖尾、圆尾自由组合。直箭头尖尾对齐 Qt 原版连续平滑多边形轮廓构造，彻底消除箭身与尾尖连接处的镂空与断口。
- 荧光笔按 Qt 原版重构为正片叠底（乘法混合）模式，真实呈现荧光马克笔透亮叠加质感；新增直线模式与自由绘制模式切换，并支持笔宽与模式的独立记忆。
- 文字工具聚焦输入时按 Qt 原版样式动态呈现青绿色虚线外框，支持缩放视图下的局部重绘刷新；虚线外框仅在编辑输入期间显示，失焦或提交后自动隐去，且不计入图片导出与缓存。

### 输入法与多平台兼容

- Windows 端重构原生输入法（IME）上下文生命周期管理，修复逻辑光标插入符定位、候选窗口位置跟随与系统光标隐藏逻辑；支持跨输入字段切换时输入上下文的独立隔离与状态恢复。
- Linux 端修复 Wayland 覆盖层点击文字工具后键盘焦点策略频繁切换导致的焦点死循环与输入法失焦问题；在独立会话中完成真实 Fcitx5 与 Rime 输入法的中文切换、候选词选择及连续输入验证。
- Windows 剪贴板发布兼容传统 DIB（Device Independent Bitmap）位图格式，解决截图复制后无法直接粘贴到飞书等第三方应用的问题。

### 界面交互与布局细节

- 截图与标注阶段快捷键提示面板与顶部模式栏在首次拖动选区时即刻隐藏，避免遮挡截取内容。
- 设置界面快捷键输入框在录入状态下自适应缩窄，将“恢复默认”与“清除”按钮独立置于右侧，避免按钮覆盖快捷键内容。
- 扫码识别窗口关闭按钮增加悬停（Hover）高亮反馈。
- OCR 引擎模型与语言包管理窗口统一界面风格与悬停样式，修复 Wayland 模态子窗口尺寸同步，展开详情时外层窗口自适应增高而非挤压内部内容。
- 滚动长截图控制面板预览重构：两处预览图改用直角边缘、小缩略图初始对齐底部，并为整体预览浮层增加 1px 细微边界线，防止在纯白背景下与底层混淆。

### 配置与状态持久化

- 修复 Windows 平台置顶贴图右键菜单选项（“拖选文字”、“窗口置顶”）以及标注阶段工具粗细未正确持久化的问题。
- 规范诊断日志默认路径，在 Windows 下平滑回退至本地数据目录（`data_local_dir`）。

### English

Mark Shot 0.2.3 adds sharp and rounded arrow tail options with an independent bidirectional arrow toggle, highlighter multiply blending with straight-line mode, dynamic dashed text editing frames, and comprehensive Windows IME and clipboard compatibility fixes.

- **Annotation tools and rendering:** Add sharp and rounded arrow tail options; bidirectional arrow is now an independent toggle that can combine with any head or tail style. Sharp arrow tails use continuous contour geometry matching the Qt original to eliminate tail gaps. Rebuild highlighters with multiply blend mode and straight-line drawing, remembering width and mode independently. Show dynamic cyan dashed outlines around text during active editing with localized damage updates, excluding outlines from final export.
- **Input methods and platform compatibility:** Overhaul Windows native IME context management, fixing caret tracking, candidate window positioning, and cursor visibility while isolating context across field switches. Fix Wayland overlay keyboard focus flapping when opening the text tool, verifying Fcitx5 and Rime Chinese composition. Publish compatible DIB image formats to the Windows clipboard to allow direct pasting into Feishu/Lark.
- **Interface and controls:** Hide capture hints and the top mode bar immediately upon first selection drag. Narrow the shortcut recording input box and place Reset and Clear buttons to the right. Add hover states to the QR/barcode close button. Resize Wayland modal OCR dialogs dynamically when expanded. Style scrolling-capture dual previews with square corners, a bottom-anchored thumbnail, and a subtle 1px border.
- **Preferences and persistence:** Persist pinned image context menu toggles (text drag-selection, always on top) and annotation stroke widths on Windows. Fall back to local app data directories for log paths on Windows.
