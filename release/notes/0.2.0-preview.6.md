## 0.2.0-preview.6

这是原生 Rust 重写版本的预发布，面向 Linux X11、Wayland 和 Windows x86_64。
本次版本与此前的 Qt 0.1.x 安装包不同；旧实现保留在 `qt-old` 分支。
预发布尚未作为稳定版本分发，不更新 AUR 或 PPA 稳定渠道。

### 更新描述

- 将原生重写版本切换为 `main`，保留截图、标注、贴图、历史记录和滚动截图功能。
- 集成进程内屏幕录制及媒体库，安装包包含录制所需组件、媒体源码和许可声明。
- 提供文字识别、翻译与条形码／二维码识别；默认按需下载 OCR 推理库及语言模型。
- 继承已有 DEB、RPM、Arch、AppImage、Flatpak、Linux 便携包和 Windows 打包流程。
- 统一发布入口，测试和各平台打包成功后再公开预发布；文件列表及 SHA-256 在发布页面折叠展示。
- 补充中英文安装、平台支持、录制、快捷键和使用文档。

### 使用限制

- Wayland 的截图、录制与全局快捷键支持取决于合成器和桌面门户，首次使用可能需要授权。
- 默认 OCR 模式需要联网下载推理库及模型；下载完成后才可使用本地文字识别。
- macOS 暂不支持。请按发行版和架构选择安装包，不要混用 Qt 0.1.x 插件或安装包。

### English

This prerelease moves the native Rust rewrite to `main`; the previous Qt implementation
remains on `qt-old`. It includes screenshot annotation, pinning, history, scrolling capture,
in-process recording, OCR, translation and barcode scanning for Linux and Windows x86_64.

The existing platform packaging workflows are retained. Publication waits for verification
and all package jobs, and download links with SHA-256 values appear in the collapsed list.
Checksum and internal metadata files are no longer separate release assets. Stable AUR and
PPA channels are not updated by this prerelease.

Wayland support depends on the compositor and portal. The default OCR mode downloads its
runtime and models on request. macOS is not supported.
