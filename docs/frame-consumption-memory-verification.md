## 完整像素与消费契约

恢复默认单表面合成，冻结原件仍保留为只读来源。后端接收明确可消费的 `Pixmap`，
完整帧按最多 1 MiB 交付并立即归还已读取 CPU 页，再合成原生背景。局部帧只消费
提交区间，范围外非零字节继续保留；旧只读接口继续保留全部 CPU 前景。
活动 `wl_buffer` 不允许修改，两份原生缓冲继续等待真实释放后复用。

连续帧回归调用真实编辑器重建、损坏累积、提交和帧末清理，比较消费与只读两条路径。
完整、局部、延迟提交、文件导航、正文显隐、画笔烘焙及恢复、混合比例多输出全部相同。
Linux 页状态回归核对实际自有驻留，不输出物理地址；消费后源容量与原生像素仍有效。

窄扫描行回归还复现了全零页驻留：局部归还系统调用成功，但透明大页为稀疏写入分配
了额外物理页。当前仅对自有像素页采用稀疏策略，消费结束后归还全部已验证零页。
标注完整栅格也采用该策略，恢复和完整正文提交后回收全零页，不缩小画布或改变光栅。
进入原生备用帧复制前先回收损坏恢复写入的零页，减少整屏副本重叠峰值。

R17 三项工具终态与 R16 零像素差异；R18 与 R17 也零差异。实际协议检查确认普通
表面最多两个完整缓冲，无释放前重复活动提交。证据为
`target/memory-verification-r18/tools/contract-and-final-pixels-r17.json`。

## 同场景对照

单位为 MiB。稳定值与观测峰值均计入应用及子进程、原件/冻结来源的未映射文件缓存、
原生共享文件额外驻留，按 device/inode 去重。测试页面、合成器与脚本单独运行。
25 毫秒观测与内核 VmHWM 分开保留，后者不包含未映射额外文件驻留。

| R18 场景 | Qt 稳定 RSS | Rust 稳定 RSS | Qt 观测峰值 | Rust 观测峰值 | 本轮门槛 |
| --- | ---: | ---: | ---: | ---: | --- |
| 普通 4K 编辑 | 201.645 | 67.992 | 214.707 | 104.352 | 通过 |
| 128 次滚动 | 528.148 | 160.691 | 620.777 | 229.523 | 通过 |
| 长图结果编辑 | 205.313 | 68.492 | 同一滚动流程 | 同一滚动流程 | 通过 |
| 实际矩形 | 202.145 | 67.949 | 214.188 | 102.594 | 通过 |
| 实际画笔 | 202.004 | 71.566 | 202.004 | 105.805 | 峰值失败 |
| 实际尺子 | 202.445 | 71.309 | 215.199 | 106.953 | 通过 |

画笔本轮 Qt 主进程内核峰值为 202.004 MiB，Rust 为 104.855 MiB；计入额外文件的
观测 PSS 峰值分别为 169.076、98.980 MiB。五个峰值键全部失败。
该轮 Qt 峰值低于以前部分轮次，判断仍使用本轮值，不替换为较高的历史基线。

R17 普通和滚动矩阵已经通过，矩形仍有内核峰值失败、画笔五项峰值失败；R18 修复了
矩形失败并降低了画笔占用。R18 的剩余问题仍按完整样本保存。
