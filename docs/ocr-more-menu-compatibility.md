# OCR 更多菜单对照

## 原版完整窗口

`tests/fixtures/qt-ocr-more-reference/main.cpp` 只读链接原版完整 `OcrResultWindow`，
从真实 `ocrMoreButton`、`ocrMoreMenu` 和子菜单采集字体、行几何与交互状态。
探针不创建替代窗口，不修改原版源码、对象文件或用户配置。离屏运行使用临时配置；
Wayland 模式要求私有运行记录，首次菜单打开必须经过外部真实点击。

冻结记录位于 `tests/fixtures/qt-ocr-more-menu.json`。父菜单只有 Keyboard shortcuts，
尺寸为 195×37，行矩形为 `[4,4,187,29]`。子菜单尺寸为 252×95，三行分别为
Translate、Copy all text、Undo edit，快捷键分别为 Ctrl+Enter、Ctrl+Shift+C、Ctrl+Z。
三行均为禁用的快捷键说明，不执行翻译、复制或撤销。菜单字体解析为 DejaVu Sans，
字号为 16 个逻辑像素，字体高度为 19 个逻辑像素。

离屏与私有 Sway、niri 的完整记录一致，包括 14 个交互状态、禁用项不触发动作及原文不变。
这些证据验证实际布局和事件规则，不证明不同渲染器的抗锯齿或全部像素已经一致。

## 已接入规则

- More 使用标题栏原版按钮位置和矢量图标；右键只聚焦，普通 Return 不打开，左键或 Space 释放才打开父菜单。
- 父菜单与子菜单分别使用独立 `wl_surface`、`xdg_surface` 和 `xdg_popup`，不是同一表面的两块绘制区域。
- 根菜单必须取得新的真实输入抓取；子菜单继承仍存活父菜单的同座席、同序号抓取，不复用已关闭根会话。
- 父菜单位于按钮下方四个逻辑像素；子菜单首行与父行对齐，左右重叠两个逻辑像素，右侧不足时向左翻转。
- 父行左键按下立即展开子菜单，释放不执行说明动作；右键不直接展开。
- 悬停使用 180 毫秒的单次绝对期限；重复悬停同一行不延长期限，进入子菜单取消父菜单的待关闭期限。
- 父菜单尚未展开时，指针离开表面或移动到整棵菜单之外会取消期限和高亮，旧期限不能展开子层。
- 键盘始终作用于最深可见菜单；子层 Left 或 Escape 只关闭子层，根 Left 保留菜单，根 Escape 关闭整树。
- 禁用说明行不高亮、不交付动作，复制和撤销快捷键不能穿透到正文或剪贴板。
- 回收按子层到根层的顺序执行；业务动作回调前先销毁整棵相关弹层树，旧表面事件不能关闭新会话。
- 无悬停期限的静止菜单不创建等待线程，不周期刷新表面，不初始化识别模型。

## 本地验证

实际 More 回归在私有 Sway 和 niri 上检查独立父子角色、活动抓取继承、逐层键盘关闭、
禁用项、指针悬停、取消期限、按下展开、外部关闭及静止资源。回归还调整私有窗口位置，
分别验证子菜单向左翻转和利用右侧空间展开，不以单一方向代替双向定位验证。

悬停离开的新增测试先观察到失败：真实 Wayland 已发送父菜单离开，180 毫秒到期后
仍创建子层。修正根菜单离开事件的期限清理后，同一离线测试和真实 Sway 场景通过。
失败证据为 `target/ocr-more-hover-red.log` 和 `target/ocr-more-sway-r1/`。

测试在重复悬停前检查首个移动是否实际送达；没有送达时直接失败，不能用后续移动
补偿 niri 的既有输入问题。静止采样核对单线程、CPU 时钟不变和表面请求数不变。
原文和原图菜单的既有动作交付回归也重新执行，不只检查新菜单是否能够显示。

工作区 Rust 测试共 834 项通过、10 项忽略；另有 1 项既有尺子测试明确跳过并单独复现。
该项在未修改 HEAD 的归档中也失败，不能据本轮菜单改动认定为新回归。严格 Clippy、
格式检查和发布模式编译通过。Python 检查器及脚本测试共 175 项通过。

Sway 的反馈、按钮输入、原文菜单、原图预览及窗口输入法五组回归均通过。
niri 的前三组通过，原图和输入法两组保留此前已复现的首次指针移动丢失问题。
真实识别回归另外验证缓存模型、首次使用引导、识别结果窗口交接及表格识别；
首次使用场景在用户动作前没有写入模型，测试在私有目录提供已缓存资源，不重新下载模型。

二进制指纹、实际计数和证据路径统一记录在 `target/ocr-more-local-r1/validation.json`。
该目录只保存本地验证结果，不是发布资产。

## 未完成范围

本轮只进行本地重构与验证，没有提交、推送、创建发行版或修改 GitHub 工作流。
More 中的 Translate 是原版禁用的说明，不代表翻译任务已经实现。目标语言输入、
结果窗口独立置顶、中文界面、完整焦点遍历、工具提示、表格完整几何和逐像素一致性
仍需继续移植。不能以父子菜单完成宣称整个重写已经完成。

启用子菜单业务动作不属于当前 More 菜单；其协议销毁顺序由后端统一约束，
本轮不会临时启用说明行来伪造实际动作验证。多座席、混合设备和全部合成器矩阵也未全面覆盖。
