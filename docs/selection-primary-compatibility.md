# 尺寸字段主选择区与鼠标轨迹兼容

尺寸字段接入截图现有 Wayland 连接的主选择区协议。左键释放复制当前选择，中键释放
先取消选择，再从当前光标插入主选择正文。普通剪贴板保持独立；首次打开字段的点击
仍属于数值控件，不把初始全选复制到主选择。字段外释放继续归原编辑会话。

右键不定位光标、不开始编辑，也不清除字段三击计时器。中键普通按下定位光标，活动
三击可以全选；中键双击不执行普通定位，释放仍尝试粘贴。合成器没有主选择协议时，
保留按下产生的选择，不在释放时取消或粘贴。

## 原生连接与接收边界

主选择管理器在首次编辑字段时绑定；普通静止截图不创建协议对象。来源、接收设备和
发送管道均属于当前截图会话，不新增连接、线程或剪贴板守护进程。每次按钮事件保留
座席与真实序列号，释放授权独立于菜单按下授权，未来排队事件不能替换当前授权。

外部正文通过非阻塞管道接收，事件循环监听读写就绪。来源属于本进程时直接使用已
拥有正文，避免主循环等待自身发送回调。接收限制为131071字节，字段仍按32767个
UTF-16单位裁切，并整批执行整数验证；来源末尾或中间包含非法 UTF-8 时整体拒绝。
三秒超时关闭未完成管道，发送最多保留八个活动请求，静止时不增加周期轮询。

粘贴请求记住字段身份、编辑会话、修订号、正文和光标。字段关闭、程序替换、后续
键盘输入或鼠标按钮使旧请求失效；迟到结果不能进入新字段。来源在会话关闭时释放，
取消一个接收请求不撤销已有复制正文。

## 双击、三击与移动合并

平台双击比较原生毫秒时间，间隔严格小于配置值，横纵位移分别允许五个逻辑像素。
一次双击后重新开始平台计数。鼠标中途超过五像素即废弃候选，移回原位置不能恢复。
字段三击使用独立墙钟、局部取整坐标和小于十像素的曼哈顿距离，计时器跨越右键及
重新编辑。鼠标拖选另外核对编辑身份。

Wayland 后端继续合并连续移动及帧通知，但为每个输出保存横纵极值。应用先将极值
转换到全局坐标并更新点击判断，再处理最终位置，既保留移出轨迹，也避免逐点重绘。
字段字符命中先取整局部坐标，再扣除文字原点，与 Qt 的整数点转换保持一致。

## 原版与验证工具

`field_click_sequences.cpp` 通过 Qt 平台分派生成双击，不手工指定事件类型。200组序列
覆盖五种正文、位移门限、分数坐标、移出返回、右键插入、程序替换、失焦重开、
399/400/401毫秒间隔及墙钟期限。原版为 Qt 6.12.0、Noto Sans、96 DPI，双击距离五、
拖动距离十。550个键盘样本及520个鼠标样本重新采集后与此前数据相同，拆分探针
指纹记录于 `tests/fixtures/qt-selection-size/field-navigation-index.json`。

`wayland-selection-field-primary.py` 共用 Qt 与 Rust 的实际输入流程，验证主选择复制、
右键插入后三击、中键合法与非法粘贴、字段外释放、自身来源、空闲及退出释放。
Qt 原生输入法在光标不变而仅锚点改变时可能遗漏周边状态通知，工具另外直接记录
生产控件状态，并核对实际主选择正文；不以旧输入法缓存推断选择结果。

导航工具的无动作检查持续读取协议消息，发现任何上下文变化立即失败。此前
`target/fp-before-s1/checks/result.json` 使用旧缓存检查，不能作为通过证据；修正后的
`target/fp-before-s2/checks/` 在914构建上确认移出返回误判，第二次按下只相隔42毫秒。

## 验证范围

优化构建为48,456,072字节，SHA-256为
`a1e35aed2a46f7f60b18bf7bf8d0f2a7f1b0d66fb0a2ac46779719140bcf8617`。
源码通过1085项 Rust 测试、10项忽略，严格 Clippy、格式及201项 Python 测试通过。
动态依赖全部可解析，没有 Qt 依赖。独立候选保存在
`target/selection-primary-candidate-r1/mark-shot`，运行与发布状态见
`target/verification-selection-primary-r1/result.json`。

Qt 与这个优化构建在私有 Sway 和 Xvfb 内的 niri、1.5分数缩放与翻转输出上完成扩展
主选择流程。同一候选另外完成两套字段、两套尺寸和两套完整截图翻译流程，合计
八套。翻译各完成七次请求，首次下载后三个模型文件指纹一致。52次空闲采样保持
单线程，CPU时间与缓冲区提交计数没有增长；主选择流程还检查进程没有子进程，
退出后来源自行消失。

全部流程结束后，在同一私有 niri 会话顺序测量此前914构建与本次候选，各三次温
启动。内部首提交中位数15.58→15.56毫秒，候选父进程观察中位数20.90毫秒；空闲
RSS中位数56,788→57,112 KiB，候选约55.8 MiB。三个样本不能证明确定的性能变化，
也不代表冷启动或合成器呈现时间。

原始记录分别保存在 `target/primary-rel-sway-r1/`、`target/primary-rel-niri-r1/`、
`target/qt-field-primary-s10/checks/`、`target/qt-field-primary-n3/checks/` 与
`target/primary-performance-before-r1/`、`target/primary-performance-after-r1/`。

组成文字时的鼠标行为、全部语言、真实混合缩放多输出，以及完整界面逐像素一致仍
未完成。这个功能范围不代表整个 Rust 重写已经完成。
