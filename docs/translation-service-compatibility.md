# 翻译服务与任务层对照

本文记录服务层阶段的实现和证据，后续已将任务接入 OCR 翻译按钮、目标语言、译文编辑器及分栏。
窗口阶段的当前验证与剩余差距见 `docs/ocr-translation-compatibility.md`，不把服务测试视为完整翻译功能。
没有执行 Git 提交、推送、发布或修改远程工作流，没有调用付费服务或使用用户翻译凭据。

## 模块职责

```text
src/translation/
  mod.rs                  服务标识、分段身份和结果契约
  language.rs             九个界面选项、界面语言与服务语言代码
  resolve.rs              配置优先级、服务选择和凭据脱敏
  response.rs             模型内容、数量校验和最终原文回退
  http.rs                 有限异步 HTTP、禁止重定向
  task.rs                 按需工作线程、超时、取消和一次性交付
  process.rs              私有输入文件、命令参数和进程组回收
  providers/              六类服务的请求、签名和响应适配
src/config/
  translation.rs          翻译配置读取和单项语言保存
  persistence.rs          历史与翻译共用锁及原子保存
```

## 已核对行为

- 自动选择顺序为 OpenAI、Gemini、Anthropic、腾讯、百度、有道；命令配置优先
- 显式服务请求失败不切换厂商，不向另一家服务发送原文
- `builtin` 不继承 `translation.openai` 子节；Gemini、Anthropic 不继承公共 OpenAI 凭据
- 原文按行生成身份，空行仍计入行号；任务使用确认文本快照，不修改调用方原文
- 厂商批次按 UTF-16 长度计算；腾讯下线 Action 只降级到同一家服务的单段接口
- 空译文在最终结果中回退到原始分段，批次压平不改变保留的制表符
- 腾讯 TC3、百度 MD5、有道 SHA-256 签名对照真实原版结果，包含 UTC 跨日与代理对截断
- 百度、有道表单分别使用加号与百分号表示空格，原始加号、星号和波浪线匹配 Qt 编码
- 英文界面保留中文自由输入；中文界面识别九个中文展示标签，稳定值与标签分开
- Gemini 区分候选、内容块与空正文；Anthropic 拼接全部文本块并忽略思考块

服务记录位于 `tests/fixtures/qt-translation-services.json`，覆盖 102 个语言别名、
9 个中文标签、签名和模型内部 JSON。Gemini、Anthropic 的 28 条实际解析记录位于
`tests/fixtures/qt-translation-model-responses.json`，成功映射及失败文案均逐项核对。
两个探针重复执行结果一致；探针只读链接原版对象，输出写入本地 `target`。

## 资源与保存边界

每次任务只创建一个按需工作线程与单线程 Tokio 运行时。任务完成只通知一次；
取消和超时关闭所属网络连接，结束后不保留运行时线程。
DNS 使用异步解析，不依赖系统阻塞查询工作线程。

HTTP 禁止自动重定向，响应上限为 4 MiB；没有总长度的分块响应也受同一限制。
原文上限为 8 MiB。命令 stdout 上限为 4 MiB，stderr 上限为 512 KiB。
命令输入使用 0600 临时文件；取消、超时和输出超限时先终止所属进程组，
再等待直接子进程退出，最后删除输入文件。交互取消不等待；窗口事件循环退出后等待所属任务完成清理。

命令支持 `{input}`、`{inputPath}`、`{targetLanguage}` 和 `{config}`。
没有占位符时追加输入路径。只解析原始模板，不递归展开参数中出现的占位符文本，
避免原版逐次替换方式破坏 shell 引用；这是明确的安全差异。

配置读取拒绝符号链接、多重硬链接、非普通文件和超过 1 MiB 的文件。
历史和语言保存使用原有 `toml.history.lock` 锁名，单项原子更新保留厂商字段、
未知字段及注释。独立读取支持原版 JSON 翻译节；语言写入仍针对原生 TOML，
不等同于完整旧配置迁移。服务调试输出隐藏接入点、命令和凭据，厂商服务错误在交付前脱敏。

## 当前验证

六类服务均通过真实回环 HTTP 测试，覆盖请求路径、鉴权、正文、空译文回退、
业务错误脱敏和连接取消。测试只绑定 `127.0.0.1`，使用固定测试凭据。
真实命令测试覆盖私有输入、参数引用、进程组取消、超时、超量输出和直接子进程回收。
配置测试覆盖危险文件拒绝、错误保存不覆盖及历史与语言并发更新。

本次完整检查索引保存到 `target/ocr-translation-local-r1/validation.json`。
871 项 Rust 测试通过、10 项忽略，37 项属于翻译与配置；既有尺子失败单独复现，
与未修改 HEAD 的结果一致。175 项 Python 测试、严格 Clippy、格式及发布模式构建通过。
新构建 SHA-256 为 `5615cd423fa3b90244154baca8e8e4d183f71680bec714df1caf9ed1eca15d58`，
大小为 43410024 字节，动态链接不包含 Qt、GTK 或 WebView。

历史窗口完整回归在短路径私有 niri 会话通过，验证记录位于
`target/ocr-translation-history-r2/result.json`。两个窗口尺寸下均保持单线程，
空闲 CPU 时钟增量为零；保存、策略修改、清空确认、配置保留和关闭资源通过检查。
首次会话因 Unix 套接字路径过长未启动，没有进入应用测试，不计入通过结果。
日志按检查类型保存，不与此前更多菜单构建混用。
