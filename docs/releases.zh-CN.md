# 发版说明

### 0.1.44

- **Debian 与 Ubuntu 安装包**：`.deb` 构建在全部矩阵条目上失败，原因是扫码代码按 zxing-cpp 3.x 接口编写，而 Debian 12 提供的是 1.4、Ubuntu 26.04 提供的是 2.3。现在读码参数类按主版本取别名，并通过 `ZX_USE_UTF8` 让各版本的 `text()` 统一返回 `std::string`，两个发行版恢复构建且内置扫码保持可用。插件写码测试在 3.0 以下仍然关闭，因为只有 3.0 起提供对应的 `CreateBarcode` 接口。

### 0.1.43

- **录制暂停与继续**：录制过程中可以从悬浮控制条、托盘菜单、全局快捷键或 `--pause-recording` 暂停与继续。采集、编码和音频同时停止，暂停时长会从输出时间轴中扣除，音画保持同步。
- **录制控制条与区域边框**：区域录制会在录制区域外围显示红色边框，并在旁边显示带计时、暂停和停止的紧凑控制条。两者都不会进入录制画面，其余区域的点击照常穿透。整屏录制不显示覆盖层，改由托盘和快捷键控制。
- **更广的硬件编码支持**：视频编码在 Linux 上补充 VAAPI 与 Quick Sync，Windows 上补充 AMF 与 Quick Sync，不再只有 NVENC。候选会按 FFmpeg 实际编入的编码器和机器上的设备节点筛选，多显卡机器逐个渲染节点尝试，跳过不支持编码的设备。
- **并行像素转换**：BGRA 到 YUV 的转换按行切片在常驻线程池中并行执行，写出线程不再受限于单线程转换。
- **GIF 逐帧调色板**：GIF 录制改用 libavfilter 的 `palettegen`/`paletteuse` 做逐帧调色板量化，替代固定 3-3-2 调色板，渐变画面的平均通道误差从 20 以上降到约 3。
- **MKV 封装与画质档位**：视频录制可以写成 MKV，录制意外中断后仍可播放；新增画质档位（均衡、画质优先、体积优先），影响恒定质量取值、编码预设与码率。
- **起录倒计时**：可选择在正式开始录制前等待 3 秒或 5 秒。
- **保存通知打开目录**：录制保存通知提供在文件管理器中定位文件的入口。
- **KDE 搭配 NVIDIA 录制失败**：KWin 在 NVIDIA 专有驱动上导不出可用的 DMA-BUF，这类机器上录制会立即失败。现在单显卡的 KDE 会话遇到该驱动会自动协商共享内存，混合显卡保持使用 DMA-BUF，`MARK_SHOT_FORCE_DMABUF` 可强制恢复，导入失败时也会提示绕过方法。
- **静止画面时长压缩**：事件驱动的采集后端在画面不变时不出帧，追帧上限会把这些时段压缩。新增心跳在静止期间补写重复帧，使录制时长与真实时长一致。
- **GIF 采集后端**：GIF 录制此前被排除在 wlroots screencopy 之外，在 niri、sway 等合成器上只能走全链路轮询截屏。现在与视频共用采集路径，由写出层按目标帧率筛除多余帧。
- **奇数尺寸画面**：奇数宽高的采集区域改为裁剪而非缩放，消除编码结果的轻微形变。
- **录制队列深度**：待编码帧队列按帧内存与帧率计算，不再固定为一到两帧，编码抖动不会再造成无谓丢帧。

### 0.1.42

- **形状标记工具**：工具栏新增形状标记组，支持三角形、五角星、对钩、叉叉、扑克花色、加号、禁止等多种实心标记；再次点击可打开形状面板。
- **曲线标记字形**：黑桃、梅花、禁止等标记改为三次贝塞尔/圆角曲线，避免多边形块状和挖空。
- **双 deb 包**：继续分别发布 Debian 12 与 Ubuntu 26.04 包，覆盖不同 FFmpeg/Qt 共享库代际。
- **插件依赖打包**：deb 打包会对主程序和已安装插件 so 一起生成共享库依赖。
- **Wayland 覆盖层 exclusive zone**：恢复忽略其他 exclusive zone，修复 niri 上冻结帧上方露出真 waybar 的问题。
- **反色矩形边框**：反色矩形不再绘制外描边。
- **FFmpeg arm64 兼容**：为 Ubuntu 22.04 arm64 等 FFmpeg 4.4 构建环境增加 channel layout 旧 API 回退。
- **设置关于页**：将「关于」从「高级」拆成独立导航页，并收紧侧栏间距对齐。

### 0.1.41

- **Windows 构建兼容性**：PipeWire SPA 缓冲区辅助实现和专项测试仅在 Linux 平台参与编译，恢复 Windows 构建与发布包生成，同时保持 Linux PipeWire 截图行为不变。

### 0.1.40

- **截图设置实时生效**：每次截图时重新读取鼠标指针、冻结范围和默认标注工具设置，修改配置后不再需要重启 Mark Shot。
- **默认移动工具**：新安装和未明确配置默认工具的用户将使用移动工具进入标注编辑，不再默认选中画笔。
- **工具栏支持拖动**：标注工具栏和右侧操作工具栏新增拖动区域，并在编辑期间保留用户调整的位置。
- **鼠标指针反馈**：移动工具在选区外显示普通箭头；工具栏、属性面板、颜色控件、字体列表、扩展面板和下拉菜单不再错误显示绘制十字指针。
- **文本标注布局**：文本背景增加宽度余量，避免编辑期间文字提前换行。
- **KDE 与 PipeWire 截图**：改进 KWin 自身窗口处理、KDE Wayland 截图兼容性和 PipeWire 缓冲区数据类型处理，并补充相关测试。

### 0.1.39

- **Wayland 多屏截图**：Wayland 多屏环境改为分别捕获各显示器，修复混合缩放下只能选择半屏、覆盖层比例异常等问题。
- **Niri DMS 窗口几何**：Niri 窗口检测会读取 DMS 的 bar、dock、frame 和 frame-exclusion 设置，使平铺窗口选区与实际可见边界一致。
- **贴图跨屏拖动**：Layer Shell 贴图在拖到其他显示器时会重新绑定目标输出，修复跨屏后图片消失的问题。
- **导出图片外框默认值**：可选的 macOS 风格导出外框改为默认关闭；已有配置仍可通过 `export.imageFrame.enabled` 启用。
- **截图窗口可见性设置**：`capture.hideOwnWindows` 改为每次截图时读取，并统一应用到单屏和多屏路径，修改设置后不需要重启应用。
- **数字标记旋转**：数字标记改为围绕圆形标记中心旋转，并同步修正命中检测与选择框几何。
- **独立插件资产**：发版构建会把 Provider 插件作为带校验文件的独立资产发布，并提高 Rapid OCR 插件构建的稳定性。
- **打包与文档**：Arch 包补充 FFmpeg 录制依赖，统一所有发行包版本，并将配置参考和发版说明纳入安装包。


### 0.1.38

- **插件生态基础**：新增 Provider 插件注册、用户级插件目录、插件优先级配置和插件设置页，OCR、翻译、扫码能力都可以通过动态库扩展。
- **GitHub 插件市场**：新增 C++/Qt 内置插件索引解析、下载、SHA-256 校验和安装流程，插件市场只依赖 GitHub Release 资产，不需要 Python 环境。
- **C++ Rapid OCR 插件升级**：Rapid OCR 插件改为输出词级 token，中文和标点按字符切分，拉丁文本按空白切词，并复用旧 RapidOCR 模型目录。
- **钉图文本选择修复**：修复中文全角字符选中背景半宽、复制时连续中文 token 被误插入空格等问题。

### 0.1.37

- **Windows 录制音频**：新增 Windows 原生 WASAPI loopback 音频采集，视频录制可采集系统声音，不再依赖 PulseAudio。
- **Windows 发布打包**：启用基于 FFmpeg 的 Windows 发布包构建，补齐运行时 DLL 部署，并支持对可执行文件和 DLL 执行 Authenticode 签名。
- **Windows CI 构建修复**：修复 WASAPI GUID 链接和录制测试目标链接问题，Windows 构建、测试、签名、打包和 artifact 上传已完整通过。

### 0.1.33

- **窗口层级选择**：改进 GNOME、KDE Plasma、Hyprland、X11 和 Windows 下的窗口排序，选区时优先匹配视觉上最上层的窗口。
- **Wayland Fcitx5 候选窗支持**：调整 layer-shell 光标矩形处理，使 fcitx5 候选窗可以在 Wayland 截图覆盖层下正确显示。
- **设置齿轮图标更新**：重绘工具栏设置按钮和设置页 General 导航图标，使用更清晰的齿轮图形，避免看起来像太阳。
- **托盘模式兼容性**：修复直接以托盘模式启动时，在系统托盘暂不可用环境下的启动行为。
- **Wayland 文本编辑器宽度修复**：修复分数缩放 Wayland 环境下标注文本编辑器异常变窄的问题。

### 0.1.31

- **命令行图片贴图**：新增 `--pin-image <path>` 参数，可直接将本地图片作为贴图窗口打开，跳过截图与选区流程。
- **取色器颜色历史**：启动取色器现可记录最近拾取的颜色，保存在 `config.json` 的 `colorPicker.history` 中（最多 7 条 `#RRGGBBAA`），并在颜色面板以色块展示。
- **界面语言设置**：新增可配置的 `ui.language` 选项（`system` / `english` / `chinese`），可在设置通用页选择；取代旧版最外层 `language` 字段。
- **按桌面环境自动选择窗口检测**：Mark Shot 运行时会自动探测当前桌面环境（GNOME、KDE Plasma、Hyprland、Niri）并选择匹配的检测脚本，其他 Wayland 会话回退到 niri 脚本，X11 会话使用原生 X11 检测。配置命令与环境不匹配时仅在内存中纠正，不修改 `config.json`。
- **GNOME 遮挡窗口过滤**：GNOME Shell 滚动助手扩展现会从检测结果中过滤完全被遮挡的窗口。
- **预编译 AUR 包**：新增 `mark-shot-bin` AUR 包，从 GitHub Releases 下载预编译 pacman 包安装，与源码版 `mark-shot` 并存。
- **GNOME Adwaita 配色修复**：在 `qApp` 层覆盖应用调色板，使深色配色在 GNOME Adwaita 下彻底替换 libqtk3 基础调色板。
- **AUR 可选依赖**：新增 `python-rapidocr`、`python-pillow`、`python-zxing-cpp` 作为 OCR/扫码首选可选依赖。

### 0.1.30

- **设置配置对话框**：新增独立设置窗口，包含通用、截图、标注、贴图、滚动、快捷键、存储、集成、高级等多个分页。原先只能通过文件修改的配置项现在均可在一个界面内编辑，底层仍读写同一份 `config.json`，并统一了设计令牌与自定义导航侧边栏。
- **开机启动**：通用页新增 `开机启动` 开关。Linux 会写入 XDG `autostart` 桌面项，Windows 会写入当前用户的 `Run` 注册表项；在不支持的平台上开关会自动禁用。
- **Portal 全局快捷键支持**：新增基于 `xdg-desktop-portal` 的 `GlobalShortcuts` 后端，使全局截图热键在无 X11 的 Wayland 环境下也能生效。
- **贴图文本选择开关**：贴图窗口新增可配置的文本选择开关，并将 `pinned_window_config` 拆分为独立模块。
- **截图会话中的设置入口**：从工具栏或快捷键打开设置时，会先关闭冻结的截图会话，并在下一轮事件循环再弹出设置对话框，避免与 layer-shell 截图窗口冲突。
- **Wayland 贴图窗口定位**：抽出 layer-shell 几何计算并改进 resize 控制器，修复贴图窗口在多屏或屏幕外的放置问题。

### 0.1.29

- **放大镜双框独立调节**：放大镜的内层取景框与外层透镜各自带有 resize 把手，矩形透镜每框 8 个角/边把手，圆形透镜每框 4 个上下左右把手。调整任一框时按 `magnifierScale` 联动另一框，倍率始终保持不变；平移单框时另一框保持原位。

- **工具默认值跨会话持久化**：标注工具默认值（颜色、不透明度、各工具笔宽、矩形填充/圆角/风格、放大镜倍率与形状、箭头/荧光笔/数字步骤风格、文本字体、文字背景色）会通过独立的 `annotation-state.json` 跨会话保留。写盘通过 `QSaveFile` 原子提交，并在每个修改默认值的入口触发后立即写入。
