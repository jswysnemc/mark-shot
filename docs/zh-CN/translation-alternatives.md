# 腾讯翻译政策与替代方案评估

截至 2026-11-17，腾讯机器翻译已不适合作为新用户的默认选择。Mark Shot 当前默认使用
哔哩哔哩 Index-Translate，也支持百度、有道以及模型服务的兼容接口，腾讯选项继续供已有账号使用。

## 官方政策核对

[腾讯云快速入门](https://cloud.tencent.com/document/product/551/104415) 提示文本翻译和批量文本翻译
将下线，不再支持新用户，并推荐迁移到 TokenHub。
[腾讯云国际站公告](https://intl.cloud.tencent.com/announce/detail/101482) 对受影响接口给出的计划为：
2026-10 起逐月缩减 QPS，2027-10-01 起降为零。公告涉及的地域、账号和接口范围应以控制台通知为准。
Issue #154 提到的 2030-12-31 不能作为所有文本翻译接口的统一停止日期。

[另一份腾讯退市公告](https://cloud.tencent.com/announce/detail/2274) 涉及文件、图片、语音翻译和语种识别，
不能用它替代文本翻译公告。免费额度和接口可用性也是两个不同问题，已有账号应分别核对。

## 替代服务比较

| 服务 | 官方免费额度 | 超额单价 | 本版本接入情况 |
| --- | --- | --- | --- |
| [阿里云通用机器翻译](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-machine-translation-general-purpose-edition) | 主账号每月 100 万字符，子账号共享 | 50 元/百万字符 | 尚未提供原生签名接口，可用自定义命令接入 |
| [火山引擎文本翻译](https://docs.volcengine.com/docs/machine-translation/product-billing?lang=zh) | 每月前 200 万字符 | 49 元/百万字符 | 尚未提供原生签名接口，可用自定义命令接入 |
| 哔哩哔哩 Index-Translate | 本次没有核实额度承诺 | 本次没有核实计费承诺 | 已有默认入口，不要求配置密钥 |
| OpenAI 兼容接口、Responses、Gemini、Anthropic | 取决于服务商和模型 | 取决于服务商和模型 | 已支持地址、密钥、模型查询及手动模型配置 |
| 百度、有道 | 取决于账号套餐 | 取决于账号套餐 | 已支持原生接口 |

阿里云和火山引擎的表格数据来自本次读取的官方计费页面。字符统计口径和账号政策应按对应页面执行。
模型 Token 计费与传统机器翻译字符计费不能直接比较。

## 评估结论

需要每月固定免费字符额度时，优先评估火山引擎；其官方额度高于阿里云，超额单价略低。
已有阿里云账号和权限体系时，阿里云也适合。两者均需新增服务商鉴权、语言映射和错误处理后才能
成为 Mark Shot 原生服务选项，本版本没有把模型兼容接口冒充这两个传统翻译接口。

当前用户可以直接使用已有服务，在“设置 → 翻译服务”保存服务选择、凭据和目标语言。
选择模型兼容接口时，需要核对该服务商实际支持的接口类型、地址和模型；已有腾讯配置不会自动迁移凭据。

证据通过 `smart-search fetch <官方页面地址> --format markdown` 获取。主搜索连接校验遇到 TLS 错误，
本次使用已配置的文档获取能力读取上述官方页面，没有修改搜索供应商配置。
