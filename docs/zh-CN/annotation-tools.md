# 标注工具

[English](../annotation-tools.md) | **简体中文**

框选区域后，主工具栏提供绘图工具，动作工具栏提供完成动作。工具栏旁的属性栏显示当前工具的设置项。
两条工具栏的内容都可以在**设置 → 工具栏**中调整。

下列按键均为默认值，全部可以修改，见[快捷键](shortcuts.md)。

## 工具列表

| 工具 | 按键 | 用途 |
| --- | --- | --- |
| 选区 | `S` | 移动和调整截图区域 |
| 选择 | `V` | 选中、移动、缩放、旋转和删除标注 |
| 画笔 | `P` | 自由绘制 |
| 荧光笔 | `H` | 半透明的自由绘制 |
| 直线 | `D` | 直线或曲线，支持实线、虚线和点线 |
| 箭头 | `A` | 四种箭头样式，三种线型 |
| 矩形 | `R` | 描边或填充的矩形，可设置圆角 |
| 椭圆 | `C` | 描边或填充的椭圆 |
| 形状标记 | `K` | 24 种预设形状 |
| 文字 | `T` | 可设置字体、字号、粗体、斜体和背景 |
| 序号 | `N` | 自动递增的序号标记 |
| 编号箭头 | `Shift+N` | 带编号的箭头，独立计数 |
| 滤镜 | `M`、`X` | 对区域进行像素化、模糊、灰度、反色或提亮 |
| 放大镜 | `Z` | 持久显示的放大镜，放大图片的局部 |
| 尺子 | `U` | 测量长度或角度 |
| 激光笔 | `G` | 用于演示的临时笔迹 |
| 取色器 | `I` | 从图片中取色 |
| 文字识别 | `O` | 识别选区内的文字 |

## 工具说明

**直线与箭头。** 按住 `Shift` 可以把方向吸附到 45 度的倍数。使用选择工具双击路径可以插入控制点，
拖动控制点即可弯曲线条；按 `Delete` 删除选中的控制点。箭头头部分为实心和开口两种，可以单向或双向。

**矩形与椭圆。** 拖动时按住 `Shift` 可以绘制正方形或正圆。属性栏的 `1:1` 开关可以固定该比例，
`R` 用于设置矩形的圆角半径，单位为图片像素。

**文字。** 单击放置光标后输入。`Enter` 换行；`Esc`、`Ctrl+Enter` 或点击外部提交文字。
字体面板提供搜索、8 到 300 点的字号、粗体和斜体。Wayland 与 X11 均支持输入法。
修改已有文字时，先用选择工具选中它，再点击属性栏的编辑按钮。

**序号。** 单击创建圆形序号，拖动可以添加指向尾部。提供七种样式：数字、大小写字母、
大小写罗马数字、天干和中文数字。删除某个序号不会改变其他序号，重置按钮让计数重新开始。

**滤镜。** 效果始终根据原始截图计算，不受其他标注影响。强度范围为 4 到 48，
决定像素块大小或模糊半径，单位为图片像素。

**放大镜。** 拖动创建源框和镜框。两个框可以分别移动；缩放其中一个时，另一个随之缩放，
放大倍率保持不变。镜框可以是圆形或矩形，倍率范围为 1.25 到 6。

**尺子。** 以图片像素为单位显示宽度、高度、对角线和面积，或显示夹角。再次按 `U`
可以切换下一次测量使用长度模式还是角度模式。

**激光笔。** 松开鼠标约两秒后笔迹消失。笔迹不会出现在保存的图片中，也不计入撤销历史。

## 编辑标注

按 `V` 后单击标注即可选中，标注周围会显示带控制点的虚线框。

| 操作 | 方法 |
| --- | --- |
| 移动 | 拖动标注 |
| 缩放 | 拖动控制点，按住 `Ctrl` 保持长宽比 |
| 旋转 | 拖动旋转控制点，按住 `Shift` 吸附到 45 度的倍数 |
| 删除 | 点击选框上的红色叉号，或按 `Delete` |
| 多选 | 拖动出一个框把标注围住，或按 `Ctrl+A` 全选 |
| 修改属性 | 使用属性栏，修改会应用到所选标注 |
| 撤销、重做 | `Ctrl+Z`，`Ctrl+Shift+Z` 或 `Ctrl+Y` |

单击右键会取消正在绘制的标注，并切换到选择工具。双击右键打开颜色面板。

## 粗细、颜色与视图

- `[` 和 `]` 减小和增大笔宽或字号。使用绘图工具时，滚轮具有相同作用，并在指针旁显示当前数值。
- 颜色面板提供调色板、最近使用的颜色、十六进制输入框和透明度滑条。
- 使用选择工具或编辑图片文件时，滚轮以指针位置为中心缩放画布。按住中键拖动可以平移，
  快速连按两次 `Ctrl` 复位视图。
- `Space` 隐藏或显示工具栏。

程序会记住每个工具上次使用的颜色、笔宽和样式，下次启动时继续使用。

## 导出外框

导出外框在编辑器保存或复制图片时，为图片添加透明留白、圆角和柔和的阴影，默认关闭。
可以在**设置 → 贴图与外框**中启用，该页面提供实时预览；也可以在 `[export.image_frame]` 中配置：

```toml
[export.image_frame]
enabled = true
padding = 112
corner_radius = 18.0
shadow_radius = 72
shadow_offset_y = 28
shadow_opacity = 0.32
```

贴图和屏幕上的预览保持原图，不添加外框。
