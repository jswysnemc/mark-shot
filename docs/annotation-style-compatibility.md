# 标注样式单位与验证范围

当前实现区分原图属性数值、稳定画布坐标和窗口绘制限制。文件图片的初始适配、截图
设备比例和后续导航倍率不再共同改变持久笔宽。完整 Qt 界面及像素审计仍未完成。

## 持久单位

`src/features/annotation_style/units.rs` 保存原图与稳定画布的比例。标注通过
`style_scale` 保存一个原图像素在当前坐标中的大小，导出换坐标时同步调整该比例。
原图 getter 和 setter 使用标注自身比例，属性栏和工具默认值均保持原图数值。

工具创建统一经过 `EditorState::adopt_annotation_style()`。画笔、荧光笔、矩形、椭圆、
直线、箭头、序号、形状标记、放大镜、尺子、滤镜与旧编号箭头均已接入。
序号、标记、放大镜和尺子在移动时重新写入宽度，也使用原图 setter；放大镜重新构造
草稿后恢复自身比例。普通绘图工具不再附加原版不存在的阴影或画笔光晕。

文字点字号及其 `appearance.size_scale` 保留既有独立换算，创建入口不重复缩小字号。
滤镜强度仍使用原图像素。尺子的粗细公式按画布笔宽乘以测量原图比例计算；文件入口
没有截图补偿，截图入口保留原版零点五至四倍截图比例补偿。

激光笔不进入持久标注。其草稿保存原图单位，抖动阈值及插值步长按原图数值计算，
导航只影响当前窗口投影。

## 窗口绘制

`WindowUnits` 的输入是一个窗口逻辑像素在当前坐标中的尺寸，与输出设备比例独立。
通用笔宽下限为一点五窗口像素，荧光笔为六窗口像素，放大镜边框范围为一点五至十八。
激光主线至少三窗口像素，白芯至少一点四。实际绘制入口不再把窗口最小笔宽按原图
最大值夹紧。

序号圆框半径至少十三窗口像素，白边限制为二至九，尾部半宽限制为八至三十八。
字体先按窗口点字号取整，再按九十六 DPI 转为像素；标签逐点缩小至八点后允许超出
圆框。真实标签边界参与分块绘制，最低字号不会重新连续缩小。字形跨越一千零二十二
像素的分块回归继续检查局部画布与完整画布一致。

燕尾箭头头部的十二至六十长度限制使用窗口单位。序号、滤镜和放大镜的选中控制点
尺寸、选中命中容差及专用旋转连接间隔不再乘以原图适配比例。普通标注和群组此前
已经验证的二十六窗口像素旋转间隔继续保留。

荧光笔使用原版乘法混合及二百级透明度。包含荧光笔的场景按标注顺序读取实际底图，
局部绘制直接替换已恢复的区域。其他标注保留与持久缓存相同的透明合成，避免草稿
与提交结果产生舍入差异。原图导出也读取实际底图，不使用已烘焙的荧光笔透明缓存。

动态剔除范围包含序号窗口最小圆框、长标签和窗口描边。它不覆盖持久选框、旋转轴心
或原图宽度。

## 只读 Qt 参考

`scripts/annotation-style-reference.py` 从原版只读提取完整 `drawAnnotation()`、
`drawNumber()`、`annotationSizeScale()`、坐标映射和笔迹平滑函数；完整链接原版主题、
直线骨架和箭头绘制文件。采集使用 Qt offscreen，关闭 GLX，移除用户显示服务器
及合成器连接变量。

生产样本位于 `target/qt-annotation-style-reference-r2/`，固定像素度量及来源清单位于
`tests/fixtures/qt-annotation-style/`。共一百四十四例，覆盖画笔、直线、自由荧光笔、
椭圆、燕尾箭头和阿拉伯序号；投影比例为零点一二五、零点五、一和二，原图笔宽为
一、六和七十二，设备比例为一和一点五。

Rust 对照检查窗口外框及画笔、直线、荧光笔的固定像素颜色。边界容差为一个窗口
像素对应的设备像素，实色颜色容差为两级。箭头只检查头部外移范围和右侧边界，
渐细尾部最左侧低覆盖像素仍有光栅差异；椭圆边缘颜色及序号字体内部像素没有纳入
这项颜色断言。此检查不证明全部一百四十四张图逐像素一致。

宿主只执行零旋转的已列出工具。矩形、标记、尺子、滤镜、放大镜、文字及非零旋转
分支如果到达会立即退出，不为这些分支提供假实现或假成功。宿主没有完整
`ShotWindow` 初始化，也不代替原生鼠标、焦点和属性输入测试。

## 输入与原生证据

`src/app/input/tests/annotation_style/` 覆盖小图放大、大图缩小、分数设备截图、移动
覆盖、导航后创建、单项属性输入、成员各自比例、历史、原图导出、激光采样、
窗口细线、最小圆框的窄条重绘、荧光笔底图混合及专用控制点，共十二项输入回归。

`scripts/wayland-annotation-style.py` 在校验后的私有合成器中创建线条，独立测量当前
窗口厚度，再通过生产复制入口核对原图厚度、图像尺寸和空闲资源。新旧候选使用
同一脚本对照。初次脚本使用了错误快捷键及宽度配置，现场保留在
`target/as-negative-sway-r1/` 和 `target/as-sway-r1*/`，这些失败不能证明旧候选存在
单位错误。修正后另用独立目录保存真实对照结果。

修正后的同一脚本在新 R1 候选上完成四个正例，并拒绝旧 R5 候选。有效负例保留在
`target/as-negative-sway-r2/result.json`：实际窗口笔宽约一点三八八，按原图换算应约
三点一二零。后续长标签缓存修复形成 R2 候选，R1 二进制及全部早期现场继续保留。

## 最终样式候选

候选为 `target/annotation-style-candidate-r2/mark-shot`，大小 48,674,312 字节，SHA-256
为 `e424c362caea9d9731aafc3413e9b2ca8d6bc89502cefa01f10bb25ba0151c3e`。
清单位于 `target/verification-annotation-style-r2/result.json`，SHA-256 为
`bc474651e9fbb17f5d74d9761b9f48d189140a7f405ef58fb36ab8ff5b679d8c`。
构建、测试及原生验证前后，一千三百八十个 Rust、Cargo、资产和测试输入文件一致；
两个新脚本指纹也一致。Rust 文件最大七百四十一行，候选动态依赖可解析且没有 Qt。

默认工作区一千一百八十八项、全特性一千一百八十九项通过，各忽略十项。严格 Clippy、
格式、两份脚本 Ruff 与 Python 编译通过。新增缓存回归先复现旧圆框外字形的窄条
重绘缺口及损坏范围遗漏，修复后九项序号渲染测试通过。

同一 R2 候选在私有 Sway 与不可见 Xvfb 中的 niri、单输出一点五倍比例下逐个完成
十六个原生场景：八个样式创建及导出、四个导航、四个普通或群组旋转。结果目录分别为
`target/as-sway-r2-r2/`、`target/as-niri-r2-r2/`、`target/as-nav-sway-r2-r2/`、
`target/as-nav-niri-r2-r2/`、`target/as-rot-sway-r2-r2/` 和 `target/as-rot-niri-r2-r2/`。
旋转历史只比较脚本记录的画布区域，不代表完整 Qt 界面像素一致。

一百二十八个编辑后空闲样本均为单线程，CPU 计数及缓冲提交保持稳定，RSS 范围为
60,892–69,052 KiB。此结果不代表冷启动性能。第一次并行原生矩阵出现输入或画面等待
失败，全部现场保留，未计入通过数量；逐个运行后完成上述矩阵，尚未确认并行失败的
具体原因。逻辑截图覆盖积分允许四分之一窗口像素的重新采样误差，原图导出允许
零点零八像素误差。

样式候选未发布，当前 `target/release/mark-shot` 保持
`27866fbec304ab3d6afe52f5ecf632031bfb9b5386e61399b1a52e1cd097e175`。
