# 普通标注旋转对照

矩形、椭圆、形状标记、画笔、荧光笔和文字已接入独立旋转角度、旋转控制点、正文绘制、
反向命中、缩放、移动和标注历史。专用工具继续使用各自旋转模型。完整 Rust 重写仍未完成。

## 几何与鼠标

普通标注保留未旋转的原始坐标和边界。选框先与冻结画布相交，再计算旋转中心；移动时
画布位置保持不变，导出缩放时画布边界随坐标一起缩放。选框不把阴影留量加入缩放几何，
画笔和荧光笔的选框按原版包含笔宽。

旋转点位于上边中点外侧26逻辑像素，随角度转动。左键拖动改变角度，Shift将最终角度
吸附到45度倍数。普通归一化保留正负180度边界；吸附使用原版余数规则，因此540度
一般归一化得到180度，吸附得到负180度。

角度计算保留鼠标原始双精度坐标。方向向量半径小于或等于0.1原图像素时不更新角度。
鼠标与变换后定点限定到最后一个原图像素，缩放最小尺寸为8原图像素。移动和缩放从
拖动开始时的快照计算，避免逐帧累积误差。

右键不开始旋转。左键旋转途中按下右键，恢复原始正文、角度及选中身份，取消的手势
不进入历史。提交后的撤销、重做恢复同一标注身份，选框与删除按钮不进入PNG导出。

## 绘制与文字

矢量正文直接旋转路径。文字使用实际字体缓存，在当前可见区域生成原始字形，再旋转
合成。旋转正文按128×128物理像素的固定网格绘制，整图与局部缓冲使用相同原点和
抗锯齿计算；单个分块占64 KiB，不分配第二张完整屏幕图像。

普通画笔和荧光笔的增量绘制只用于零角度的新笔迹，旋转或拖动已有笔迹使用完整正文
入口。渲染结束后恢复父变换，外围控制点不会重复旋转。

内联文字编辑器按照原版保持横向，提交后保留标注角度。实际Qt测量确认，单行扩宽
可以只改变存储矩形而不改变可见框；未换行时按自然字形收框，发生换行时Qt文档回退
尺寸保留请求宽度。存储高度不决定实际排版高度。原生缩放验证使用缩窄到实际换行的
手势，不把单行扩宽没有画面变化判定为失败。

## 原版生产对照

参考仓库为只读的 `/home/snemc/workspace/mark-shot`。采集器仅在本项目的 `target/`
新目录编译，核对采集前后的原版源码指纹。

`scripts/annotation-rotation-reference.py` 提取完整生产函数：

- `normalizedRotationDegrees`、`rotationDragDegrees`、`snappedRotationDegrees`
- `ShotWindow::clampImagePoint`、`ShotWindow::resizedBounds`

得到18个角度、72个方向阈值和384个八方向缩放样本。缩放样本再覆盖四种比例及两种
画布原点，共3072个映射场景；坐标误差上限为 `8 × f32::EPSILON × 640`，
约0.00061原图像素。普通矩形四角和旋转点另对照72个生产Qt选框结果，误差小于0.0001。

`scripts/annotation-rotation-text-reference.py` 提取完整字体构造及文字测量函数，包含
`textAnnotationWraps` 和 `textAnnotationBoxSize`。Qt 6.12.0、Noto Sans、96 DPI下，
三种正文、六种存储宽度、三种存储高度和三种比例共162个实际样本通过对照；字形引擎
取整差异限制为1像素。结果及指纹分别位于：

- `tests/fixtures/qt-annotation-rotation/reference.json` 和 `index.json`
- `tests/fixtures/qt-annotation-rotation/text-reference.json` 和 `text-index.json`

独立宿主提供必要类型和字体条件，只执行采集函数，没有运行完整Qt窗口或群组编辑。
上述对照不表示Qt与Rust的全部字形和抗锯齿像素完全一致。

## 像素及原生验证

五类矢量和文字在90、45、负37度，1、1.25、1.5、2倍比例，以及两种原点下共144个
局部绘制场景通过检查。局部范围与完整输出逐像素一致，范围外保持透明。90度文字
旋转另核对全部字形像素；测试没有放宽为只比较边界或部分内部像素。

私有Sway与不可见Xvfb中的niri在1.5倍输出下，通过实际输入创建六类普通标注。
每项检查可见控制点、实际正文宽高交换、45/90度吸附、右键隔离及取消、精确撤销重做、
旋转后的缩放与移动、PNG导出；文字另检查横向编辑器、旋转提交和编辑历史。

每个合成器另复核标注删除、十四类工具、字段、尺寸、主选择与完整截图翻译，共十四套
命名流程，使用同一构建指纹。汇总包含180次真实资源采样，各静止采样组保持单线程，
CPU计数和缓冲提交不增长。

一次niri尺寸回归的截图早于最后缓冲回调36毫秒，旧深色画面触发逐像素失败。
`scripts/wayland-selection-size.py` 现等待本次完整缓冲及回调完成，再执行同一像素判据；
Sway和niri复核均通过。原始现场保留在 `target/rotation-rel-niri-r3/size/`，复核位于
`target/rotation-size-sway-r4/size/` 和 `target/rotation-rest-niri-r4/size/`。
