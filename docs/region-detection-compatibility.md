# 窗口与 UI 区域识别对照

原版区域算法、捕获前窗口快照和编辑器悬停工作流已接入。候选独立于正式选区，
支持短点击采纳、滚轮切换包含层级和手动拖选。整体重写目标继续保留。

## 已实现范围

`src/features/region_detection/` 按候选、游标、分析、边缘、提案、评分、精修及
独立图像运算拆分。截图只分析一次，后续悬停和滚轮查询不重新处理图像。

- BT.601 整数灰度、可分离高斯、Sobel、非极大抑制和八邻域 Canny
- 方向色差边、弱直线提升、形态运算与四邻域及八邻域连通域
- 轮廓、背景和并行直线提案，边界评分、纹理惩罚与原图精修
- 控件和窗口独立排名，窗口外四像素容差及完整包含链
- 普通悬停三像素容差、滚轮层级六像素容差，正滚轮扩大、负滚轮缩小
- 最高窗口层级选择，全部层级缺失时按较小面积回退

最大分析边长为 1280，提案上限 4096，精修和图像候选上限均为 512。
不透明预乘输入借用原始像素；透明输入独立解除预乘。
临时标签和连接栈使用三十二位索引，查询器仅保留候选与图像尺寸。

## 缩图差异修复

初次回归在真实工具栏图像失败：Rust 得到 21 个候选，Qt 为 16 个，缩图 RGBA
摘要也不同。独立探针确认原始像素和目标尺寸一致。

Qt 对不透明预乘截图使用十四位面积采样；普通 ARGB 小图在缩小不超过两倍、
原图面积小于 1048576 像素时使用绘制器。后一条路径在十六位预乘空间进行
双线性插值，反变换前加入一个定点单位的坐标平移，再分别截断通道乘积。
Rust 已分别实现两条路径，修复后全部 116 个场景通过。

源码依据为 Qt 官方 `qt/qtbase` 的 `qimage.cpp`、`qimagescale.cpp`、
`qdrawhelper.cpp`、`qpaintengine_raster.cpp` 及本机 `qrgba64.h`。
下载内容与独立像素探针分别保留在 `target/qt-region-scaling-source-r1/` 和
`target/qt-region-scaling-debug-r1/`。

## 窗口快照与共用 IPC

niri 窗口捕获的通用连接已拆到 `src/backend/wayland/niri/ipc.rs`，继续使用
内核 PID/UID 校验、有界换行读取与可取消异步请求。活动窗口身份和输出比例
保留在捕获专用 `target.rs`。

`src/backend/window_detection/` 在覆盖层映射前取得窗口信息。niri 使用窗口、工作区、
输出、Layers 和配置，优先读取精确 tile 边界，旧版本按活动列、gaps、struts、配置
include 及面板独占区计算几何；96 个实际原版几何场景记录在
`tests/fixtures/qt-niri-window-detection/`。Sway 读取当前工作区的平铺与浮动树并保留
焦点层级。总期限为 500 毫秒，回复上限 1 MiB。配置文件读取限制总大小与 include
深度，拒绝非普通文件。

图像和窗口识别分别由以下配置控制，两者默认开启：

```toml
[region_detection]
enabled = true

[window_detection]
enabled = true
```

同时关闭时跳过窗口请求和图像分析。仅开启窗口识别时不创建图像分析任务。

## 编辑器输入与生命周期

`src/app/region_detection/` 将状态、任务、坐标、输入、移动阈值和绘制分别组织。
单输出任务共享 `FrozenPixmap`，多输出仅合成一次。分析完成通过 `task_wake` 唤醒，
工作线程完成或取消后回收；不保留线程池，也不设置持续轮询计时器。

悬停使用 RGB 94、234、212 的薄荷色直角边框，宽两个逻辑像素，填充透明度为 32。
此阶段不创建正式选区或显示正式选区工具栏。左键按下后，移动距离小于五个逻辑像素
才允许在释放时采纳；达到五像素后撤销候选，转为手动拖选，返回原点也不重新采纳。
采纳沿用八图像像素最小尺寸检查、默认工具切换和区域直接交付。右键和 Esc 保留
原版选择阶段取消职责。正滚轮扩大，负滚轮缩小，层级容差继续使用图像像素。

合并指针轨迹保留实际位置。水平或垂直共线移动只保留实际端点，非共线位置分别记录，
每批最多 128 条，界面仅绘制最终位置。五逻辑像素判断遍历这些端点，不把分别出现的
横纵极值拼成未经过的矩形角点。跨输出坐标加上各输出逻辑原点，不乘物理比例。
旧框和新框均记录完整填充损坏范围；局部恢复必须与完整重绘逐字节一致。

## 原生差异诊断

私有 niri 的 X11 后端将滚轮按钮按下和释放各转换为一次完整刻度。一次
`xdotool click 4` 因而使候选从子控件越过父面板到窗口。独立探针分别发送按下和释放，
确认前者选择父面板、后者选择窗口。同一原始截图调用 Qt 采集器得到相同层级。
证据保留在 `target/verification-region-detection-r1/wheel-probe-r1/` 和
`target/qt-region-native-niri-r1/`。测试在按下后验证一刻度，交付结束后释放按钮，
同时断言客户端只收到一次轴事件。

分数比例输出不能使用 grim 的默认图片作为原始像素基线：一点五倍时，逻辑尺寸
取整使其重新采样为 1280×799，而协议缓冲为 1280×800。原生脚本现使用独立
wlr-screencopy 客户端读取完整缓冲。这个基线又发现导出按横纵逻辑尺寸分别缩放的
问题；合成现按捕获比例统一映射两轴，原生比例直接复制像素。捕获比例按 Wayland
一百二十分之一单位还原，避免 1280÷853 引入 1.500586 的误差。

私有 X11 指针转换也可能产生分数端点。手动拖选期望裁切从实际 Wayland 端点独立
计算，并还原二百五十六分之一坐标精度，不假定请求坐标与接收坐标相等。
