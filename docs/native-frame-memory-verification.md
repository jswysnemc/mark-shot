普通编辑、长图结果编辑以及实际工具矩阵仍有失败指标；Windows 工作流尚未完成。

## 画面差异与轨迹修复

旧工具检查首次看到正文变化便保存，尺子因此保存了手势中间帧。新检查保存全部过渡帧，
完整画面连续静止至少 0.8 秒且正文变化超过 200 像素后才交付最终 PNG。
R13 与 R14 终态尺子逐像素相同，画笔仍有 620 个差异像素，范围为
`[800,607,1453,930]`。证据在 `target/memory-verification-r14/stable-pixel-comparison-r13.json`。

真实工具回归在修复前失败：合并输入只分派最终位置，画笔丢失中间角点和折返位置。
当前合并队列保留有界、按顺序排列的真实点，只移除相邻重复点；自由画笔与荧光笔在
一次事件处理中消费中间点，仍按显示器节奏提交帧。回归核对真实笔迹及全部光栅字节，
修复后与逐点输入一致。失败和通过日志为 `target/pointer-history-red-final-r15.log` 与
`target/pointer-history-green-r15.log`。

R15 画笔与充分静止后的 R13 逐像素相同。R16 三项工具的最终画面均与 R15 相同，
矩形及尺子也与 R14 终态相同。实际协议检查确认每个普通前景最多两个缓冲，冻结背景
使用一个独立缓冲，没有释放前重复活动提交；证据在
`target/memory-verification-r16/tools/contract-and-final-pixels-r15.json`。

## 原生驻留与失败指标

背景仅上传一次，按来源行访问维持读取预算。前景复制只保留非零页，释放后的备用页
继续归还；透明共享页测试核对真实物理驻留、损坏范围外字节及通道转换。
R15 仍预先触碰浮层共享池，R16 去除了普通原生帧和冻结背景的这次写入。
该修改未解决全部超标：整屏遮罩和边框仍占有完整前景中的物理页，独立背景也占有内存。

下表稳定值与观测峰值均计入应用及子进程 RSS、原件/冻结文件的未映射缓存和原生共享
文件的额外驻留。文件按 device/inode 去重；测试页面、合成器与测量脚本单独运行。
25 毫秒采样与 VmHWM 分别保留，VmHWM 不包含未映射额外文件驻留。

普通编辑峰值和稳定 PSS 失败；滚动增长通过本轮内存门槛，结果编辑稳定 RSS/PSS 失败。
三项工具计入额外文件驻留的峰值均失败；画笔稳定 PSS 和尺子稳定 RSS/PSS 也失败。
各组 JSON 保留所有失败键，按本轮自己的 Qt 基线计算，不替换为较高的历史值。

R16 分层方案在上述普通编辑及工具场景中尚未优于 R14 的总量，不能作为满足内存要求
的实现。后续需要减少前景中遮罩、整屏细边框及连续提交时的物理页重叠。
