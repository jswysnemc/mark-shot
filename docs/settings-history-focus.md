# 设置、历史重选区与贴图改进

截图工具栏打开设置时，当前截图会话先关闭，再启动独立设置进程。设置窗口保持打开时可以开始新截图。

翻译设置中的测试原文支持多行编辑、选择、复制、粘贴和输入法。测试请求使用当前草稿，“恢复默认原文”恢复目标语言对应的示例。草稿保留在本次设置会话中，不写入翻译凭据或配置文件。长路径编辑时输入框展开到整行，恢复和保存按钮仍在字段右侧；底部字段展开后自动滚动到可见位置。

“关于”是独立导航页面，展示版本、操作系统、桌面环境、窗口管理器或合成器、显示协议。Linux 桌面环境来自会话变量；窗口管理器使用已知合成器变量、Wayland 套接字对端进程或 X11 EWMH 名称识别。无法确认的信息显示“未识别”，不将桌面环境名称当作窗口管理器名称。

## 历史重选区

成功完成的新截图保存两份 PNG：`capture-…png` 是最终完成图，`original-…png` 是对应的完整、未标注原图。选择历史记录后点击“重选区”，完整原图进入区域选择模式；“编辑”继续打开原完成图。旧记录没有完整原图时，“重选区”按钮不可用。

完整原图与完成图共同计入容量限制，删除、清空和数量淘汰同时处理两份文件。原图先落盘，完成图任何写入步骤失败时清理原图；异常退出产生的孤立原图在下次保留策略执行时清理。路径和 PNG 验证沿用原有历史存储规则。另存为和无界面 `--capture-to --region` 也保存原图；本地图片编辑使用原始图片，不保存屏幕预览作为原件。

## 剪贴板贴图

贴图入口支持剪贴板图像、纯文本、HTML 正文、颜色和复制文件。

- 色值支持 `#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`，以及三个 0–255 整数或 0–1 小数。色卡展示颜色、HEX 和 RGB。
- HTML 保留可读正文、段落换行和字符实体，忽略脚本、样式和标签；不保留网页 CSS 排版。
- 单张图片文件始终贴出图像；其他文件、多文件和特殊文件显示路径文字。
- 设置“贴图与外框 → 将文件路径贴为文字图片”控制路径文字转换，配置键为 `pinned.file_paths_to_image`，默认开启。

Windows 使用剪贴板序号、X11 使用选择拥有者识别新复制操作；只有这些平台在再次贴同一份剪贴板文件内容时才显示路径。Wayland 没有公开剪贴板版本，无法区分“再次复制同一路径”和“再次贴同一份剪贴板”，因此始终贴出图片。文件重复状态保存在用户状态目录，普通图片和文本贴图不依赖配置目录写权限。

## 聚焦滤镜

按 `M` 或 `X` 选择马赛克工具，在效果菜单选择“聚焦”或“椭圆聚焦”。框内保留图像，四周覆盖黑色遮罩，不使用彩色描边。强度控制外围暗度；矩形聚焦支持圆角。旋转、撤销、重做及最终 PNG 导出使用同一几何。

新增、删除、切换效果及修改暗度时，整个绘图范围参与损坏更新。移动、调整尺寸或旋转时，只更新新旧孔洞和控制框范围，并按原图层顺序重绘相交成员。遮罩使用固定像素块，不生成原图滤镜缓存或整屏标注缓存。

性能复现入口：`cargo test -p mark-shot --lib --locked focus_interaction_frame_budget -- --ignored --nocapture --test-threads=1`。它通过真实指针与帧绘制入口测量 1080p、4K 下移动和调整的耗时，正常回归另行检查局部损坏范围与完整帧像素一致。
设置 `MARK_SHOT_FOCUS_BENCH_LARGE=1` 可测量接近全屏的聚焦范围；加上 `--release` 可测量优化构建。

## 验证入口

Rust 回归覆盖真实翻译请求、完整原图像素和成对清理、文件及色值分类、聚焦像素及撤销。`scripts/settings-history-workflow.py` 在私有 Xvfb 中验证设置交接、新截图、完整原图保存、路径布局和历史重选区，不操作当前桌面。Windows 原生剪贴板格式测试要求私有测试会话，通过现有 Wine 测试运行器执行；Wine 结果不等同于 Windows 实机验证。
