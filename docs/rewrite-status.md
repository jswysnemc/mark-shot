Windows 主应用已接入共享业务与原生后端，私有 Wine 中的截图、编辑、剪贴板、保存和
基本贴图、真实模型下载、OCR 推理与独立结果编辑实际流程通过。完整 Windows 交互、
中文输入法和真实 Windows 11 验证尚未完成；
不把通过编译或基本流程视为完整重写完成。
