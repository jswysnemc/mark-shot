# 截图交互与设置

## 取色标注

取色工具在原始图像上按下时保存该点颜色，释放后创建带引线、色块和十六进制值的标注。
按住拖动可以放置标签。标注支持选择、移动、缩放、旋转、撤销和导出；移动指针不会改变
已经取样的颜色。完成后滚轮调整标签字号。

悬停时实时更新原图颜色，与画笔颜色、已完成标注分开保存。取色使用指针对应的原始像素，
不使用缩放预览或双线性混合值。`Ctrl+C` 复制当前 HEX 值。

单击取样后显示颜色格式面板，也可以点击属性栏的格式按钮打开。面板包含当前色预览、
历史色块和八个独立复制按钮：HEX、hex lower、RGBA hex、RGB、RGBA、HSL、HSV、Qt。
面板打开期间冻结颜色，移动到复制按钮不会取到面板自身颜色。复制后保留截图与标注；
“继续取色”或 `Escape` 返回采样。拖动放置标签后不自动打开面板，滚轮可立即调整字号。
历史颜色沿用调色板的持久化记录。调色板中的单次取色仍只修改绘图颜色，不创建标注。

## 选区控制点

任意工具下，指针进入选区四角和四边中点时显示缩放光标，按住拖动直接调整选区，完成后
保留当前工具。控制点命中范围按窗口逻辑像素计算，不会随图片缩放扩大或缩小。
工具栏、弹层与文本字段保留正常输入优先级，选区内部继续交给当前工具。
普通边线不再作为整条缩放热区；指针离开选区和八点范围后显示普通箭头，拖动中的控制点
保持缩放光标直到释放。

## 设置窗口

通过工具栏齿轮、`Ctrl+,` 或 `mark-shot --settings` 打开独立原生窗口。
从截图编辑器打开时暂时隐藏覆盖层，关闭设置后恢复选区、标注与撤销记录。
分类参考 shotori 的任务组织方式，界面继续使用本项目的字体、主题和原生控件：

- 外观与语言：语言、明暗主题和完成通知。
- 截图与标注：默认完成操作、保存目录、文件名与月份子目录、指针、默认工具、区域识别和历史。
- 快捷键：点击字段后按下新组合；冲突会显示错误并保留原绑定。
- 文字识别：引擎生命周期与计算设备。
- 高级：覆盖层方式、诊断日志和当前配置路径。

`Ctrl+F` 搜索设置；`Tab` 在当前结果中移动焦点；`Enter` 激活或确认；`Escape` 先关闭
菜单或取消输入，再关闭窗口。开关、选项和快捷键即时保存，文本字段通过保存按钮或
`Enter` 确认。内容溢出时显示可拖动滚动条，可点击轨道、使用滚轮以及 `PageUp`、
`PageDown`、`Home`、`End` 翻页。滚动不会直接丢弃尚未提交的文字。

设置行说明实际业务用途和生效阶段：

- 主题立即更新；保存目录、文件名、月份子目录、通知和截图内快捷键在当前进程生效。
- 从设置返回时同步默认完成操作、选区放大预览和框选后工具，不改动现有标注和撤销记录。
- 鼠标捕获、窗口方式、区域识别、图片初始工具和识别引擎生命周期在下次截图生效；
  日志等级在下次启动生效。快捷键页不负责注册桌面全局热键。
- 不支持 GPU 的构建不提供 GPU 选项。无效日期格式和冲突快捷键不会覆盖原配置。

写入沿用命令行指定的配置文件和现有原子锁，单项修改保留其他字段、TOML 注释及文件格式。
业务流程读取共享配置快照，不在每次指针移动或绘制时重新解析配置文件。
