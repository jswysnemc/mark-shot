# 截图历史兼容与隐私边界

功能参考原版 `qt/src/capture_history/`，存储命名参考 `history_store.cpp`，窗口操作参考
`history_window_actions.cpp`。本实现不加载 Qt，不修改原版仓库或原 JSON 配置。

## 入口与完成行为

| 行为 | 当前实现 |
| --- | --- |
| 独立入口 | `--history` 打开普通 Wayland 窗口，不启动捕获运行时或 OCR |
| 截图内入口 | `Ctrl+H` 在无未完成手势时交接，历史首帧就绪后取消原截图会话 |
| 自动记录 | 完成普通、区域、立即或长截图图像导出，以及成功的无界面捕获时记录 |
| 取消 | 不记录取消截图、未完成草稿或单纯打开历史的操作 |
| 原图复制 | 保存 PNG 原始像素及透明度，关闭历史窗口不丢失剪贴板 |
| 贴图 | 打开独立贴图窗口，不产生重复记录 |
| 另存为 | 使用打开对话框时的原图快照，不重新编码 IDAT，不产生重复记录 |
| 重新编辑 | 通过匿名文件进入原图编辑器，完成后新增一项，取消不新增 |
| 删除与清空 | 删除选中项；清空需要显式确认，默认 Enter 取消 |

历史窗口支持 760×460 与 360×360 布局。窄窗口把原图预览放到列表下方，全部设置及
操作按钮保持可访问。截图中的共用另存为入口、贴图高级操作及其他图形设置仍未完成，
不把历史另存为视为全部导出工作流已经接入。

## 策略与配置

```toml
[history]
enabled = true
limit = 50
max_size_mib = 256
directory = ""
index_annotations = false
```

数量范围为 1–200，默认 50；总量范围为 1–4096 MiB，默认 256 MiB。数量或总量超出
预算时删除最旧项。新图本身超过容量预算时拒绝记录，不删除已有项。

窗口提供记录开关和数量设置，调整数量立即执行清理。容量和目录通过 TOML 配置。
默认目录为 `$XDG_DATA_HOME/mark-shot/capture-history`，未设置数据目录环境变量时采用
`~/.local/share/mark-shot/capture-history`。自定义相对目录按当前工作目录解析。

首次禁用时，捕获和打开空历史窗口均不创建历史目录。窗口设置和辅助进程遵循
`--config`，原子更新保留其他字段、未知字段和注释。使用覆盖路径时不改写默认配置文件。

## 搜索与隐私

日期、尺寸和文件名搜索始终可用。附加标注文字索引默认关闭；启用 `index_annotations`
后，原始文字写入 PNG 的 `mark-shot-history-search` 元数据。

文字索引可能包含最终画面中已经裁掉或遮盖的原始标注文字。关闭开关仅影响新记录，
不会清除旧 PNG 中已有索引。复制或另存为历史 PNG 会保留其中的元数据。

历史本身包含截图内容，不提供加密。目录首次创建为 0700，记录为 0600；已有自定义目录
不自动更改权限。临时编辑快照为匿名 0600 文件，异常退出不会遗留命名临时截图。

## 存储与资源

文件名采用 `capture-<UTC 毫秒时间>-<32 个小写十六进制字符>.png`。同一目录的写入在
锁内生成严格递增的毫秒时间，不依赖随机标识排序；锁等待有一秒上限。

目录固定在已打开的描述符上，拒绝末级目录链接。读取和删除拒绝任意路径、非法身份、
符号链接及多重硬链接。清空仅处理符合身份规则的单链接普通文件，包括损坏记录；无关
文件和链接不属于清理范围。

自动记录复用原 PNG 的 IDAT，不建立 JSON 索引或持久缩略图。比例元数据的有效范围为
1–16，范围外按 1 处理。PNG 字节上限为 320 MiB，总像素上限为 64 Mi；访问还受历史
总量预算约束。原图编辑器受 256 MiB 解码预算约束，不再直接拒绝超过 16384 像素高度的长图。

预览逐行缩小，支持隔行、灰度透明和调色板 PNG。原图预览缓存最多 8 MiB，缩略图最多
4 MiB。临时工作线程使用 eventfd 唤醒窗口，正常任务结束后退出，空闲不持续轮询。

保存对话框支持 Home、Up、Alt+Up、目录行、键盘选择、隐藏目录、Unicode 名称和新建
目录。目录行单击进入；新建目录刷新当前列表并恢复原文件名，不自动进入新目录。
覆盖确认默认取消，显式替换前核对目标文件身份。

## 此前证据

历史专项验证构建为 42220568 字节，SHA-256 为
`7d6422f6da1fe291d2bf83b0cbf422ce26365a724cb6b401d6b6d49d6793f80f`。

- `target/wayland-history-r3/`：自动记录、原图 RGBA、默认索引关闭、中文搜索、复制、贴图、另存为、覆盖确认、删除后的保存快照、重新编辑、数量清理和配置保留
- `target/wayland-history-edges-r3/`：首次禁用不创建目录、忙碌 Ctrl+H、独立窗口交接、144×20000 长图完整重编辑及全部目录操作
- `target/verification-history-gesture/`：548 项 Rust 测试、6 项忽略、严格 Clippy、手势回归先失败再通过的日志

上述真实回归使用私有 Xvfb 中的 niri，物理尺寸 1280×800、分数缩放 1.2、Flipped180
输出变换，不操作真实桌面。采样中的历史窗口均为一个线程，一秒空闲 CPU 增量为零。
这些结果不代表全部合成器、全部设备或全部文件格式已经完成运行验证。
后续文字事务与菜单构建没有重新运行这组历史窗口场景，不把旧构建证据当作当前二进制验证。
