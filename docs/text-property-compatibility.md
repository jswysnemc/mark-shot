# 文字属性栏与字体弹层对照

本阶段以原版 `ShotWindow` 实际控件为参考，不使用 LumineCapture 的属性栏外观。
应用仍使用 Rust、Wayland、tiny-skia 和 cosmic-text；Qt 只进入开发探针，不进入应用依赖。

## 原版几何

默认文字属性栏为 438×44，选择工具下选中已有文字时为 476×44。
新增的三十八像素用于编辑按钮与间距。

| 控件 | 本地矩形（x、y、宽、高） |
| --- | --- |
| 字号图标 | 10、8、19、28 |
| 字号滑条 | 35、14、88、15 |
| 字号标签 | 129、6、34、32 |
| 透明度图标 | 171、8、19、28 |
| 透明度滑条 | 196、14、76、15 |
| 透明度标签 | 278、6、36、32 |
| 主色按钮 | 322、6、32、32 |
| 背景按钮 | 360、6、32、32 |
| 字体按钮 | 398、6、32、32 |
| 编辑按钮 | 436、6、32、32 |

滑条轨道高四像素，手柄为 14×12。字号滑条范围为 -11–281，标签显示点字号减十九，
实际点字号范围仍为 8–300。数值靠右对齐，采用十像素、700 字重。
颜色、背景、字体和编辑按钮使用原版 SVG，不以字符代替图标。

字体弹层默认 360×360。搜索为 `[6,7,348,28]`，列表为 `[6,40,348,280]`，
字号为 `[6,326,288,26]`，粗体与斜体按钮分别为 `[298,326,26,26]`、`[328,326,26,26]`。
列表行高二十八像素，最多显示十个完整行；过滤不缩小面板。
纵向滚动条宽十四像素，上下按钮各十四像素，最小手柄高二十六像素。

## 已接入行为

- 属性滑条、字体按钮和编辑按钮进入真实鼠标路由；按钮只在左键同位置释放时执行
- 左键抓取滑条手柄保留抓取偏移，轨道点击按十单位翻页，按住轨道重复翻页
- 字号或透明度滑条每次实际变化分别记录撤销；字号同步工具默认值，透明度不覆盖默认颜色
- 打开字体弹层清空搜索、获得搜索焦点并按完整行居中当前字体；选择字体后关闭
- 搜索、字号、粗体、斜体、列表滚轮和滚动条分别接收输入；弹层与颜色选择等面板互斥
- 有效字号即时应用，低于八点的输入可保留为中间值，超出三百点的输入拒绝；字号字段 Return 提交当前文字但不关闭面板或导出截图，Escape 只关闭字体弹层
- 搜索与字号文字在独立小缓冲内裁切，长输入不覆盖其他控件

## 字体目录与缓存

目录只在首次打开弹层时枚举。Fontconfig 排除可变字体主体，保留命名实例元数据。
同语言、不同样式的附加名称登记为子家族，其余附加名称仅作为别名。
家族名称排序，家族内部保留代工厂登记顺序；多个代工厂使用方括号后缀。
三种通用家族为 `Sans Serif`、`Serif`、`Monospace`。

预览只加载可见行字体，完整页最多十个、部分行最多十一个。页面变更时重建预览
`FontSystem` 并清空对应 `SwashCache`，关闭弹层时释放预览；删除 fontdb face 不能代替
这一步，因为 cosmic-text 字体缓存可能仍持有文件数据。正文与其他界面的字库不受预览修改影响。

规则对照来源：

- 原版 `qt/src/shot_window_setup.cpp`、`qt/src/shot_window_layout.cpp`
- 原版 `qt/src/shot_window_font_panel.cpp`、`qt/src/ui/toolbar_panel_style.cpp`
- [Qt Fontconfig 后端](https://code.qt.io/cgit/qt/qtbase.git/plain/src/gui/text/unix/qfontconfigdatabase.cpp?h=dev)
- [Qt 字体数据库](https://code.qt.io/cgit/qt/qtbase.git/plain/src/gui/text/qfontdatabase.cpp?h=6.10)

探针链接原版已构建对象，只替换本项目中的程序入口；依赖过期时拒绝构建。
输出与配置全部使用独立目录，不修改原版源码、对象或用户配置。

## 实际对照

同一隔离字体环境下，Rust 与 Qt 的 2366 项家族名称及顺序一致。
对照文件位于 `target/text-properties-native-verified/comparison.json`，原版探针位于
`target/qt-property-reference/reference-dark-r6-*`。这项结果不代表所有机器字体集合相同。

## 字号输入与撤销

`setSelectedTextFontSize` 委托原版宽度入口，不能把字号与字体家族的默认值策略视为相同。
统一的 `editor/text_size.rs` 现在对应这一入口：实际字号变化同步默认字号；同值输入不覆盖默认值、
不创建历史。单行文字重新按自然宽度收框，已换行框宽乘以新旧点字号之比。
历史快照不含工具偏好，因此撤销恢复标注字号和框宽，默认字号仍保留最后一次修改。
编辑预览另有局部字体历史：实际字体、字号、粗体和斜体动作恢复文档格式，不回退默认值
或持久对象样式。控件导航、普通刷新及边界同值不追加格式记录，直接字号 setter 则保留
原版格式操作。取色动作与透明度滑条使用不同入口，后者不插入字体历史。

| 输入入口 | 标准刻度 | 小刻度与反向 | 纯像素 |
| --- | --- | --- | --- |
| 画布 | 每刻度 1.5 点 | 有符号余量朝零截断，时间间隔和反向不清除；换目标清除 | 每 80 像素一刻度 |
| 属性滑条 | 每刻度三格 | 反向清除余量；Ctrl/Shift 按十格翻页，朝零截断，不累积翻页余量 | 忽略 |
| 字号输入框 | 每完整刻度一点，Ctrl 为十点 | 累积角度刻度，反向保留余量 | 忽略 |
| 字体列表与滚动条 | 每刻度三行 | 反向清除余量；Ctrl/Shift 按可见行数翻页 | 忽略 |

滑条的单次滚轮增量不超过翻页步长。字体列表按完整行定位，不把原始像素乘以八十四。
Wayland 轴事件保留高分辨率 value120、旧 discrete、像素、来源、方向与停止信号；纵轴只反号一次。
真实 Wayland 事件可以同时携带角度和像素，角度优先，不能重复叠加。缺少离散刻度时，Qt 6.10
按每帧像素位移乘十二并取整，触控板同样生成角度；适配层对应这一规则。表中纯像素指明确没有
角度的事件，不表示真实 Wayland 触控板必然走纯像素路径。
平台规则见 [Qt Wayland 输入实现](https://github.com/qt/qtbase/blob/6.10/src/plugins/platforms/wayland/qwaylandinputdevice.cpp)。
画布的连续修改共用 350 毫秒防抖历史；独立输入和撤销前提交挂起快照，到期后不保留空闲轮询。

实际 Qt 样本位于 `target/qt-text-size-inputs/reference-sizes.json`。探针先按原版完整打开入口
确定 360×360 弹层与 280 像素列表，再驱动真实滑条、数字框、列表、滚动条、画布及撤销。
`tests/fixtures/qt-text-size-inputs.json` 保留二十八组记录，生产输入路由逐组比较字号、默认值、
列表行位置和画布余量。未打开完整弹层时列表只有三行，此类中间布局不作为最终参照。

修改前失败回归保存在 `target/text-size-policy-before.log`，修复后结果和实际输入记录位于
`target/text-size-policy-after.log` 与 `target/text-size-native-traces/native-traces.json`。

同一 release 的真实 Wayland 回归位于 `target/wayland-size-events-final/`、
`target/wayland-size-font-final/` 和 `target/wayland-size-text-final/`，汇总记录位于
`target/verification-text-size-inputs/result.json`。两次独立滚轮输入耗时 131.406 毫秒，
一次撤销从二十三点恢复二十点；超过三百五十毫秒的输入分别恢复二十一点、二十点，
保存的默认字号仍为二十三点。实体触控板和其他合成器尚未实测，不把源码对照当作完整运行矩阵。

## 未完成的对照

几何一致不等于逐像素一致。字形、抗锯齿、界面字体以及部分可变字体命名实例预览仍有差异，
尤其不能将命名实例索引低十六位对应的基础 face 当作已经完整应用全部变化轴。
亮色主题、字段鼠标定位与拖选、字段局部撤销、搜索输入上限、字段右键菜单、最近字体分组及完整停靠位置矩阵
仍需继续对照。
字号入口的数值与历史对照不代表其他工具宽度滚轮、滚轮预览、画布缩放或平移已经完整兼容。

文字本体已接入独立编辑事务、Esc/Ctrl+Enter 提交、空白文字处理、字符拖选与标注移动分流，
文字区右键菜单与局部正文历史已经接入，具体边界见 `docs/text-editing-compatibility.md`。
字体局部历史、字号字段 Return 提交和属性来源隔离已完成真实 Qt 状态对照，
具体构建与合成器边界见 `docs/text-editing-compatibility.md`。
完整角点字号缩放、选区边缘换行和位置回移与输入法仍未完成。
本阶段不代表原版文字工作流或完整重写已经完成。
