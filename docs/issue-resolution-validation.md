- Rust 工作区：1757 项通过、0 项失败，46 项因网络、模型或特定平台条件按既定标记忽略。测试使用独立 XDG 目录、英文系统语言，清除外部 `MARK_SHOT_LANG` 覆盖，保持单项测试自主设置语言的能力。

- Rust 格式检查和差异空白检查通过。
- Python 验证工具：238 项通过；打包测试：79 项通过。
- 官方运行库额外验证：归档解包测试通过；生产下载入口成功安装并初始化 `ort::session::Session::builder()`。这两项按名称单独执行，不属于默认忽略项通过计数。
- 主题运行时回归：替换为原始主题实现时测试因门户请求超时失败；恢复独立连接后通过。
- 私有 niri、总线和 PipeWire：成功、取消、拒绝授权、来源取消及失效令牌重试五个实际协议场景通过。暂停期间线程计数和 CPU 采样稳定，退出时关闭对应授权会话。

- 页锁定采样脚本：无操作命令的两轮校准均为零净增量；此结果只验证采样工具，不代表 KDE 泄漏修复结果。
