# 独立 OCR 窗口输入法对照

## 范围

OCR 原文和已经开启编辑的表格单元格接入原生 Wayland text-input-v3，复用截图窗口的
协议消息归属、原子批次和过期目标校验。原图、按钮、菜单、失焦及关闭编辑的单元格
不接受候选或确认。窗口不因编辑操作初始化 OCR 模型。

本阶段不代表完整重写完成。原版历史窗口没有搜索与数量输入框，当前原生界面多出的
这两个控件仍是兼容性差异，不作为新增原版功能计入完成状态。

| `scripts/wayland-window-input-method.py` | 私有合成器中的真实协议与画面验证 |

## Qt 参考

本仓库的 `tests/fixtures/qt-window-input-method/` 探针使用 Qt 6.12.0，直接操作
`QTextEdit`、`QLineEdit` 和 `QTableWidget`。原版 OCR 原文使用 `QTextEdit`，表格
默认编辑器为 `QLineEdit`；探针不修改原版 Qt 源码。

冻结样本 `tests/fixtures/qt-window-input-method.json` 包含 35 组编辑器场景和 7 组
表格场景。逐操作比较正文、UTF-8 光标与锚点、选择文字、撤销及重做能力。
Qt 的 UTF-16 相对替换转换为合法字节；协议无法表达的相对范围通过生产编辑器接口
测试，不计为原生 Wayland 交付。

| 行为 | 对照结果 |
| --- | --- |
| 多行连续确认 | 每次确认独立撤销；撤销恢复光标但不恢复字符选择 |
| 单行连续确认 | 相邻确认合并；撤销恢复原文字、光标和字符选择 |
| 选择与候选 | 候选开始可以删除所选正文；候选内容不进入复制或历史 |
| 相对替换 | 拒绝非 UTF-8 边界、越界及超限批次，合法确认与删除整体应用 |
| 单行换行与制表符 | 保留逻辑文字；显示副本绘制为空格，不使用显示文本生成业务输出 |
| 单元格选择 | 单击只选择；双击、F2 或普通键入开启编辑 |
| 单元格写回 | Enter、Shift+Enter 提交并保持单元格；Tab、Shift+Tab 提交并循环选择 |
| 单元格取消 | Escape 丢弃草稿，不改变此前已经写回的表格 |
| 原文快捷键 | Ctrl+Shift+C 始终复制 OCR 原文，即使当前显示表格 |
| 表格格式 | TSV、CSV、Markdown、HTML 通过格式菜单复制 |

## 显示与资源

候选只存在于独立显示编辑器，确认正文才进入业务编辑器。复制、表格导出和局部历史
不读取候选副本。周边正文最多 4000 字节，保留合法 UTF-8 边界和完整文档偏移；
超长选择或空字符上下文不进入协议。静止同步缓存正文与选择，不重复发送相同快照。
光标矩形使用实际显示编辑器的字形布局，候选位置不伪造为已确认光标。

0.75、1、1.2、2 倍绘制测试核验偏移原点和裁切。输入法要求隐藏光标时，聚焦画面
与无焦点画面逐像素相同，候选字形仍存在。活动候选可能复制完整多行缓冲，大文档
持续输入的内存与延迟尚未验证，不据静止测试宣称该路径低资源。

`target/window-ime-sway-r2/`、`target/window-ime-regression-*`、
