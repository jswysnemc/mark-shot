# OCR 原文右键菜单对照

## 原版依据

`tests/fixtures/qt-ocr-source-menu-reference/main.cpp` 只读链接原版
`OcrTextPane::showEditorMenu`，以实际右键事件打开 `markshot::ui::ContextMenu`，
不是构造一个相似菜单，也不使用 `QMenu` 替代。探针在独立临时配置和离屏环境执行，
使用原版应用暗色调色板，不修改 Qt 源码或构建对象。

冻结记录为 `tests/fixtures/qt-ocr-source-menu.json`，画面为
`tests/fixtures/qt-ocr-source-menu.png`。Qt 6.12.0 样本包含 21 个场景，记录正文、
光标、选区、剪贴板、撤销与重做资格，以及菜单行几何、快捷键和导航结果。

## 菜单契约

| 行 | 快捷键 | 启用资格 |
| --- | --- | --- |
| Undo | Ctrl+Z | 可撤销 |
| Redo | Ctrl+Shift+Z | 可重做 |
| 分隔线 | 无 | 不可交互 |
| Cut | Ctrl+X | 有字符选区 |
| Copy | Ctrl+C | 有字符选区 |
| Paste | Ctrl+V | 剪贴板有非空纯文本 |
| Delete | Del | 有字符选区 |
| 分隔线 | 无 | 不可交互 |
| Select All | Ctrl+A | 正文非空 |

原版探针还采集只读资格。原生结果窗口在识别完成后接收文档，当前没有识别期间的
只读编辑模式；不能据此声称已移植原版忙碌状态。

- 菜单使用 DejaVu LGC Sans，逻辑尺寸为 225×229，行高 29，两处分隔区域高 9。
- 右键保留光标和选区，即使点击选区之外；不把右键当作左键定位或拖选。
- 左键按下只准备动作，释放执行；右键菜单行不执行，禁用行和分隔线不高亮。
- 上下、Tab、Home、End 和翻页键跳过禁用项；首字母在可用匹配项之间循环。
- 菜单内编辑快捷键不修改正文，Escape 只取消菜单，外部首次点击不穿透父窗口。
- 菜单关闭后才修改正文或创建持久剪贴板源。菜单选区复制不改变全文复制反馈。

## 实现分工

| 文件 | 职责 |
| --- | --- |
| `src/backend/wayland/window/popup.rs` | 原生弹层、位置避让、有界缓冲、帧许可和关闭顺序 |
| `src/backend/wayland/window/popup_input.rs` | 表面身份分流、独立焦点与指针事件 |
| `src/features/ocr_result/source_menu.rs` | 原文菜单状态、缓存绘制、导航与会话校验 |
| `src/features/ocr_result/source_menu_actions.rs` | 编辑资格、局部历史及纯文本剪贴板操作 |
| `src/features/ocr_result/window_input.rs` | 主窗口鼠标与键盘输入 |
| `scripts/wayland-ocr-source-menu.py` | 同一二进制的私有 niri/Sway 回归 |

菜单为真正的 `xdg-popup`，可以伸出父窗口边界。创建时只使用当前真实鼠标按下的
座席和序列号，不缓存旧序列号。打开菜单取消显示候选、停止正文拖选并停用原生
输入法目标，关闭后重新协调资格。独立弹层焦点不等同于父窗口失活，过期表面和
会话编号不能触发新菜单动作。

父窗口、历史模态子窗口和菜单分别保持角色与缓冲。菜单最多持有三个当前尺寸
共享内存缓冲，静止菜单不提交帧或启动轮询。父窗口缩放改变时关闭旧菜单，不在
抓取过程中更换尺寸或比例。

## 验证边界

离屏探针未从 Shift+F10 或 Menu 键自动产生上下文事件；这不能证明真实 Qt Wayland
平台也不支持这些键。当前仅交付右键入口，没有把推测的键盘入口加入原版契约。
主结果窗口旧控件焦点遍历、光标闪烁、整页几何、全部 Unicode 排版与全界面逐像素
一致性仍需分别验证。菜单参考画面与本轮几何测试不代表这些范围已经完成。

私有桌面回归检查真实弹层角色和尺寸、选择保持、左右键职责、快捷键隔离、七项
编辑动作、禁用项、首字母导航、外部取消、先销毁再复制、持久剪贴板及静止资源。
预览版 4 的下载二进制在同一新增回归中复现“右键不创建原文菜单”，保留失败证据，
不把旧版本验证结果作为本轮成功证据。
