# 标注多选与群组变换对照

当前源码已经接入相交框选、有序选择编号、共同移动、旋转、缩放、批量属性和整组删除。
R3 候选已经通过本阶段自动检查与同指纹私有 Sway、niri 原生矩阵，尚未发布。
现有 `target/release/mark-shot` 对应此前文字存储版本，其文件与清单指纹保持不变。
完整 Rust 重写目标仍有未完成项。

## 编号与输入

选择保存有序且有效的对象编号，过滤重复值和已经删除的对象。持久图层顺序保持独立，
只有一个成员时才投影为旧单项索引。历史保存完整选择集合，同时兼容旧单项编号。

选择工具先命中已有群组控制框，联合框内的成员空隙同样可以开始共同移动。空白按下
立即清除旧选择并开始框选，松开后选择与框相交的成员。两边均须达到两个原图像素，
无需完整包含对象。框选本身不写历史。

每次共同变换从手势开始时的完整快照重算，不累计前一帧误差。收到第一次指针更新时
即捕获一次历史，包括零位移；完全没有更新的点击不捕获。Shift 吸附本次旋转增量，
成员已有角度分别保留。整组成员始终留在持久数组内，保持原始图层顺序。

右键、工具切换和焦点中断结束共同手势，保留已经更新的几何。再次选择同一个选择工具
保留群组。拖动期间撤销会结束旧手势，后续移动和释放不会再次提交；重做恢复同一集合。
红色按钮在左键按下时删除整个组，一次历史恢复全部成员、图层和选择顺序。

## 几何与批量属性

群组选框按各成员旋转后的可见范围组合。原图裁切和专用工具规则沿用完整 Qt 函数：

- 线条保存本地骨架和独立旋转角度，正文、命中、端点编辑和双击插入反向映射坐标
- 序号联合框只计气泡矩形，零面积尖端矩形不会扩大范围
- 放大镜采用镜框与实际源框的联合矩形，增加宽度、裁切后再旋转
- 圆形放大镜共同非等比缩放保留存储长宽，正文仍采用短边圆形，源框按短边和倍率计算
- 源框限制在原图内，保留请求源点；共同变换和批量改宽后重新计算放大镜旋转中心，再刷新正文边界
- 长度尺模型使用角度，滤镜、序号和放大镜模型使用弧度；角度尺直接旋转三个点
- 换行文字保留原始存储宽高；原图测量排除软换行前的空格，显式行尾空格和正文保持独立

| 属性 | 生产规则 |
| --- | --- |
| 普通描边 | 原始宽度 1–24，普通工具同步共用默认值 |
| 荧光笔 | 独立宽度 1–48；旧配置缺少独立值时读取旧画笔分组 |
| 序号 | 原始宽度 1–72 |
| 滤镜 | 原始强度 4–48 |
| 文字 | 原始宽度为字号减 19，批量 setter 范围 -11–281 |
| 透明度 | 每项保留自身 RGB，只修改 alpha |
| 快捷颜色 | 每次输入捕获历史，同色也清除重做，同时更新默认色 |
| 属性颜色 | 一次打开只在首个有效输入捕获历史，同色也捕获；关闭不重复提交，默认色保持独立 |

工具默认宽度按照选择编号顺序同步，同一分组最后一个成员决定结果。

## 界面与合成

群组属性栏只显示数量标题、宽度、透明度和颜色，复用统一滑条和色块组件。原生 Qt
属性样式采用 11 像素 Noto Sans 粗体、0.2 像素字距、7 像素圆角和 58 像素最小标题宽度。
字距及字形前进量按 1/64 像素处理，标题变化才重排，字体按需定向加载。

| 数量 | 英文标题宽度 | 中文标题宽度 |
| --- | ---: | ---: |
| 2 | 63 | 58 |
| 10 | 69 | 58 |
| 100 | 75 | 63 |
| 1000000 | 101 | 89 |

群组滑条高度为 18 像素，纵向位置为 13 像素；普通既有滑条保持自身布局。

共同拖动期间跳过持久缓存重建，在损坏区域按原图层顺序合成所有相交对象，保留未选中
透明对象的遮挡关系。结束手势时登记初始和当前正文损坏，恢复正常缓存。虚线转换为
填充轮廓后按固定像素原点分块绘制，控制点也采用固定小块，避免分数比例局部重绘改变相位。

发现端点选中提示与撤销后状态不同，Sway/niri 分别有 187/204 个局部像素差异。它保留为
失败候选，清单为 `target/verification-annotation-collection-r1/result.json`。
