# 原图位置翻译兼容与验证

固定图片已接入图片位置翻译、目标语言父子菜单、原文与译文切换、译文选择及复制。
截图编辑器也已接入语言弹层、结果栏、原图恢复与截图到贴图的翻译交接；独立语义、
输入及验证边界见 [selection-translation-compatibility.md](selection-translation-compatibility.md)。

## 共享计算与渲染

`src/features/image_translation/` 分开处理段落、颜色、文字排版、服务交换、绘制、选择及交接。
段落保持 OCR 行顺序，按原版续行规则合并并分离列；颜色采样使用图像存储的预乘通道。
字体度量采用原版的 1/64 像素量化，保留完整译文并单独计算可见行和省略文本。
所有背景板先绘制，再绘制所有文字；绘制直接使用可见缓冲区，不分配整图透明覆盖层。

原生服务保留段落身份。命令和 helper 请求携带实际 OCR 坐标；响应支持矩形及点集，
先标准化、裁切，再按行身份或最大重叠映射。图片响应缺少几何信息时报告失败，纯文本
OCR 结果窗口仍使用既有文本协议。

## 固定图片工作流

- 翻译显示不改变复制、保存、编辑使用的原始像素；显示切换复用缓存。
- 目标语言使用原生父子 `xdg-popup`，继承抓取并逆序销毁；右键不能激活语言项。
- 改变语言先保存配置，再取消旧任务、清除旧译文；旋转同时使旧坐标和任务身份失效。
- 识别和翻译期间在贴图底部显示状态；失败保留原图并显示错误，关闭桌面通知时仍可看到反馈。
- 服务未返回任何有效译文时报告失败，不把回填原文缓存为翻译成功；部分译文缺失仍保留对应原文。
- 翻译完成提示三秒后消失；任务回收与提示到期均结束后恢复阻塞调度。
- 首次缺少模型时打开紧凑原生引导；下载成功后继续原贴图翻译，取消保留贴图。
- 无 OCR 缓存时，“复制图片文字”在同一贴图识别并复制；空结果不覆盖剪贴板。
- 双击只选中当前行；复制选区使用单个换行，不改变独立 OCR 窗口的段落复制语义。

## 截图交接协议

`image_translation::seed` 保留原始 OCR token、译文块和显示状态。帧格式为
`MS-PIN-TRANSLATION\0`、小端 32 位 JSON 长度、JSON 元数据及原图 PNG。
元数据限制 8 MiB，PNG 限制 64 MiB；输入验证坐标，并支持移位及范围过滤。
贴图命令行已支持 `--translation-seed`，`pin::spawn_translated` 可交付原图和缓存。
截图编辑器使用当前裁切范围导出原图和标注，再移位、裁切并缩放翻译数据，保持译文显示
状态。字号、底板、行框和基线一起换算，跨输出缩放后仍保留实际物理像素坐标。

## 验证证据

`scripts/x11-pin-translation-workflow.py` 使用私有 Xvfb 和本地 HTTP 服务，通过真实右键菜单
验证请求发送、错误和空响应提示、失败重试、等待进度、译文显示、目标语言、原始 PNG 复制、
缓存切换及完成提示到期。无模型时同时验证所属 OCR 引导窗口、取消保留贴图和再次打开引导。
测试仅使用夹具文字与密钥。Windows 共用原生窗口实现，交叉编译不能代替 Windows 实机验证。

`src/translation/task/tests/response_tests.rs` 通过实际 HTTP 任务覆盖空数组、无匹配段落及
全空文本，防止服务成功响应被误判为有效译文。Wayland 专项脚本同时验证错误在贴图内可见，
以及完成提示消失后的空闲资源与原图恢复。

实际 Qt 6.12.0 生产模块生成 92 个样本：56 个段落、13 个连接、9 个颜色、10 个排版、
4 个交换样本。`tests/image_translation.rs` 全部通过。排版误差阈值为 0.0001 像素，
颜色逐通道一致；字体数值对照以本机 Noto Sans 为条件，不代表完整字形像素一致。
初次排版失败记录保留在 `target/image-translation-layout-diff-r1.json` 和 `r2.json`。

本节记录贴图第五轮专项验证时的历史二进制，SHA-256 为
`fb78805658341493f765b014dcd35fe3386df2182fafc6da81b52d52037aecbc`，大小 48,122,888 字节。
Rust 工作区 1018 项通过、10 项既有忽略；格式及全部目标、全部特性严格 Clippy 通过。
Python 单元套件 199 项通过；后续剪贴板等待修正另由完整实际流程验证。

`scripts/wayland-pin-translation.py` 在隔离 Sway 和 niri、1.2 分数缩放及翻转输出上通过
实际命令坐标交换、缓存切换、父子菜单抓取、左右键隔离、明暗菜单像素恢复、译文复制、
原图复制、语言失效、失败恢复、运行命令取消、模型引导取消、真实模型下载后继续翻译，
以及新贴图直接识别复制。两次运行均记录九次空闲采样，共 18 次；所有采样保持单线程、
CPU 时间不增长、缓冲提交数不增长。

`target/wayland-pin-translation-sway-r5/checks/result.json` 和
