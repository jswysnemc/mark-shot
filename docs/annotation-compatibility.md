# 标注功能参考

本文记录原版行为与已定位的实现位置，不把尚未移植的能力标记为已支持。

## 文字标注

原版参考为 `qt/src/text_annotation_layout.cpp`、`qt/src/annotation/text_size_limits.h`、
`qt/src/shot_window_text_controls.cpp`、`qt/src/shot_window_text_editor.cpp` 和
`qt/src/shot_window_font_panel.cpp`。探针直接编译原版排版文件，不修改源码或读写原版配置。

- 默认 Sans Serif、二十点、DemiBold（600）字重及透明背景；字号属性限制为 8–300 点
- 点字号先随预览比例取整，再由字体引擎转换并取整像素；实际 96 DPI 探针测得二十点为 27 像素
- 文字背景圆角为四个原图像素，正文与背景分别使用自身 alpha；背景透明也保留左右六、上下四像素内边距
- 原图判断换行，可用宽度不足十六像素时不启用换行，预览只映射宽度
- 字体家族和字形修改保持单行状态且不覆盖默认样式；字号同步默认值并比例缩放换行框宽，背景取色一次打开共用一次撤销
- 原版 Enter 插入新行，Ctrl+Enter、Esc 和外部点击提交；提交去掉末尾空白，空白新文字不形成标注

原生文字拆为 `features/text/`、`fonts/text_faces.rs`、`fonts/text_spans.rs`、
`tools/text/`、`editor/text_edits.rs` 与 `editor/text_size.rs`，字体匹配按实际文件缓存，不把常规字体当作同家族半粗体。
正文缺字采用系统首选回退，统一保留字素、换行与末尾空行，字体和背景进入标注历史。
此前 Rust 偏好中的旧像素字号转换为点字号，新偏好明确保存单位，尚未完成原版 Qt 配置迁移。

当前只有文字度量、样式属性、背景和导出链路完成本轮对照。实际 Qt 与 Rust 的十五个场景
字号像素均相同，十二组背景框相同；八点与斜体样例宽度各少一像素，半比例换行样例少一行。
字形和抗锯齿仍不同，不宣称逐像素一致；原始 JSON、PNG 与差异图见
`target/text-annotation-comparison-final/`。

属性栏与字体弹层已经接入，字号入口另有二十八组实际 Qt 输入记录对照。
独立内联事务、Esc/Ctrl+Enter 提交、空白文字处理、字符拖选与标注移动分流和文字右键菜单
现已接入。实际编辑预览不修改持久正文，提交保留已有身份；键盘提交不退出截图会话。
输入法、光标闪烁、原版完整角点缩放、选区边缘换行与位置回移以及样式局部历史仍未完成。
具体规则和证据边界见 `docs/text-editing-compatibility.md`。

### 标注历史快照

原版 `qt/src/shot_window_annotation_editing.cpp` 的快照还包含选中对象和下一标注编号，
不能只保存标注及序号计数。`editor/history_snapshot.rs` 对应保存 `selected_id` 和 `next_id`；
撤销、重做按持久身份恢复选择与下一编号，删除已有文字后撤销恢复该对象及选中状态。
新文字提交先保存快照再分配编号，空草稿不消耗编号。工具默认字号仍不属于历史快照。

## 激光

- 激光是自动消散的临时笔迹，不是持久画笔标注，见原版 `docs/user-guide.zh-CN.md:191`
- 实现位于 `qt/src/shot_window_annotation_painting.cpp:293`：按平滑路径绘制外层辉光、颜色主线与白色细芯
- 外层宽度为主线的 2.6 倍，颜色透明度同时乘以消散进度和原始颜色透明度
- 鼠标移动按距离插入中间点，每次最多插入 24 个，见 `qt/src/shot_window_annotation_painting.cpp:336`
- 松开鼠标后重新设置过期时间，启动清理定时器；没有完成笔迹时不保存单击草稿
- 切换工具只取消未提交草稿，已经完成的临时笔迹继续自然消散，见 `qt/src/shot_window_input.cpp:558`
- 生命周期为 1800 ms，见 `qt/src/shot_window_internal.h:44`；清理间隔为 33 ms，见 `qt/src/shot_window_setup.cpp:638`
- 即时保存和复制均通过 `renderedSelection()`，只绘制持久标注和尺子，不绘制激光草稿或完成笔迹，见 `qt/src/shot_window_actions.cpp:300`

原生实现使用 `features/laser_trace/` 保存独立临时状态，支持工具栏、颜色、独立笔宽、
`G` 快捷键与 `--fullscreen-default-tool laser`。草稿不消散，松开后开始完整生命周期；
切换工具取消草稿，完成笔迹继续消散。最后一笔过期后停止激光轮询，局部绘制包括辉光边缘，
不在未清除区域重复叠加透明度。激光不进入持久标注、撤销记录或图像导出。

本次实现增加内存保护：最多 64 笔、单笔最多 4096 个采样点、总量最多 16384 个点。
长手势原地简化并保留首尾点，容量不足时优先淘汰最旧完成笔迹；这些限制不是原版常量。

## 形状与编号

- 形状标记包括星形、心形、多边形等，非填充轮廓随笔宽变化；工具栏图标跟随当前形状
- 路径与样式入口位于 `qt/src/shot_window_marker_shapes.h`、`qt/src/shot_window_property_panels.cpp:170`
- 序号支持阿拉伯数字、字母、罗马数字、天干与中文，与编号箭头属于不同工具
- 序号拖动使用独立点数组，见 `qt/src/shot_window_input.cpp:196`；提交后更新下一编号
- 箭头需要实心、KDE、双向头部，并支持直线、曲线、实线、虚线和点线

原生标记现已实现全部二十四种形状，使用 `K` 和 `--fullscreen-default-tool marker`。
形状、填充与三像素独立默认笔宽分别保存，不复用普通矩形的填充设置。工具栏图标跟随
当前形状，属性网格支持鼠标、键盘、滚动、确认和关闭。已有标记可以修改形状、填充、
颜色与笔宽，修改形成单次撤销；空手势、源图外起点与 Ctrl 等比约束已有输入回归。

画笔草稿覆盖已有标记时，取消或切换工具通过原始像素块备份恢复图层。标记原图导出保留
原始分辨率与透明度，二十四种形状和持久剪贴板均经过真实 Wayland 回归。不把旧编号
箭头当作全部序号能力。

独立序号已接入 `N` 和 `number|serial|sequence`，旧编号箭头保留 `Shift+N` 和
`numbered|numerated-arrow`。单击绘制圆框，拖动保持按下位置为圆心、当前位置为尖端；
提供七种样式及重置按钮，默认独立笔宽为 3，范围 1–72。新安装采用原版红色
`#FF4D4D`，已有颜色偏好保持优先。

字母按 A–Z、AA–AZ 继续，大小写罗马分别绘制，天干每十项循环；中文超过 9999 使用
十进制，过长罗马标签也回退到十进制，避免无界分配。中文与天干使用二十三字内置字体
子集，包含独立字体名称和 OFL 1.1 许可证，不依赖识别模型或系统字体扫描。

提交、取消、删除及重置保持独立计数规则，撤销与重做恢复标注和下一编号，偏好不保存
会话编号。已选序号支持圆心、尖端独立移动、外框缩放和旋转；正文外控制点优先命中，
首次按下圆心不转为整体移动。Ctrl 等比、Shift 四十五度吸附、属性粘贴与原图绘制均有
专门回归覆盖。

## 箭头与曲线

原版路径和属性参考位置为 `qt/src/annotation/arrow_rendering.cpp`、
`qt/src/annotation/arrow_style.h`、`qt/src/line_skeleton_path.cpp`、
`qt/src/shot_window_line_anchors.cpp` 与 `qt/src/shot_window_arrow_properties.cpp`。

- 四种头部保持原版编号：实心、KDE 开口、双向实心、双向 KDE；头部与箭身线型分别选择
- 实线、虚线和点线只改变箭身，头部始终连续；普通直线使用独立线型和笔宽偏好
- 两端点保留索引零、一，控制点从索引二开始；单控制点为二次曲线参数，多点按相邻中点形成连续路径
- 选择工具双击路径插入控制点，Delete 优先移除当前控制点；端点不能单独删除，撤销清除临时点选择
- 端点、正文外控制点、外框和旋转把手分别命中；Ctrl 等比缩放，Shift 将创建方向和旋转吸附到四十五度倍数
- 默认笔宽为 3，范围 1–72；修改已有标注的头部或线型不覆盖后续默认样式

原生实现以 `features/line/` 组合骨架，以 `features/arrow/` 组合头部。屏幕与原图共用
闭合轮廓，头部与箭身一次填充，不重复覆盖半透明接缝。分数缩放、局部重绘、原图缩放、
退化输入和完整头部乘线型矩阵已有几何与绘制测试。

当前构建已完成 24 种直线、曲线组合的真实 Wayland 回归，覆盖多控制点、删除历史、
实际外框、旋转吸附、属性粘贴、默认值隔离、偏好重开及原图剪贴板。旋转把手放在全部
骨架点上方，避免遮挡控制点；精确外框和损坏区域共用边界，取消选择不残留角标。

控制点最多 128 个、细分最多 8192 点、重采样最多 512 段，临时像素块最多 4 MiB。
这些是本次新增的容量保护，不作为原版常量。通用图形旋转与多选仍需补齐，不能
用线条专用控制点代替全部高级编辑能力。

## 原图滤镜

原版参考为 `qt/src/shot_window_filter_rendering.cpp`、
`qt/src/shot_window_annotation_editing.cpp`、`qt/src/shot_window_width_state.cpp`，
以及 `crates/shot-image/src/blur.rs` 和 `crates/shot-image/src/filters.rs`。

- 五种模式保持原版零至四编号：像素化、模糊、灰度、反色、提亮；默认像素化
- 默认强度十四，范围四至四十八；像素化网格从原图选区左上角开始，不使用全画布网格
- 模糊使用三次盒式处理，读取区域外两倍半径留量后裁回；灰度权重为红十一、绿十六、蓝五，再除以三十二
- 灰度与反色不使用强度，提亮比例为强度除以六十，限制为 0.05–0.9
- 所有模式读取冻结原图，不处理先前标注；创建最小尺寸为两条边各两个原图像素
- 支持透明度、旋转、八点缩放、移动、删除和历史；Ctrl 用于已有区域等比缩放，Shift 用于四十五度旋转吸附，创建不强制正方形
- 修改已有模式不覆盖后续默认模式，修改已有强度同步工具默认强度

原生实现使用 `features/filter/` 与纯 Rust 图像算法，屏幕和原图共用冻结像素。
像素化平均值直接写入预乘通道，避免半透明颜色再次乘透明度。效果作为覆盖层进行
`SourceOver` 合成，半透明区域最终可能更不透明；未修改区域保持原始颜色和透明度。

核心块为 512×512；单项像素缓存最多 4 MiB、总量最多 16 MiB，较大区域按需分块。
取消、删除和历史替换立即清理无效项，不把旧工作区模糊副本保留为常驻缓存。固定输出
相位同时用于完整画布、非整数原点导出与局部子缓冲，视口裁切不改变遮罩扫描起点。

配置保留旧 `pixelate` 读取兼容，新模式优先；偏好写入 `filter_mode`，不再写入旧开关。
强度字段粘贴后使用 Enter 确认；数值输入没有字段级 Escape 取消约定，Escape 仍属于
会话取消，不能与模式弹层或未提交手势的取消混为一谈。

当前构建完成五模式乘三种强度的真实 Wayland 回归，包含 598×530 原图区域的双向接缝、
真实透明度字段、全部缩放点、自由及等比调整、自由及吸附旋转、取消与删除历史、默认值
隔离和偏好重开。独立 NumPy 参考核对全部 1600×900 像素，RGB 只允许一单位编码舍入，
alpha 和未修改 RGBA 完全一致；退出后图片剪贴板与保存图像一致，普通编辑不创建模型目录。

## 尺子与放大镜

- 长度尺显示宽、高、对角线与面积；角度尺先放顶点和第一条边，再点击确定第二条边
- 选中尺子可以移动、缩放、旋转；Ctrl 等比缩放保持夹角，Shift 将边吸附到 45 度倍数
- 尺子的测量结果会进入复制和保存图像，不是仅供编辑器显示的提示
- 完整行为见原版 `docs/user-guide.zh-CN.md:192`，绘制入口为 `ShotWindowRulerPainter`
- 标注放大镜保存取样点与透镜中心，允许圆形和矩形镜框；拖动决定透镜直径和位置
- 放大镜拖动逻辑位于 `qt/src/shot_window_input.cpp:171`，不能把现有光标取色放大镜当成标注放大镜

长度和角度尺已实现，入口为 `U` 或 `ruler|measure`。长度说明保留宽、高、对角线与面积；
角度支持三次单击，或拖动第一条边后单击第二条边。Shift 吸附四十五度，Ctrl 等比调整
保留夹角，已选尺子可移动、调整定点及旋转。再次激活尺子切换下一次测量模式，不转换或
删除持久测量。模式弹层 Enter 只确认，不触发截图导出。

从选区工具进入尺子后，Escape 依次取消草稿、清除本次测量并返回选区、退出截图。测量
数字使用原图像素，不因本地图像预览或导出缩放改变。测量说明最后绘制，窄范围分行，
长度说明避让其他尺子及说明；临时悬停不进入保存或复制。

持久双框放大镜已实现，入口为 `Z` 或 `magnifier|magnify|loupe|zoom`。参考位置进一步核对为
`qt/src/shot_window_magnifier_drag.cpp`、`qt/src/shot_window_annotation_painting.cpp:449`、
`qt/src/shot_window_selection_frame.cpp:248` 与 `qt/src/shot_window_property_panels.cpp:338`。

- 默认圆形、倍率 2.75，范围 1.25–6；矩形和圆形均为完整源框与镜框，不是光标提示
- 创建最短拖动 64 个原图像素，直径为距离的 1.05 倍，限制为 72–320；小图按原图可用范围约束
- 源框与镜框独立移动，任一框调整尺寸后按固定倍率联动；两框的完整范围均约束到原图内
- 镜框控制点优先，再检查源框控制点；内部重叠时优先移动源框，矩形各八点、圆形各四点
- 中心距离大于镜框半径加源框半径的 0.65 倍时绘制两条连接线，取点角度为三十四度
- 原图使用双线性预乘取样，圆形裁切、边框向内绘制；逻辑笔宽限制为 1.5–18，导出同比缩放
- 支持单组双框旋转、Shift 吸附、Ctrl 矩形等比调整、删除、草稿取消以及单次属性撤销

放大镜不复制源区域内的旧标注，也不再次捕获桌面。原图、透明度和导出比例通过测试；
已有框拖动时按原始层序重绘，较新的标注始终位于正确层级。矩形切换、倍率两位精度、
真实剪贴板输入、控制点和空闲状态经过隔离 niri 回归。通用标注旋转与多选仍属未完成项。

## 快捷键差异

原版编辑阶段：S 选择、P 画笔、L 直线、H 荧光笔、R 矩形、E 椭圆、K 形状标记、
A 箭头、T 文字、N 序号、M 遮挡、G 激光、U 尺子。

原生版本当前仍包含参考项目的默认映射：S 调整选区、V 选择标注、D 直线、C 椭圆、
I 取色、M 或 X 原图滤镜；G 已改为激光，K、U、Z、N 分别进入标记、尺子、持久双框
放大镜和独立序号。Shift+M 切换光标取色放大镜，默认快捷键已有无冲突测试。选区前
启动工具和编辑阶段必须分别处理，不能全局
覆盖造成按键冲突。

## 原生职责边界

- `src/tools/` 负责手势与按键，不承担图片编码或协议分发
- `src/types/annotations.rs` 保存数据，`annotations/bounds.rs`、`annotations/transform.rs` 分别处理边界与变换
- 临时激光状态与绘制应独立于持久标注，空闲且笔迹消失后恢复阻塞等待
- `src/renderer/` 负责屏幕与导出的一致绘制，测量单位需要考虑本地原图与 Wayland 缩放
- `src/renderer/frozen_image.rs` 负责冻结原图采样，`annotation_stack.rs` 负责暂存标注的原始层序
- 原版源码只读，不修改其未提交内容
