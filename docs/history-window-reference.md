原版窗口默认 800×520，当前参考屏幕下最小 440×320。采集 440×320、620×460、
760×460、800×520 四组真实布局，均保持水平列表与预览，不改为上下分区。

| 控件 | 实测逻辑位置与尺寸 |

| 摘要 | x=12，y=10，高 30；显示标题及记录数，不显示容量预算 |
| 关闭按钮 | x=窗口宽−44，y=10，32×30，只显示原版关闭图标 |
| 图像操作栏 | y=46，高 30，顺序为复制、编辑、贴图、另存为、删除，间距 4 |

| 预览 | x=221，y=82，宽=窗口宽−233，高=窗口高−128 |
| 分隔条 | x=219，y=82，宽 5，与列表等高 |
| 记录开关 | x=12，y=窗口高−34，163×18 |
| 清空按钮 | x=窗口宽−131，y=窗口高−40，119×30 |
| 列表行 | 首行视口位置 (2,2)，高 44；第二行 y=50，行距 48；图标为 56×38 |

440 像素宽时，五个操作按钮实际宽度分别为 78、79、78、86、79，英文文字仍显示。
800 像素宽时，按钮均宽 152。不能直接把源码中的最小高度、固定尺寸、分隔条样式宽度
当作最终 QWidget 几何；实际布局受到样式与尺寸提示影响。

列表、预览和分隔条的测量矩形存在一像素交叠。实现前必须保留真实测量并核对画面与
命中归属，不能自行把它改成猜测的六像素间距。

## 输入行为

真实 Qt 投递确认：右键点击第二条记录会选择该条；右键点击复制按钮不执行复制。
Ctrl+F 不改变列表焦点。原版没有搜索、数量输入框或刷新按钮。

从列表开始，Tab 顺序为：列表、复制、编辑、贴图、另存为、删除、清空、记录开关、
关闭、列表。该序列只覆盖当前英文样本中可用控件，仍需补充空列表、禁用按钮和弹窗。

补充探针确认初始焦点为关闭按钮。普通图像按钮按 Enter 不执行点击；Space 按下不执行，
释放才执行并复制 PNG。状态行高 19 像素，显示后列表高度与底部操作位置减少 25 像素。
分隔条将列表宽度限制在 184 像素以上，右侧预览最少 180 像素。

离屏探针主动清除显示服务、Wayland、桌面 IPC 和会话总线环境，只使用进程内 Qt 剪贴板。
此前 r2 的复制失败来自临时目录中不存在的 Wayland 套接字，不能当作按钮行为证据。

## 当前原生状态

已移除搜索、数量、加减和刷新控件，恢复顶部五项操作、水平分隔、底部复选框与清空按钮。
列表只显示日期和尺寸两行，预览去掉额外透明棋盘；历史窗口定向加载系统 Sans Serif，
不更改其他窗口的字体。原版 SVG、深色配色和分隔宽度单独组织，不加载全部编辑工具。

四组默认布局、状态行和五组分隔宽度执行严格矩形比较。初始关闭焦点、Tab 顺序、
Space 释放、外部释放取消和失焦取消均有窗口事件回归。左键双击只在相同记录的连续
左键点击中成立，右键或其他区域打断序列；重复选择同一项保留状态文字。

滚动条输入与绘制共用同一几何，轨道翻页和滑块拖动不改变活动记录。未选中记录只缓存
缩略图，避免可见项多于整图预算时淘汰当前预览并反复解码。回归覆盖三十项记录和精确
滚动边界，完整 Rust、Clippy、Python 与格式日志位于 `target/verification-history-r3/`。

本地构建 SHA-256 为 `df1729b4c4214a5152d1dfcd7cf2ae04636826cd22e51a241920f9fbc57d330e`，
大小 43261064 字节。776 项 Rust 测试通过、10 项忽略；147 项 Python 测试通过。
私有 niri 证据为 `target/history-reference-main-r4/`、`target/history-reference-edges-r4/`
与 `target/history-reference-pointer-r3/`。满屏滚动、空历史及完整流程采样均为单线程，
空闲一秒 CPU 时钟增量为零。这些仍为本地二进制证据，发版必须另行验证远程产物。

`scripts/wayland-history.py` 改为真实列表选择和私有配置策略验证，保留原图 RGBA、IDAT、
文件身份、存储边界、配置保留及原图交接断言。鼠标脚本额外验证右键复制按钮不执行、
分隔拖动、满屏记录滚动与屏幕外选择复制，不以这些行为证据宣称逐像素一致。

## 保留差异

历史窗口仍只覆盖英文深色主题；完整提示框、长状态及空预览换行、滚轮和翻页的精确 Qt
行为、亮色与中文、增量缓存及全像素比较尚未完成。清空已替换为同进程独立模态对话框，
三十组真实 Qt 行为和当前证据另见 `docs/history-clear-dialog.md`，不将此前界面证据视为
新窗口验证。公开版本通过新的版本化清单交付，旧清单与资产不改动。
