# 原版界面与鼠标职责对照

技术栈参考 LumineCapture，界面、图标和操作顺序以 Mark Shot Qt 源码为依据。
本轮不是重新设计界面，也不把工具栏分组和贴图菜单完成视为全部界面逐像素一致。

## 截图工具栏

原版依据为 `qt/src/shot_window_setup.cpp`、`qt/src/ui/compact_toolbar.cpp`、
`qt/src/ui/toolbar_grip.cpp` 和 `qt/src/ui/toolbar_palette.h`。

| 项目 | Rust 实现 |
| --- | --- |
| 主栏顺序 | 移动、标注选择；画笔、直线、荧光笔；矩形、椭圆、形状标记、箭头；文字、序号、滤镜、放大镜、尺子、激光；清空、撤销、重做 |
| 副栏顺序 | 范围；打开方式、扩展、滚动截图、贴图、OCR、翻译；复制、另存为、上传；设置；关闭 |
| 默认主栏 | 610×42 逻辑像素，按钮 30，图标 22，内边距 6，间距 2 |
| 默认副栏 | 36×390 逻辑像素，按钮 28，图标 20，内边距 4，间距 2 |
| 握柄 | 十像素窄边，六点排列，点半径 1.25 |
| 分组与配色 | 单像素分隔线；原版石墨色底板、青色悬停、浅青选中、绿色另存为渐变 |
| 全图编辑 | 副栏动作合并到主栏，提供横纵排列切换 |
| 布局约束 | 主栏跟随选区下侧，副栏避让选区与主栏；狭窄输出换行，不改变命中矩形 |
| 图标 | 内置原版 Mark Shot SVG，许可位于 `assets/icons/mark-shot/LICENSE` |

菜单或按钮尚未有完整业务实现时显示禁用状态，不执行无效动作。当前禁用入口为
打开方式、扩展、翻译、上传和完整设置。部分属性面板和默认取色放大镜仍存在
与 Qt 版不同的布局；颜色界面已分别实现原版几何，亮色主题、提示文案与全部快捷键尚未完成对照。

## 鼠标职责

- 左键选择区域、操作标注和界面控件。工具栏按钮只在同一显示器、同一按钮释放时执行；
  按下后移出、右键打断或跨显示器释放都不执行
- 标准选区选择阶段右键取消会话，包括首次拖选尚未完成的临时选区
- 编辑阶段右键取消当前草稿或拖动，保留选区与已完成标注，并回到标注选择工具
- 编辑画布双击右键打开环形快捷色板，再次双击右键关闭；连续点击按不重叠的双击对处理
- 属性颜色按钮只在左键同一按钮释放时切换独立取色器；非左键不执行颜色按钮，也不穿透面板
- 没有选区时中键进入全图编辑，范围按钮可以恢复之前没有选区的状态
- 工具栏握柄只响应左键拖动；跨显示器控件命中按实际面板所在输出判断

## 两种颜色界面

原版依据为 `qt/src/ui/color_picker.cpp`、`qt/src/shot_window_overlay_panels.cpp`、
`qt/src/shot_window_layout.cpp` 和 `qt/src/shot_window_property_panels.cpp`。

| 项目 | Rust 实现 |
| --- | --- |
| 环形快捷色板 | 178×178 透明宿主；十色排列半径 68；原版实际按钮为 28×28；中心预览为 8–34 像素 |
| 属性取色器 | 200×228 宿主；184×112 SV；独立横向 Hue 与 alpha 轨道；当前色、唯一 Hex 字段及八个历史槽位 |
| 属性锚点 | 对应颜色按钮中心下方；底部不足时移到属性栏上方；四边留八像素 |
| 取值 | 跟随 Qt QPoint 先取整指针，再使用控件宽度减一映射；Hue 0–359，其余通道 0–255 |
| 文本 | 支持 RGB 简写、RGB 与 RGBA；确认或失去焦点时应用；连续 Enter 保持字段焦点，不触发导出 |
| 历史绘制 | 当前色禁用；最多七项去重历史；保持原版槽位重叠与末项裁切，不填入旧默认调色板 |
| 控件裁切 | SV、Hue 和 alpha 握柄分别按实际控件边界裁切，不伸入相邻间距 |
| 字体 | 第一次打开属性取色器时只匹配 Sans Serif 常规和半粗文件；快捷色板不加载额外字体 |

属性取色只修改选中标注；没有属性对象时才改变工具默认色。一次打开共用一个撤销快照，
多个 HSV、alpha 与文本操作合并成一个历史项，空编辑不产生历史，也不清除重做。
快捷色板在左键同一按钮释放时同时修改默认色和选中标注，随后关闭；移出释放不取色。
跨输出的滑条拖动继续使用原面板坐标，不把新输出的本地横坐标作为输入。

`tests/fixtures/qt-color-reference/` 直接编译原版控件生成实际 JSON 与 PNG，只用于测试。
探针采用原版子控件结构并关闭顶层背景重复绘制，避免把错误透明背景或自动焦点作为参考。
`scripts/color-interface-reference.py` 分别记录几何相同和像素误差；当前暗色取色器与快捷色板
仍有抗锯齿及字形像素差异，不宣称逐像素一致。文字背景入口已接入独立颜色目标，
但原版文字属性栏布局尚未移植。亮色配色、字段局部撤销、
鼠标拖选与文本右键菜单等状态仍需继续对照。

## 贴图

原版依据为 `qt/src/pinned_window/pinned_image_window.cpp`、
`qt/src/pinned_window/pinned_image_window_paint.cpp` 和 `qt/src/ui/context_menu_style.cpp`。

右键采用真正的 `xdg-popup`，菜单可以伸出贴图边界，由合成器处理抓取和屏幕避让。
菜单保留左右旋转、放大、缩小、重置大小、置顶、编辑、复制、复制所选文字、复制图片文字、
文字选择、翻译、目标语言、显示译文、另存为和关闭的原版顺序。翻译相关项目暂禁用。

- 左键拖动；空白处双击左键关闭；启用文字选择且识别就绪时，左键拖选文字而不是移动
- 八方向边缘缩放优先于文字选择；角落优先命中，单边另一轴居中，对边固定，保持起始宽高比，最小尺寸为 24×24
- 边缘命中留量为 `max(8, border_width + 5)`；贴住或裁切到屏幕边缘的相应方向改为移动，便于恢复完整图片
- 旋转使用九十度无损像素映射；滚轮和菜单缩放只改变预览，倍率限制为 0.1–6，窗口每边至少二十四像素
- 边缘拖动不限制到六倍或屏幕大小；旋转、滚轮及菜单再次应用原版倍率约束，不把首次适配屏幕用于后续缩放
- 滚轮保持指针处的图像锚点，菜单缩放保持中心；右键只打开菜单，不触发边缘缩放
- 复制、编辑、另存为使用旋转后的原始像素，不包含显示缩放、边框或选择高亮
- 默认显示两像素青色边框，文字选择使用原版蓝色半透明高亮
- 置顶使用 layer-shell；关闭置顶切换为普通 xdg 窗口；重新置顶保留原图与倍率
- 选区逻辑位置交给独立贴图进程；首次定位按全局坐标选择输出
- 默认置顶贴图拖动期间固定原输入表面，用无输入预览保持隐式抓取；同一次左键手势可以跨输出并继续拖动
- 输出按相交面积及中心距离选择，支持负坐标和不同分数比例；完整图像可超出屏幕，可见表面只占输出内交集，至少保留二十四像素可见
- 普通窗口使用 xdg 系统移动及缩放；缩放几何、视口与新图像缓冲同时提交，避免旧缓冲尺寸反馈导致连续拖动回退
- 菜单采用原版圆角、细边、危险动作配色；支持左键释放确认、键盘上下导航和 Escape 取消
- 另存为使用共用原生文件选择器，不重复记录截图历史；保存期间贴图降低层级并隔离输入，
  结束后恢复；嵌套窗口退出后显式发送表面销毁请求
- 没有模型时，文字选择或图片文字复制打开首次下载引导，不自动下载；缓存模型在后台识别，
  完成事件唤醒窗口；推理子进程结束后释放模型和并行线程池，普通贴图操作不初始化 OCR

配置示例：

```toml
[pinned]
always_on_top = true
border_enabled = true
border_color = "#5EEAD4"
border_width = 2.0
```

尚未实现可配置阴影、翻译子菜单及全部 Qt 配置兼容。普通窗口经过系统移动后再恢复置顶，
其位置仍需与原版逐项对照；xdg-shell 不提供通用全局窗口位置，不能把默认置顶的跨屏验证
当作全部窗口模式的位置一致证明。输出移除的通知顺序处理仍未完成：主层关闭通知先到达时，
当前循环会结束，不能保证迁移到剩余输出。该流程及多输出混合旋转仍需真实验证。
首次下载引导是独立任务；下载后继续在原贴图上选择文字需要再次启用文字选择。

## 验证边界

`scripts/wayland-toolbar.py` 驱动真实 Wayland 输入，核对双工具栏位置、左右键隔离、
选中状态、握柄移动与实际导出。测试选区宽度允许主副栏同时避让；它不以计算出布局尺寸
代替屏幕上的按钮位置核对。

`scripts/wayland-color-interface.py` 验证实际 RGB/RGBA 粘贴、连续 Enter、HSV 与 alpha 拖动、
整次取色撤销重做、历史预览、环形色板双击切换、默认色和选中标注交接，以及原图尺寸与导出像素。
取色器打开后还检查单线程与稳定空闲 CPU。所有配置、源图、保存目录与合成器均隔离。

`scripts/wayland-ui-parity.py` 验证贴图位置、原生菜单、旋转、缩放后原图复制、另存为取消、
实际保存、窗口角色切换、独立编辑、首次模型引导和空闲 CPU。传入已有模型时再验证
真实文字拖选、全文复制和识别线程回收。所有保存目录、配置、模型副本和合成器均隔离。

`scripts/wayland-pin-geometry.py` 使用独立 headless Sway，验证八个边缘方向的按住预览和释放、
对边固定、左侧裁切后原图比例、嵌边移动恢复，以及同一次抓取跨输出后继续移动和返回。
两个输出使用 1.25 与 1.5 倍缩放，还覆盖第二输出的原生菜单、旋转和非中心滚轮锚点、
普通窗口的系统缩放与移动。复制逐像素核对全部 RGBA，结束后检查单线程及空闲 CPU。
此回归不连接真实桌面，Sway 只是测试工具，不进入应用依赖。

这些回归覆盖交互与原图像素，不等同于 Qt 与 Rust 的全界面截图逐像素比较。最终构建指纹、
执行结果和性能采样见 `docs/rewrite-status.md`；旧失败证据保留，不覆盖为成功记录。
