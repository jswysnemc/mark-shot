# 截图起始界面与编辑交互

2026-11-12，分支 `feat/native-barcode-scanning`，未提交工作区。

## 起始界面

- 上方四个入口：选区、全屏、录屏、录 GIF。全屏使用点击入口所在显示器。
- 左下角只读快捷键提示从有效键位映射生成，包括冲突或禁用后的结果；逗号、句号用于历史选区。
- 顶部入口栏 308×38 逻辑像素，左下角最多 280×144；提示宽高均限制为所在输出的四分之一。
- 完成有效选区后永久移除起始界面；无效小拖选不移除。不做鼠标避让。
- 录屏和 GIF 框选后打开原生控制窗口，点击开始录制。一次性格式不覆盖全局格式配置。
- 同配置已有录制时显示格式、阶段和时长，可暂停、继续、停止。控制请求独立于面板可见性。
- 已有空闲录制控制窗口时提示使用原窗口，避免创建第二个窗口争用同一录制锁。
- 使用已有 Painter、controls 和定向字体回退，没有增加依赖或内置字体文件。

## 编辑交互

- Windows 下拉菜单只在新的外部按下时关闭；打开按钮对应的松开消息仍交给原控件。
- 工具栏按钮配置显示返回入口，Esc 返回原设置页，并恢复搜索、滚动位置。
- 图片编辑器使用单行工具栏、标题按钮和可调整边框；窗口宽度至少容纳工具栏。
- 拖动工具栏空白或标题栏移动窗口；中键拖动图片，小图也可移动；溢出滚动条按需显示。
- 已有文本单击选中并拖动，双击编辑；空白处仍可新建文本。
- 历史选区只保存坐标和显示器布局，最多 32 条；并发保存合并，逗号/句号不抢文字字段输入。

- 工作区测试 1569 通过、32 忽略；Linux 全目标 Clippy 通过。
- Windows MSVC 交叉编译成功；私有 Wine/Xvfb 1920×1080 下四项原生 HWND 测试通过。
