## 此前截图文字输入法构建

已取得十七组真实 Qt 输入法场景、77 个状态与原始画面，冻结样本为
`tests/fixtures/qt-text-input-method.json`。候选更新不写正文；选区内开始组合立即删除
选中文字，取消不恢复；输入法逐次确认独立撤销。这些行为不能用普通键盘插入代替。

当前 release 为 43153416 字节，SHA-256 为
`20dbcedba3fa5a892a845be21f11437dac1cb64a2471df0c805679efc4b5cfba`。
私有配置工作区 738 项 Rust 测试通过、10 项忽略，Python 114 项通过；严格 Clippy、
格式与新增脚本 Ruff 检查通过，动态链接没有 Qt、GTK 或 WebView。索引为
`target/verification-text-input-native/result.json`，不混用此前构建证据。

独立候选标注与缓存只服务显示，正文、撤销和导出只使用已确认文本。六项生产组合
测试包含全部 77 个实际 Qt 状态、候选取消、隐藏光标和四种分数缩放下的局部像素
恢复。每次输入法确认独立撤销，非法替换整体拒绝，不丢选区或此前候选。

原生层按键盘 seat 可选绑定 text-input-v3。正文会话与焦点身份独立于预览缓存编号，
按 done 序号识别原字段；旧消息不能进入新会话，旧序号仍处理同字段内容，但匹配
序号到达后才同步上下文。周边正文最多四千字节，段落锚点规范化为合法 UTF-8
位置，光标矩形使用显示编辑器的表面逻辑坐标，闪烁帧不复制文字或重发协议。

私有 niri、Sway 的 layer 与 window 四种组合共 21 个真实投递场景通过；候选、
确认、四字节扩展汉字、字节删除、逐次撤销重做、字段停用、菜单取消和原生离开
恢复均有证据。Sway 原生焦点恢复先提交 disable，再启用新状态；不依赖合成器
清理旧启用标志。未确认候选的导出与无候选基准逐像素一致。隐藏候选光标期间
单线程、CPU 时钟增量为零，停止画布提交；同一构建的两个既有光标回归也通过。

当前 niri 菜单关闭后的首次移动仍为 `(672.6289,359.5352)`，而非 `(341,500)`，
证据位于 `target/ime-pointer-final/`。此前原版 Qt 已复现同一边界，产品不补发移动，
不缩减专项断言。默认用户偏好导致一项尺子旋转测试失败；相同源码在私有配置中
通过，最终工作区测试全部使用私有配置，未修改用户偏好。

字体搜索、普通输入框与独立窗口的原生输入法仍未接入。Fcitx、IBus 等实际输入法
配置、完整 Unicode、文字缩放换行、亮色主题和 Qt 逐像素一致尚未覆盖；设置、
翻译、上传、扩展、托盘、配置迁移与完整合成器矩阵仍属于原目标。
